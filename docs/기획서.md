# 멀티플레이 탁구게임 기획서

Nov 16, 2026 · @재현 · 기획 단계 초안 v0.1

## 1. 개요

- **게임 이름**: 준비하시고, 스매시!
- **목적**: 소규모 교육생(10\~20명)이 수 주 과정 동안 쉬는 시간과 친목 시간에 즐기는 게임
- **플랫폼**: PC 웹 브라우저 (설치 없음, 링크와 방 코드로 접속)
- **모드**: 1v1, 2v2 (복식은 번갈아 치기)
- **시점**: 3D 3인칭 (내 캐릭터 뒤에서 상대를 바라봄, Wii 스포츠 느낌)
- **아트 스타일**: 로우폴리 카툰
- **사운드 콘셉트**: ASMR 게임. 탁구공 바운드음과 타구음이 핵심이고 BGM은 없음
- **핵심 재미**: ① 마우스 하나로 누구나 바로 하는 쉬운 조작 ② 듣기 좋은 타구음과 바운드음 ③ 코인을 모아 캐릭터를 꾸미는 성장 요소 ④ 교육생끼리 쌓는 전적과 라이벌 구도

## 2. 핵심 조작

| 요소 | 방식 |
| --- | --- |
| 이동 | 캐릭터가 공이 떨어질 지점으로 **자동 이동** |
| 스윙 | 공이 타격 존에 들어온 순간 **마우스를 위로 올리며 클릭** |
| 방향 | 스윙할 때 마우스를 올리는 **방향**(↖ 왼쪽 위 / ↑ 위 / ↗ 오른쪽 위)으로 **왼쪽·가운데·오른쪽** 3방향 중 하나로 보냄 |
| 서브 | 클릭하면 공을 토스하고, 떨어지는 공을 같은 방식으로 스윙 |

**스윙 인정 조건**: 클릭 직전 0.15초부터 클릭 직후 0.09초까지 마우스가 일정 거리 이상 위로 움직였으면 스윙으로 인정합니다. 타구음은 클릭 즉시 나고, 방향은 클릭 직후 0.09초까지의 움직임을 보고 정합니다. 위로 올리지 않고 클릭만 하면 약하게 막는 '블록'이 되어 공이 느리고 높게 넘어갑니다.

**타이밍 판정 등급**

| 등급 | 결과 |
| --- | --- |
| Perfect | 빠르고 낮은 공, 노린 방향으로 정확히 감 |
| Good | 보통 속도, 방향이 약간 흔들림 |
| Bad | 높게 뜬 찬스볼, 상대가 치기 쉬움 |
| Miss | 헛스윙 또는 네트·아웃 → 실점 |

**시각 보조**: 공의 그림자와 함께, 타격 존에서 원이 좁혀지는 '타이밍 링'을 보여줘서 언제 쳐야 하는지 직관적으로 알 수 있게 합니다.

## 3. 경기 규칙

- **5점 선취 단판** (한 판 2\~3분)
- **서브권**: 1점마다 상대와 돌아가면서 서브
- **듀스**: 있음. 4:4가 되면 2점을 먼저 앞서는 쪽이 이기고, 듀스 중에도 1점마다 서브를 교대함
- **2v2 규칙**
  - 실제 복식처럼 A1 → B1 → A2 → B2 순서로 번갈아 침
  - 서브도 A1 → B1 → A2 → B2 순서로 돌아가며 1점씩 넣음
  - 차례인 선수만 스윙 입력이 활성화되고, 차례가 아닌 팀원은 자동으로 비켜섬
  - 화면에 "내 차례!" 표시와 함께 효과음을 넣음
  - **카메라**: 각자 자기 캐릭터 뒤 기준. 내 차례가 아닐 때도 카메라는 내 캐릭터를 따라감

## 4. 성장·재화 시스템

**코인 획득 (사용자 확정)**

부정 방지를 위해 코인은 **경기가 끝난 뒤** 서버가 계산해서 줍니다. **로그인한 사람만** 받습니다. 경기 중 나가면 전적도 코인도 없습니다.

| 구분 | 조건 | 코인 |
| --- | --- | --- |
| 경기 | 참여 | +10 |
| 경기 | 승리 | +10 추가 |
| 성과 보너스 | 퍼펙트 3연속 (6연속이면 2번) | +5, 한 경기 최대 3번 |
| 성과 보너스 | 랠리 10회 이상 이어 가기 | +5, 한 경기 최대 3번 |
| 성과 보너스 | 3연승 (1v1·2v2 합쳐서, 3·6·9연승마다) | +15 |
| 출석 | 하루 첫 접속 (한국 시간 기준) | +20 |
| 혼자 하기 | **내가 친 횟수 4번마다** (랠리가 끝날 때마다 정산, 남은 횟수는 이어서 셈) | +1 |
| 일일 미션 | 나중에 구체화 | - |

- 결과는 대기실에 "🪙 +35 코인 (경기 참여 +10 · 승리 +10 · …)"처럼 보여 주고, 로비에 내 코인이 보입니다
- 10초 안에 또 들어온 경기 결과는 무시합니다
- 혼자 하기는 1v1·2v2로 같은 시간 동안 버는 코인의 **약 50%**(사용자 확정). 시간이 아니라 친 횟수에 비례(가만히 있는 시간은 안 셈). 서버가 지난 기록 이후 시간으로 '1초에 1번'을 넘는 횟수는 잘라냅니다
- 계산 근거(추정): 1v1 한 판 ≈ 약 1분 30초~2분, 평균 약 20코인(분당 약 11코인). 혼자 하기는 AI가 실수를 안 해 1분에 약 25번 치므로, 4번에 1코인 ≈ 분당 약 6코인

**상점·꾸미기 (사용자 확정, 세부 항목은 초안)**

원칙
- **보기만 바뀌고 실력에는 영향 없음.** 개그 탁구채도 맞는 범위·판정은 기본 탁구채와 같습니다
- **공은 언제나 잘 보여야 함.** 탁구대·배경·공 색은 서로 잘 구분되는 것만 팝니다

- **산 물건 되팔기 없음.** 사기 전에 내 캐릭터에 입어 보기(미리보기)가 됩니다

## 5. 계정·기록

> 2026-11-16 사용자 확정. 예전 게임에서 정보를 **브라우저에만** 저장했더니 브라우저 초기화(교육장 PC 재부팅, 방문 기록 삭제, 시크릿 창, 다른 PC)로 계정이 사라지는 일이 있었다. 그래서 **진짜 정보는 서버(Supabase DB)에, 브라우저에는 '로그인 열쇠'만** 둔다.

- **로그인**: 닉네임 + 4자리 PIN. 처음 보는 닉네임이면 "새로 가입할까요?", 이미 있는 닉네임이면 PIN 확인. 닉네임은 한 사람만 쓸 수 있음(오타로 계정이 두 개 생기지 않게).
- **자동 로그인**: 로그인하면 브라우저에 열쇠(토큰)를 30일간 기억. 열쇠가 지워져도 닉네임+PIN을 다시 치면 **기록이 그대로 돌아옴**.
- **손님으로 하기**: 로그인 없이 지금처럼 닉네임만 치고 바로 플레이. 손님의 기록은 저장되지 않음(혼자 하기 최고 기록만 브라우저에 저장).
- **저장 항목(이번 단계)**: 닉네임, PIN(암호화), 1v1 승패, 2v2 승패, 혼자 하기 최장 랠리, 1v1 상대 전적. (코인·아이템·출석·미션은 나중 단계에서 같은 표에 추가)
- **랭킹 보드**: **승수**(1v1+2v2 합계)와 **최장 랠리** 두 가지. 승률·코인 랭킹은 하지 않음.
- **운영**: 강사용 관리자 화면 없이 운영함

**PIN 분실 대응**: 복구 단어는 **쓰지 않는다**(사용자 확정).

1. **자동 로그인**으로 PIN을 다시 칠 일 자체를 줄임
2. **PIN 변경**: 로그인된 상태에서 언제든 PIN을 바꿀 수 있음
3. **PIN을 잊으면** 운영자(개발자)가 DB 대시보드에서 직접 PIN을 초기화함

PIN을 5번 틀리면 5분 동안 로그인을 막아, 다른 교육생이 장난으로 PIN을 맞히는 것을 막습니다.

**보안·구현 원칙**

- 표 이름은 `pingpong_players`. 브라우저(공개 키)는 표를 **직접 읽거나 쓰지 못하게** 막고(RLS), 정해진 서버 함수만 부른다: 가입·로그인·내 정보·PIN 변경·경기 결과 기록·최장 랠리 기록·랭킹 보기.
- PIN은 서버에서만 확인한다. 다른 사람의 PIN(암호화된 것 포함)은 브라우저로 절대 내려오지 않는다.
- 경기 결과는 **각자 자기 PC가 자기 승패만** 기록한다(열쇠가 있어야 기록 가능). 다른 사람의 기록은 건드릴 수 없다.

**만드는 순서** (단계마다 사용자 테스트)

1. 로그인 화면: 가입·로그인·자동 로그인·손님으로 하기·로그아웃·PIN 변경
2. 전적 저장: 경기가 끝나면 승패 기록, 혼자 하기 최장 랠리를 서버에 기록, 로비에 내 전적 표시
   - **1v1 상대 전적**(사용자 요청): 1v1 상대와 붙을 때 대기실·경기에서 둘의 지난 전적(예: 3승 2패)을 보여 준다. 그래서 경기 기록에 '누구와 붙었는지'도 남긴다.
3. 랭킹 화면: 로비에서 승수 / 최장 랠리 순위 보기

## 6. 화면 흐름

로그인 → **로비** (내 캐릭터, 코인, 오늘의 미션, 랭킹) → 방 만들기 또는 코드 입장 → **대기실** (1v1/2v2 선택, 팀 배정, 준비 버튼) → **경기** → **결과** (승패, 획득 코인 정산) → 로비

로비에서는 **상점**과 **옷장**(장착 변경)으로 바로 들어갈 수 있습니다.

**동기화 방식**: 방장 PC가 기준(호스트)이 되어 공 궤적, 판정, 점수를 계산하고 채널로 알립니다. 상대 PC는 스윙 입력(시각, 방향)만 보냅니다.

**지연(랙) 대응 핵심**: 방장 PC가 공의 궤적(출발점, 속도, 회전)만 보내고, 각 PC가 같은 공식으로 궤적을 재생합니다. 타격 판정은 '공이 타격 존에 도착하는 예정 시각' 대비 입력 시각으로 계산하므로, 지연이 있어도 판정이 공정하게 유지됩니다.

## 9. 사운드 디자인 (ASMR)

BGM 없이 탁구공 바운드음과 타구음, 이 두 소리를 가장 듣기 좋게 다듬는 데 집중합니다.

| 소리 | 나는 순간 | 설계 포인트 |
| --- | --- | --- |
| 타구음 (라켓에 공 맞는 소리) | 스윙 성공 | 판정 등급별로 다르게 함. Perfect는 맑고 단단한 "톡", Good은 약간 둔한 소리, Bad는 얇고 가벼운 소리. 칠 때마다 음높이와 볼륨을 3\~5% 범위에서 랜덤으로 바꿔서 반복해도 질리지 않게 함 |
| 테이블 바운드음 | 공이 테이블에 닿을 때 | 공 속도에 따라 볼륨과 밝기가 바뀜. 스매시는 더 단단하고 크게 |
| 바닥에 튀는 소리 | 아웃, 실점 | 공이 바닥에서 통통 튀며 점점 작아지고 간격이 짧아짐 (ASMR 포인트) |
| 네트 | 공이 네트에 걸릴 때 | 둔하고 짧은 소리 |
| 서브 토스 | 클릭할 때 | 아주 작은 소리 또는 무음 |
| UI | 코인 획득, 버튼 | 작고 부드럽게, 타구음을 가리지 않게 |

- **공간감**: 내가 친 소리는 가깝고 크게, 상대가 친 소리는 멀고 작게 들리도록 좌우·거리 음향을 적용함. 배경(체육관, 해변 등)마다 잔향을 다르게 해서 배경 아이템의 가치도 높임
- **조용함 유지**: 관중 소리나 해설은 넣지 않음. 득점할 때도 조용한 효과음만 냄
- **반응 속도**: 타구음은 서버 응답을 기다리지 않고 내 PC에서 클릭 즉시 재생함 (Web Audio API). 소리가 조금만 늦어도 손맛이 사라지기 때문
- **소리 만들기**: 실제 탁구 라켓, 공, 테이블을 휴대폰으로 녹음하거나 무료 효과음(CC0)을 편집해서 씀
- **이어폰 권장**: 로비에 "이어폰을 끼고 즐겨 보세요" 안내를 띄움
- **사운드 스킨 (후순위)**: 탁구채나 공 아이템마다 타구음이 조금씩 다르게 나는 상점 아이템

- 구현 단계(제안): ① 서버 표·칭호 달기·꾸미기 '🏅 칭호' 탭·이름표 B안 + 🌱 업적 → ② 경기가 끝날 때 보내는 기록(실력·스매시·서브·흐름) → ③ 관계·수집·출석·숨은 업적 → ④ 결과 띠 다음 '🏅 업적 달성!' 연출 다듬기.

## 12. 관전 모드 (사용자 확정, 기획 완료)
- 목적: 쉬는 시간에 경기 안 하는 사람도 다른 방 경기를 구경하고 응원한다. **선수들 네트워크에 부담이 가지 않는 것**이 전제.

### 네트워크 원칙
- 관전자는 게임 방 채널을 **듣기만** 한다. 방장이 공 정보를 한 번 보내면 Supabase가 나눠 주므로, 관전자가 늘어도 선수 PC가 보내는 양은 그대로.
- 관전자는 게임 방 출석부(presence)에 이름을 올리지 않는다(대기실 인원·정원에 안 낌).
- 관전자는 방장과 시계 맞추기(ping)를 하지 않는다. 받은 공 정보의 시각으로 스스로 맞추고, 약 0.3초 늦게 보여 줘서 부드럽게.
- 중간에 들어와도 방장에게 상황을 묻지 않는다. 점수는 로비 방 목록 정보로, 공은 다음 서브부터 보인다.
- 응원·관전자 출석부는 방마다 따로 있는 **관전석 채널**에서만 오간다. 선수는 이 채널을 듣기만 한다.
- Supabase는 받는 사람마다 메시지를 센다(무료 대략 초당 100개, 월 200만 개 — 만들 때 다시 확인).

### 응원 횟수 제한 (안전장치)
- 한 사람당 **3초에 1개**. 관전자가 **12명을 넘으면 간격이 자동으로 늘어난다**(간격 = 관전자 수 ÷ 4초, 예: 16명 4초·20명 5초). 각자 화면이 관전자 수를 보고 정하므로 서버 일이 늘지 않고, 몇 명이 오든 초당 약 80개 아래.
- 응원 버튼에 다시 누를 수 있을 때까지 남은 시간이 동그랗게 차오른다.

### 관전석
- **탁구대 양옆에 계단 관중석**(사용자 확정, 시안 B). 선수 카메라 화면 양쪽 가장자리에 보인다. 관전자 '옆에서' 카메라는 한쪽 관중석 위에서 내려다본다.
- 관전자는 **내가 꾸민 캐릭터 그대로** + 작은 이름표. **인원·캐릭터 수 제한 없음**(줄을 뒤로 늘림). 많으면 느린 PC·휴대폰 속도를 재 보고, 느리면 줄이는 방법을 사용자에게 고르게 한다.
- 몰입 연출로 체육관이 어두워질 때 관전석도 같이 어두워진다.
- 관전자 카메라: 기본 = 옆에서 보는 중계 시점, 버튼으로 A팀 뒤 / B팀 뒤.

### 응원
- 버튼: 👏 박수 · 🔥 화이팅 · 😮 우와 · 😂 ㅋㅋ · 🚩 A팀 · 🚩 B팀.
- 응원한 관전자 캐릭터가 통통 뛰고 머리 위에 이모지 말풍선. **선수 화면에도 보이고 작게 들린다**. 동시에 많으면 '와아~' 함성처럼.
- 서브 토스 순간에는 응원 소리를 줄인다(선수 방해 X).
- 자동 반응(메시지 없음, 각 PC가 알아서): 랠리가 길면 술렁, 스매시에 "우와!".
- 팀 응원 게이지(선택): 팀별 응원이 쌓이면 그 팀 쪽 현수막 반짝. 점수·판정과 무관.
- **관전 보상 없음**(코인·업적 X). **손님도** 관전·응원 가능.

### 로비 방 목록
- 로비 전용 채널에 **방장만** 방 정보(코드·모드·선수 닉네임·점수·대기 중/경기 중·관전자 수)를 올린다. 점수가 날 때만 바뀐다.
- 로비 '👀 구경하기' → 방 목록(**경기 중인 방 + 대기 중인 방**, 대기 중인 방은 '참가하기'도) + '🎲 아무 방이나'.
- 관전 중 화면 위: ◀ 이전 방 / 다음 방 ▶ / 나가기. 방을 바꾸면 듣는 채널만 갈아 낀다.
- 경기가 끝나도 관전자는 남아서 다음 경기를 기다리고, 빈자리가 생기면 '참가하기'.
- **휴대폰도 관전 가능**. 휴대폰에서는 '참가하기'가 지금처럼 잠기고 '구경하기'만.

### 만드는 순서 (단계마다 사용자 테스트)
1. 로비 방 목록 + 듣기만 하는 관전(옆 시점 카메라)
2. 관전석 캐릭터 세우기(선수 화면에도 보이게) — 자리 시안 스크린샷으로 고르기
3. 응원 버튼·말풍선·소리·횟수 제한
4. 방 넘기기·랜덤 입장, 다듬기 (로비 '경기 중 N' 배지, ← → 키, 이동 중 덮개, 다른 경기 보기 강조, 선수 화면 '👀 N명 관전 중')
- 1~4단계 모두 test에 올림. 사용자 테스트 후 고칠 점 반영. 팀 응원 게이지(선택)는 아직.
