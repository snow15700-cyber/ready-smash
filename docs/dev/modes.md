# 모드: 2대2 · 혼자 하기(김제빵) · 휴대폰 · 관중석·응원 · 링크 미리보기

> **지금 모습만**(11/27 정리). 방 만들기·대기실·방 목록·방 코드·옛 관전 화면은 없어지고 **광장**이 대신함 — 탁구대에 서서 경기·관전(경기장 거품)·모집은 `plaza.md`.
> 아래는 모두 사용자 확정.

## 1. 2대2
- 광장 탁구대에 양쪽 2명씩 서서 모두 준비 → 2대2(`plaza.md` 3장). 김제빵이 한 자리를 채울 수 있음(`plaza.md` 4-2).
- **치는 순서 A1→B1→A2→B2 고정**, 서브도 1점마다 그 순서. 대각선 서브 규칙 없음. 점수는 1대1과 같음. 경기 중 누가 나가면 경기 끝.
- 팀원은 좌우 나란히(1번 왼쪽) 서 있다가 다음에 칠 사람이 앞으로, 아닌 사람은 한 걸음 뒤로. 뒤로 물러난 동안 카메라는 몸 안쪽으로 옮겨 탁구대 가운데를 봄(`updateCamera charZ`). 다른 캐릭터가 카메라 1.3m 안이면 흐려짐.
- '내 차례!'·'내 서브!' 글자 + `playUI('turn')`은 2대2에서만. 이름표는 상대 팀 머리 위에만, 다음에 칠 사람은 노랗게.
- 구현: 선수 = `{side, slot}`, `hitOrder(mode)`·`turn`(match.js). 이벤트 `serveReady`/`shot`에 `turn`, `toss`/`shot`/`miss`에 `slot`. 입력 `in`은 `from`(id)으로 선수를 찾음. 캐릭터 `world.team[side][slot]`.

## 2. 혼자 하기 = '탁구왕 김제빵'
- **연습용**. 난이도 없음. 광장 김제빵 탁구대에서(누구나 동시에, 네트워크 안 씀). 김제빵 꾸미기 = 프라이팬 + 요리사 모자 + 앞치마(`ui/ai.js AI_LOOK`, 보기만).
- 점수 없이 **랠리 기록(내가 친 횟수)**만. 서브는 항상 나. 찬스볼·스매시·몰입 연출 포함(랠리 단계는 없음).
- **김제빵은 절대 실수하지 않음**(헛스윙·아웃 없음, 스매시도 다 받음). 약 18% BAD를 쳐서 랠리 6회 넘으면 찬스볼. 랠리는 내가 실수해야만 끝남. 스매시가 오면 BAD 대신 GOOD(아웃 방지).
- 구현: `match.js AI`(등급별 확률·`smash`·`dir`)·`aiPlan`, 김제빵 차례면 `expect.ai`에 미리 정하고 `update`에서 침.
- 코인·기록은 `accounts.md`(3번에 1코인, 하루 250, 1.2초에 1번).

## 3. 휴대폰
- 광장에 들어옴: 탭으로 걷기, **김제빵(혼자 하기)·관전·채팅·낚시** 가능. **사람 대결 자리는 PC만**('🔒 사람 대결은 PC에서만').
- 판별 `IS_MOBILE`(UA의 Android·iPhone 등 + 아이패드 + 터치만 있고 hover 없음 — 갤럭시는 S펜 때문에 미디어 쿼리만으로는 안 잡힘). `?mobile=1`이면 PC에서 흉내. `body.mobile canvas`에 `touch-action: none`.
- 남은 일(후보): 터치용 스윙 판정(손가락은 닿기 전 움직임이 없음), 휴대폰 방장, 안내 문구 '클릭'·'마우스'를 터치용으로.

## 4. 관중석 · 응원 (경기장 거품 관전에서 씀)
- 원칙 = **선수에게 네트워크 부담 0**. 관전자는 경기 채널(`pingpong-room-XXXX`)을 **듣기만**(presence track·send 안 함). 시계는 방장에게 묻지 않고 받은 `pong.th`·이벤트 시각으로(`watchClock`: 방장 시각 − 받은 순간의 최댓값). 중간에 들어오면 다음 서브부터(점수는 `serveReady.score`로 맞춤).
- **관중석 채널** `pingpong-watch-XXXX`(`net.js joinWatch`, presence + broadcast): 관전자는 `{id, nick, at, team, look, title, titleX}` track, 선수는 **듣기만**(관중 수·응원). 방마다 16명까지(`WATCH_MAX`).
- **응원** `{k:'cheer', id, c}`(`CHEERS` 키만, `Object.hasOwn`): 👏 박수 / 👍 나이스! / 😮 우와! / 🔥 와아아! / 📣 (응원 팀 선수) 화이팅!. **한 사람 2초에 한 번**(보내는 쪽 잠금 + 받는 쪽 무시), 명단에 없는 id 무시. **채팅 없음.** 응원 팀(🧡💙)은 다시 누르면 취소. 코드 `ui/cheer.js`.
- **소리** `audio.js playCrowd`(박수·'와아'·화이팅, 관중 수만큼 크게): 랠리 중 0.12, 그 밖 0.6. 점수 나면 `crowdRoar`(관중이 있을 때만). 찬스볼 신호음·타구음을 가리지 않게.
- **관중석 캐릭터** `src/crowd.js`(`world.crowd`): 본인 꾸민 몸 + 장착한 탁구채(몸 옆) + 칭호·이름(0.8배). 응원 팀은 발밑 빛 고리. 탁구대 옆 −x쪽 두 줄 13자리, **12명까지**(`CROWD_MAX`, 넘으면 '+N'), 자리는 명단 순서대로 응원 팀 쪽 빈자리(모든 화면 같은 자리). 응원하면 폴짝 + 말풍선 2.2초. 몰입 연출 때 관중도 같이 어두워짐(`crowd.setDim` — 반사·반짝임까지). 그림자 없음.
  - **배경마다 관중 줄**: 배경이 `crowd: [앞줄, 뒷줄]`(기본 2.7·3.6)을 주면 `setRows`. 소풍 3.3·4.2 · 해변 4.4·5.3 · 눈 오는 밤 4.0·4.9 · 교육장·주차장 1.9·2.65. **새 배경을 만들면 관중 12명 세워서 겹치는지 확인.**
- **🪑 관중석에 앉기**(거품 안): 관중석 내 자리 눈높이 1.2m 1인칭, 고개는 공을 따라 돎(`scene.js updateSeatCamera`, `crowd.mySpot()`), 내 화면에서만 내 캐릭터 숨김. 세로 화면은 화각 최대 100°.
- 선수 화면: 점수판 아래 '👀 관중 N명'(`#crowd-pill`). 관중석 캐릭터는 선수 카메라 왼쪽 가장자리에 작게.
- `game.js spectator`: 입력 없음, `mySlot = -1`(모두 불투명, 1대1도 이름표). 카메라 `view` = `'free'`(거품 걷기) · `'me'`(관중석).
- 이어 보기 때 같은 방이면 관중석 채널을 그대로 둠(`crowdKeep`), 명단에서 빠지면 3초마다 다시 track(`heal`).
