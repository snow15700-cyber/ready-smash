# 상점·꾸미기: 뽑기 · 탁구채 · 몸 · 머리 · 얼굴 · 세트

> **지금 모습만**(11/27 정리). 탁구공 `balls.md` · 탁구대 `tables.md` · 배경 `arenas.md`. 아래는 사용자 확정.
> **꾸미기는 보기만 다름**(판정·네트워크 메시지 그대로).

## 1. 공통 규칙
- 설계는 기획서 4장. 카테고리: 탁구채 · 머리 · 얼굴 · 몸 · 탁구공 · 탁구대 · 배경 · 궤적(아직).
- **배경·탁구대·탁구공은 방장 것**으로 통일, 궤적은 친 사람 것, 탁구채·머리·얼굴·몸은 각자.
- 로그인만 상점 이용(손님 불가), 되팔기 없음. 칭호는 업적으로만(`accounts.md`).
- **뽑기(중복 가능) + 비싸게 직접 구매**: 통 2개(캐릭터 / 경기장), 1회 100 · 10회 900, 일반 70 / 고급 25 / 전설 5%, 천장 40, 직접 구매 500 / 1,500 / 5,000, 중복은 조각.
- **무료 뽑기 50회**(`25_free_pulls.sql`, 선수 `free_pulls`, 기한 없음): 남아 있으면 코인 대신 무료(캐릭터·경기장 **합쳐서** 50). 광장 금빛 배너 `src/ui/freeGacha.js`('남은 N회 · 캐릭터·경기장 합쳐서', 다 쓰면 사라짐) + 뽑기 탭 '🎁 무료'.
- 서버 `06_shop.sql`: 표 `pingpong_items`(id·pool·cat·grade·on_sale)·`pingpong_inventory`, 선수 `pieces`·`pity_char`·`pity_arena`·`equip`(jsonb). `pingpong_shop`·`gacha(pool, 1|10)`·`buy(item, 'coins'|'pieces')`·`equip(cat, item|null)`. 기본 아이템(`DEFAULTS`)은 표에 없고 장착 해제 = 기본.
- **아이템 목록은 두 곳**: `src/items.js`(`GRADES`·`CATS`·`POOLS`, 이름·모양)와 SQL insert(새 파일로 insert만 해도 됨). **추가·수정하면 `npm run thumbs`**(목록 그림 `src/thumbs/<id>.webp`, id만: `npm run thumbs -- paddle_duck`).
- 입히기: `items.applyLook(char, equip)`(바뀐 게 없으면 아무것도 안 함) → `setPaddleModel`·`setOutfit`·`setHat`·`setFace`. 경기에서는 presence `look`을 모아 `Game`의 `looks[side][slot]`.

## 2. 꾸미기 화면
- 광장 👕 옷가게·🛒 뽑기방 → 한 화면 `#dress`(뽑기 탭 / 옷장 탭, `ui/dress.js`). 창 뒤에 광장이 그대로, **광장의 내 캐릭터가 카메라 쪽으로 돌아서서** 입어 본 모습이 바로 보임(`plaza.md` 7장). 얼굴 탭은 정면 가까이.
- 옷장 칩 줄 [탁구채·머리·얼굴·몸·…]. 사기는 두 번 눌러야 삼. 크게 보기 카드에 그 아이템이 든 세트 안내.
- **뽑기 연출**(`src/gachaShow.js`·`gachaShow.css`, 시안 `gacha.html`): 광장 뽑기방 앞 작은 기계에서 캡슐이 굴러 나온 뒤(`plaza.md` 7장 ⓒ) **탁구공 두드려 깨기**.
  - 1회 = 3번 톡(금 → 고급 이상 보라 → 전설은 어두워지며 금빛 → 팡). 10회 = 공 10개, 고급 보라·전설 금빛으로 미리 바뀜, **'모두 깨기'는 금빛 공만 남김**.
  - 전설 = 하얀 섬광 → 0.55초 고요 → 빛기둥·금가루 속에서 아이템이 돌며 내려옴 → 그 아이템 소리 → **폭죽·색종이·함성**. **건너뛰기 없음.** 결과는 서버가 먼저 정하고 화면은 연출만(천장 게이지도 끝난 뒤 바뀜). 소리 `audio.js playGacha`. 연출 중엔 3D를 안 그림(`body.gacha-on`). 점검 `window.__gachaTest.finishNow()`.

## 3. 탁구채
- 일반: 색 5(파랑·초록·노랑·검정·분홍) + 무늬 4(줄무늬·물방울·하트·번개) / 고급: 황금·네온 + 개그 15(식빵·바게트·도넛·피자·수박·와플·고등어·밥주걱·삼선 슬리퍼·파리채·태극 부채·수세미·탁구 교재·칠판지우개·도마) / **전설 7**: 프라이팬·통기타·키보드·마우스·스마트폰·고무 오리·뿅망치.
- 모델 `items.js PADDLE_MODELS`(판 가운데 = 원점, 면 ±z, +z가 내 쪽, 손잡이 −y). 부품은 반투명이어도 depthWrite.
- **친 사람의 탁구채 소리**(ASMR): 빵류 '푸석'(`bread`) · 수박 과육(`melon`) · 고등어 '철썩'(`fish`) · 밥주걱·슬리퍼·파리채·부채 플라스틱(`plastic`) · 수세미·칠판지우개 약한 푸석(`sponge`) · 나머지 기본. 전설 전용: 프라이팬 '댕~' · 기타 G→Em→C→D 화음 차례로 · 키보드 '타닥' · 마우스 '딸깍'(퍼펙트 더블클릭) · 스마트폰 '톡'+알림음 · 오리 '꽥' · 뿅망치 '뿅'. `audio.playHit(grade, pos, when, skin)`의 `HIT_SKINS`, 음량 `SKIN_GAIN`.
- **전설 느낌**: 정교한 모양(뒷면도 꾸밈 — 상대는 뒷면을 봄) + `legendAura`(후광·반짝이) + 스스로 움직임(`userData.tick`) + **칠 때 효과** `src/fx.js HITS`(기름·불꽃 / 음표 / 키캡·ㅋㅋㅋ / 클릭 물결 / 하트·좋아요 / 비눗방울 / 별·'뿅!', 등급이 높을수록 많이) + 탁구채 반응(`userData.hit()`). 효과 메시는 `userData.fxKeep`(투명도·그림자 제외).
- 낚시에서 1%로 전설 탁구채가 걸림(`fishing.md` 5장).

## 5. 머리 · 얼굴
- **머리와 얼굴은 따로 칸**(같이 입기 가능), 기본 얼굴 = 얼굴 없음. **얼굴은 얼굴에 직접 그리는 것만**(눈·표정·볼·콧수염 — 안경 같은 물건 X).
- **경기 중 내 머리 아이템만 더 투명**(머리 부품 × `HAT_FADE` 0.4, 머리 효과 × `hatFxK` 0.08). 크기 제한 없음.
- 얼굴을 덮는 것(병아리·곰 인형 머리·기사 투구·영웅 가면)과 같이 입으면 얼굴 숨김(`hideFace`).
- **머리 28**(`src/hats.js HATS`): 일반 8 = 빨간 헤어밴드·야구 모자·털 비니·새싹·고양이 귀·파티 고깔·수건 양머리·리본 머리띠 / 고급 15 = 토끼 귀·요리사 모자·바가지 머리·갓·안전모·개구리 모자·밀짚모자·머리 위 귤·게이밍 헤드셋·합격 머리띠·등산 모자·꽃무늬 두건·나이트캡·기사 투구·영웅 가면 / 전설 5 = 왕관·천사 고리·작은 구름·불꽃 머리·곰 인형 머리. 모든 모자 앞 가장자리는 눈썹 위(얼굴 자리 확보).
- **얼굴 16**(`src/faces.js FACE_LIST`): 일반 5 = 점 눈·부릅뜬 눈·졸린 눈·웃는 눈·윙크 / 고급 8 = 초롱초롱·하트·별·빙글빙글·눈물 그렁·땀 삐질·콧수염·발그레 볼(깜빡임 등) / 전설 3 = 표정 바뀌는 얼굴·레이저 눈·불타는 눈. 머리 앞 구 조각에 512px 그림(`SPAN` 2.6라디안 — 줄이면 얼굴이 **작아짐**, 상대 테이블에서 보이게 크게).
- **경기 반응** `char.react(kind, n)`: 'perfect'·'score'·'miss'·'smash'·'rally'(n)·'end' — `game.js`의 shot·point에서. 전설 머리·얼굴이 반응(왕관 빛·구름 번개·불꽃 커짐·레이저 빔 등).
- 서버 `23_heads_faces.sql`(insert만, 장착은 `pingpong_equip` cat 'head'·'face'). 시안 `hats.html?id=cap&face=heart&body=chick`, 디버그 `window.__hats`.

## 6. 세트 보너스 (`src/sets.js` = SQL `24_sets.sql` `pingpong__set_of`)
- **머리 + 몸 = 세트**, 세 번째(얼굴 또는 탁구채)까지 = **완전 세트(보너스 2배 + 칭호 하나 더)**. 입는 순간 칭호(`set_<id>` ★ · `setfull_<id>` ★★).
- 11개(코인은 그 판 코인 합에, 올림): 국가대표(헤어밴드+유니폼+부릅뜬 눈)·원탁의 기사(투구+갑옷+도마)·동네 히어로(가면+망토+뿅망치) = 이긴 판 +15% · 셰프(요리사 모자+앞치마+프라이팬) = 퍼펙트 3연속 나온 판 +25% · 수험생(합격 머리띠+롱패딩+탁구 교재) = 랠리 10 넘긴 판 +15% · 안전제일(안전모+형광 조끼+땀 삐질) = 진 판 +8 · 등산왕(등산 모자+등산복+콧수염) = 연승 보너스 때 +15 · 휴가 중(밀짚모자+하와이안+웃는 눈) = 쉬는 시간 +50% → +75% · 동네 할매(꽃무늬 두건+몸빼+밥주걱) = 첫 접속 +15 · 꿀잠(나이트캡+별 잠옷+졸린 눈) = 혼자 하기 +15% · 곰돌이(곰 머리+곰 인형탈+고무 오리) = 미션 코인 +15%.
- 세트 보너스 다음에 쉬는 시간 보너스(세트 포함 합에). 정산 함수를 고칠 땐 24 정의에서 시작(`accounts.md` 4장).
