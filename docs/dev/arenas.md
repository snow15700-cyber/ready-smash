# 배경(경기장)

> CLAUDE.md에서 옮겨 온 상세 기록. 작업할 때 필요한 부분만 읽는다. 새로 정해진 것도 여기에 적는다.

## 배경(경기장 뽑기) (사용자 확정 — 고급 5종 상점 연결, main 배포됨 / 일반 3종 test)
- 목록·등급·장면은 기획서 4장 '배경 목록'. 일반 4(체육관 기본·교실·교육장·지하 주차장) · **고급 5(출근길·퇴근길·소풍길·해변·빵집) — 먼저 상점에 넣음** · 전설 3(우주·깊은 바닷속·**눈 오는 밤**).
- **눈 오는 밤은 전설로 올림(사용자 확정)**, 시안 코드는 저장만 하고 상점엔 안 넣음. 나중에 '더 어두운 밤하늘·별' + 전설급 추가 연출(기획서 4장 후보 목록에서 사용자가 고름)로 마저 만든다.
- **울림(잔향)은 배경마다 바꾸지 않는다**(사용자가 나중에 정함).
- **출근길 시안 (main 배포됨)**: `src/arenas.js`의 `buildCommute`. 지금은 주소에 `?bg=commute`를 붙여야 보인다(상점 연결 전). `scene.js`가 `buildArena`로 체육관 대신 짓고 하늘색·안개·조명·`camera.far`를 바꾸며, `world.render()`가 매 프레임 `arena.tick(t, dt, 공 위치, 튐)`. 몰입 연출은 배경 재질 전체를 어둡게(`userData.noFocus`는 제외: 빛 번짐·비).
  - 배치: 넓은 인도 위 탁구대, 옆으로 4차선 도로(0·1차선 한 방향, 2·3차선 반대, 차 12대가 ±150m를 돌고 돎, 09시 게임 차 5종 0.78배), 양쪽 빌딩 숲, 신호등·횡단보도 2곳, 가로등, 빗줄기, 도로 건너편 '㈜ 정시상사' 본사(9시 시계). 통째로 반 바퀴 돌려서(root.rotation.y = π) 로비 카메라에서도 도로가 보인다 → A팀은 도로가 왼쪽, B팀은 오른쪽.
  - 반려동물(사용자 확정: 웰시코기·치즈냥): 탁구대와 도로 사이 벤치. 치즈냥은 벤치 위 식빵 자세(가끔 눈 뜸, 공이 튀면 깜짝), 웰시코기는 벤치 앞에 앉아 고개로 공을 따라감. 09시 게임의 툰 셰이딩·외곽선 그대로.
- **고급 5종 시안 (main 배포됨)**: 주소 `?bg=evening|picnic|beach|snow|bakery`. 파일마다 하나씩 `src/arena-<id>.js`, 공통 도구 `arena-kit.js`(정해진 난수 `seeded`, `skyDome` 하늘, `makeDrift` 떨어지는 알갱이 — `px`를 주면 거리와 상관없이 같은 크기라 카메라 앞에서 공처럼 커지지 않음, `petYaw`, `textTex`·`clockTex`, `makeFacade`), 차 `arena-cars.js`, 반려동물 6종 `arena-pets.js`(09시 게임 그대로, `update(t, dt, yaw, j)`).
  - 퇴근길 = 사내 탁구장: -x 통유리 창(멀리언 그림자가 바닥에 길게, `light.shadow` 9) 너머 노을 해·빛기둥·은행나무·불 켜진 빌딩·차. 앞벽 화이트보드·17:58 시계·비상구, 뒷벽 사원증 걸이·정수기, 오른쪽 벽 게시판·책장. 반려동물 **햄스터(찻잔, 09시에서 '퇴근길 무한모드' 펫) + 앵무새(횃대)**.
  - 소풍길 = 강가 잔디밭: -x 강(물결 흐름)·모래 둑, +x 시골길(차)·'공항 4.8km' 이정표, 빙 둘러 눈 덮인 산, 숲, 꽃·풀(InstancedMesh), 양 팀 머리 위 삼각 깃발 줄(펄럭), 돗자리·바구니·김밥 도시락, 비행기가 26초마다 A팀 앞/B팀 앞 하늘을 번갈아(비행운), 구름·꽃잎·나비. 반려동물 **토끼 + 거북이**.
  - 해변: -x 바다(꼭짓점 물결 + 거품 두 겹 + 물마루), 부표·돛단배·먼 섬, 파라솔·선베드·비치볼(가만히, 사용자 확정)·서핑보드·모래성, 야자수(잎이 촘촘한 잎줄기 3층, 야자수마다 색별로 한 덩어리 `mergeGeometries`), A팀 끝 안전요원 망루, B팀 끝 해변 매점, 갈매기.
  - 눈 오는 밤: 별·달 밤하늘, 공이 눈에 안 묻히게 어두운 돌바닥 광장, 불 켜진 집(굴뚝 연기), 소나무, A팀 끝 큰 트리(전구 반짝·별), B팀 끝 눈사람·'메리 크리스마스' 간판, 양 팀 머리 위 전구 줄, 가로등(가까운 둘은 PointLight).
  - 빵집: A팀 벽 벽돌 오븐(불꽃 일렁임 + PointLight)·칠판 메뉴판·빵 랙(김), B팀 벽 유리 진열장·계산대·OPEN 문·'스매시 베이커리', 왼쪽 빵 선반, 오른쪽 창가 카페 자리(커피 김).
  - 성능(최적화 ④ 완료, main 배포됨): `src/arena-bake.js`의 `bakeArena`를 `buildArena`가 자동으로 부른다. 배경의 tick을 미리 60초어치 돌려(0.2초 간격, 비교는 0.4초마다) 위치·보이기·재질·꼭짓점이 바뀌는 물건을 찾고, 나머지 메시를 재질별로 합친다. 색만 다른 재질은 꼭짓점 색으로 옮겨 하나로(몰입 연출 어둡게 하기도 그대로 됨), 여러 재질 메시(빌딩)는 면 묶음별로 떼어 합침, 움직이는 물건(차·반려동물) 안의 부품은 그 물건 안에서 합침, 반투명·Sprite·Points·거울 뒤집힘은 그대로. 멀리 떨어진 것은 60m 구역별로 따로(화면 밖은 안 그리게).
    - 그리기 호출(로비 화면): 출근길 544→217, 퇴근길 640→228, 소풍길 406→172, 해변 164→115, 눈 오는 밤 611→136, 빵집 480→98 (체육관 88).
    - 합치는 시간은 처음 한 번 약 0.1~0.5초(같은 배경을 다시 고르면 찾은 결과를 다시 써서 더 빠름). 해변 바다의 매 프레임 `computeVertexNormals`는 flatShading이라 필요 없어 뺌.
    - 비교용: 주소 `?nobake=1`(합치기 끔). tick이 아주 드물게(60초보다 길게) 움직이는 물건을 새로 만들면 그 물건에 `userData.dyn = true`(또는 합치면 안 되는 것에 `userData.noBake = true`).
    - 첫 로딩(최적화 ⑤): 배경 코드(`arenas.js`와 arena-*.js)는 처음에 안 받고, 체육관이 아닌 배경이 필요할 때(또는 시작 4초 뒤 쉬는 시간에) `import()`로 받는다. `scene.js`의 `setArena`는 받는 중이거나 새 배경의 셰이더를 `renderer.compileAsync`로 준비하는 동안 지금 배경을 그대로 보여 주고, 준비되면 바꿔 끼운다(`pending`·`swapArena`). 그래서 `setArena`를 불러도 `arenaId`가 바로 안 바뀔 수 있다.
    - 프레임 측정: 주소 `?fps=1` → 화면 위 가운데에 초당 프레임·가장 느린 프레임·그리기 횟수·삼각형·합친 개수(`main.js`의 `perf`).
- **상점 연결 (main 배포됨)**: `supabase/15_backgrounds.sql`(insert만, 사용자가 실행). `items.js`에 `bg_gym`(기본, DEFAULTS.bg)·`bg_commute|evening|picnic|beach|bakery`(고급, `arena` 필드), `CATS.bg.ready`, `arenaOf(look)`. 목록 그림은 `public/arenas/<arena>.jpg`(경기 화면 사진 320×180, `swatch`의 `.sw.img.bg`). **경기장 뽑기는 잠시 닫음(사용자 확정)**: 뽑기 통은 '일반' 아이템이 있어야 열린다 — 화면 `items.js`의 `poolOpen`, 서버 `supabase/16_gacha_open.sql`(`pingpong_gacha`가 `closed` 반환), 로컬 가짜 서버도 같음. 일반 아이템을 넣으면 자동으로 열림. 닫혀 있어도 뽑기 탭에 '🔒 잠시 닫혀 있어요' + 들어 있는 아이템 목록(`.pool-peek`, 누르면 '크게 보기'), 직접 구매·조각 교환은 열려 있다.
  - `world.setArena(id)`(scene.js): 체육관도 배경 하나(`gymArena`). 옛 배경은 `disposeArena`로 내림, 몰입 연출 색을 되돌린 뒤 교체. 주소 `?bg=`가 있으면 그것으로 고정(시안 보기).
  - 어떤 배경을 보이나(`main.js` 루프 끝): **방(대기실·경기) = 방장 presence `look.bg`**, 로비·꾸미기 = 내 장착(입어 보는 중이면 그것), 혼자 하기 = 내 장착. 대기실 오른쪽 위 알약 `#room-bg`('🏟️ 해변 · 방장 배경').
  - 디버그 훅 `window.__smash.shop`(testCoins·gacha·equipItem·myEquip, 로컬 가짜 서버 테스트용).
