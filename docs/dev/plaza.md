## 0. 대원칙 — 선수 부담 0 (사용자 확정)

- **Supabase presence 주의**: 명단 정보(`track`)를 짧은 시간에 여러 번 고치면(약 12초 안 6번) 채널이 끊긴다 → `net.js lobbySupabase`가 **track은 최소 4초 간격**(`TRACK_MIN`). 그래서 명단에는 이름·칭호·꾸미기·들어온 시각·휴대폰만, **걷기·자리·준비·경기 코드·연승은 메시지 `{k:'st', id, w, seat, rdy, code, st, pid}`**(바뀔 때만, 0.25초에 한 번까지). 새 사람이 들어오면 모두 내 상태를 한 번 더(0.3~0.8초 뒤), 15초마다도 한 번 더. 명단에서 잠깐 빠진 사람 상태는 2분 뒤에 버림.

## 1. 기본 조작·화면 (사용자 확정)
- **3인칭 카메라**가 내 뒤를 따라옴(걸으면 걷는 쪽으로 천천히 돎) + 오른쪽 버튼 끌기로 돌리기 + 휠로 3.2~15m(휴대폰은 한 손가락 끌기·두 손가락). 건물·본관 기둥 안으로는 안 들어감(`camBlocks`).
- **걷기는 바닥 클릭(탭)만**, 키보드 없음. 5m/s. 주황 원 표시(그 자리 바닥 높이 + 0.03). 길이 막히면 모서리를 돌아감(`plaza.js planWalk`·`clipWalk`), 높이가 다른 곳(데크·계단·선착장)은 `heightAt`·`groundHit`.
- 내 캐릭터 = 꾸민 몸 + 탁구채 + 머리 위 칭호·이름. 받는 쪽은 받은 길을 따라 그리고, 바뀌면 부드럽게 붙음(3m 넘게 어긋나면 바로).
- **광장 최대 40명**(들어온 시각 → id 순, 41번째부터 '광장이 꽉 찼어요' → 혼자 광장, 30초 뒤 다시). 먼 사람(16m+)은 이름표 생략, 24m+는 옷 효과 멈춤, 그림자는 발밑 동그라미.
- 채널에 붙는 때: 광장·꾸미기·랭킹 화면. 경기·로그인 화면이면 안 붙음. 혼자 하기(김제빵) 중엔 붙은 채 그리기만 쉼.
- **휴대폰도 광장에**: 탭으로 걷기, 김제빵·관전·채팅·낚시. 사람 대결 자리는 못 섬('🔒 사람 대결은 PC에서만').
- 미션 카드·쉬는 시간 알약·내 정보·무료 뽑기는 화면에 그대로 뜬다(`plaza-on`).
- 파일: `src/arena-plaza.js`(광장 배경·자리 `PLAZA`: tables·kim·blocks·spots·stairs·heightAt) · `src/plaza.js`(3D 뷰: 캐릭터·걷기·카메라·클릭 `pick`·`addPicker`) · `src/ui/plaza.js`(광장 채널·채팅·가게·자리·화면 흐름, `plazaFrame`) · `src/campusLayout.js`(모든 자리 한곳) · `src/campusMock.js buildCampus`(시안 `campus.html`과 실제 광장이 같은 코드).

## 2. 정해진 채팅 (사용자 확정)
- 자유 입력 없음. **정해진 문구 10개**(`PHRASES`)를 골라 머리 위 말풍선 3초. 한 사람 2초에 한 번. 경기 중 선수 화면엔 안 보임.

## 3. 탁구대에 서서 경기 (사용자 확정)
- 탁구대 4대(11/28 구역 나누기, test): 사람 대결 **1번 (−14, 15) · 2번 (14, 15) · 3번 (−7, 28.5)**(분수 남쪽 경기 구역) + **김제빵 탁구대 (−13.2, 7.2, 상점 골목 남쪽 끝 · 빵집 옆)**. 처음 서는 곳 (0, 10.5). 불꽃 원(6m, 6장)끼리 안 겹치게(1·3번 사이가 가장 가까움 15.2m → 원 사이 3.2m), 원 안엔 건물·장식 없음, **3번 원은 낚시터 서쪽 계단 길(x 0.5~3.7)에 안 닿게**(7.5m 떨어짐)(사용자 요청 — 낚시하러 가다 관전으로 바뀌지 않게). 탁구대 긴 쪽이 x, A팀 = 서쪽.
- **자리 4칸**(양쪽 2칸씩, 탁구대 끝에서 0.75m, 바닥 주황 A·파랑 B 동그라미). 칸을 누르면 걸어가서 섬(누른 순간 자리를 잡음), 다른 곳을 누르면 내려옴. 탁구대를 누르면 사람이 적은 쪽 가까운 빈칸으로(경기 중이면 관전 원 안내).
- **같은 칸은 먼저 누른 사람**: 명단 상태 `seat: {t, s, at}` → `at` → id 순, 모든 PC가 같은 규칙(늦은 사람은 스스로 내려옴). **방장 = 그 탁구대에서 `at`이 가장 이른 사람**(나가면 다음 사람).
- **시작**: 양쪽 1명씩 = 1대1, 2명씩 = 2대2. 모두 '✋ 준비' + 0.4초 그대로면 각 PC가 경기 채널 `pingpong-room-{방장 code}`로(`room.js enterTable`) → 방장이 'go' → **방장 배경**으로 VS 소개 → 경기. 9초 안에 못 시작하면 '상대와 연결하지 못했어요' → 광장 자리로.
- **끝나면**: 결과 띠 2.8초 뒤 광장으로 → 그 탁구대 자리에 그대로 서서 자리 판에 결과·코인 + **'🔁 한 판 더'**(= 준비, 채널 코드는 매 판 새로). 상대가 나가면 '○○님이 나가서 경기가 끝났어요'.
- **자리 비움**: 서서 1분 동안 아무것도 안 하면 내려옴(마지막 15초 '⏰ N초 뒤 자리 비움'). 경기 중·입장 중엔 안 셈.
- **자리 판** `#pz-table`(왼쪽 아래, 휴대폰은 가운데 아래): 'N번 탁구대 · 1대1 · 👑 내가 방장(내 배경으로 경기)' · 팀 칸 · 결과·코인 · 준비/한 판 더 · 구해요 · 내려오기.
- 탁구대 위 표지판(카메라를 봄): '빈 탁구대 · 자리를 눌러 서요' / '1대1 · 2명 · 준비 1/2' / '곧 시작해요!' / '경기 중 3 : 2 · 👀 불꽃 원 안으로 들어가면 관전'.
- 1대1 상대 전적은 상대가 서면 미리 불러 둠(`h2hOf`).

## 4. 김제빵
### 4-1. 김제빵 탁구대 (사용자 확정)
- 누구나 **동시에** — 각자 자기 PC에서 혼자 하기(`startAI`, 네트워크 안 씀, 휴대폰도). 보상 그대로.
- 동쪽 끝에 김제빵이 늘 서 있음(`AI_LOOK`: 프라이팬·요리사 모자·앞치마, 3~6초마다 휘두름, 도전자가 있으면 1~1.5초마다).
- 다른 사람 눈: 도전 중인 사람은 안 보이고 표지판 '🤖 김제빵 탁구대 / 🔥 N명 도전 중'(명단에 `kim: true`만, 최대 4초 늦음).
- 시작·끝에 **내 배경으로 물결**(5장, 사용자 확정).

### 4-2. 3명일 때 김제빵 부르기 (사용자 확정)
- 2대2 탁구대에 3명 + '구해요'를 보낸 뒤 **10초** 동안 아무도 안 오면 **방장** 자리 판에 '🤖 김제빵 불러서 2대2'. 누르면 방장 상태 `kc: {t, s, at}` → 모든 PC가 그 칸을 김제빵 자리로. 4.5초 뒤 '준비 완료'.
- **연출**(`src/plazaKim.js`, 사용자 요청 '빵 만들다 뛰어온 느낌'): **빵집 문 앞**(`PLAZA.kimHome`)에서 바게트 들고 뛰어옴(밀가루 폴폴, 먼 탁구대면 더 빨리) → 헉헉 + '빵 굽다 왔어요! 🥖' → 바게트 내려놓고 프라이팬. 경기가 끝나면 '앗, 빵 타겠다! 🔥' 하고 뛰어감.
- **🥖 김제빵 내보내기**(방장): 모두 같은 말 '이번엔 ○○을(를) 만들어 볼까나... 🥐' 하고 돌아감. 빵 목록·재밌는 대사는 `src/breads.js`(`BREADS`·`KIM_FUNNY`, 사용자가 고쳐도 됨).
- 경기: 선수 명단 `{id:'kim', side, slot}`(`match.js KIM_ID`), 방장 PC의 `Match({bots})`가 혼자 하기 AI처럼 침(실수 안 함). 'go'는 사람만 다 들어오면.
- **전적·코인**(SQL `27_kim_match.sql`): 김제빵 판 = **승·패·랭킹·연승에 안 들어감**, 코인은 보통 2대2와 같게(연승 보너스만 없음). 사람 4명이 다 입장한 판은 보통 판. 로컬 가짜 서버도 같은 규칙.

## 5. 모집 알림 · 초대 (사용자 확정)
- **'📣 구해요'**(자리 판): `{k:'call', id, t}` → 다른 사람 화면 위 주황 띠 '🏓 N번 탁구대 2대2, 1명 구해요! [가기]'(8초, [가기] = 그 빈자리로 걸어감). **같은 탁구대 15초에 한 번**(보내는 쪽 잠금 + 받는 쪽도 무시). 그 탁구대 사람·휴대폰·경기 중 선수에겐 안 뜸.
- **콕 집어 초대**: 다른 사람 캐릭터를 누르면 '🏓 N번 탁구대로 초대하기'(내가 빈자리 있는 탁구대에 서 있을 때만) → `{k:'inv', id, to, t}` → '📩 ○○님이 초대했어요! [🏓 수락] [🙏 다음에]'(12초). 같은 사람 15초에 한 번.

## 6. 관전 = 경기장 거품 (사용자 확정)
- 경기 중인 탁구대 둘레 바닥에 **불꽃 고리 마법진**(반지름 6m, 두 겹이 천천히 돎). 거리는 `arena-plaza.js BUBBLE_IN·BUBBLE_OUT`(11/28 사용자 확정 6m·8m — 전에는 7·9m. 지나가다 빨려 들어가지 않게·광장 여유).
- 자리에 안 선 사람이 **6m 안으로 들어오면** 그 경기 채널을 **듣기만** + 관중석 채널 명단에 들어감 → 방장 배경이 지어지면 **물결**(2초)이 퍼지며 광장이 그 경기장으로. **8m 밖으로 나가거나** 경기가 끝나면 거꾸로 물결 → 광장.
- **원 안**: 광장처럼 걸어 다니며 진짜 경기를 봄(방장 탁구대·공 꾸미기·공 소리, `Game` 관전 모드 `view = 'free'`). 원 안 사람끼리만 보이고 채팅 됨. 중간에 들어오면 다음 서브부터.
  - 아래 막대 `#pz-bub`: 'N번 탁구대 · A팀 3 : 2 B팀 · 👀 N명' + **'🪑 관중석에 앉기'**(1인칭, '🚶 일어나기') + 응원 팀(🧡💙)·응원 5가지(2초에 한 번, 머리 위 말풍선).
  - **걸을 수 있는 범위**: 배경을 지을 때 벽까지 재서(`src/arenaWalls.js`) 실내 배경(교실·빵집·교육장·퇴근길)은 벽 앞까지. 벽 밖을 누르면 벽 앞까지 → 광장으로 나간 뒤 계속 걸음. 선수 치는 자리는 못 들어감. **카메라와 나 사이를 가리는 벽·물건은 동그랗게 뚫어 보임**(`bubbleFx.js`).
- **선수 화면**: 원 안 사람은 안 보임, 점수판 아래 '👀 관중 N명'(관중석 채널을 듣기만). 관중석엔 관전자 캐릭터.
- 휴대폰도 똑같이.
- 파일 `ui/plazaBubble.js`(거품 + 선수 물결 공용 `drawWave`) · `bubbleFx.js`(셰이더). **물결**: 광장을 그 탁구대가 원점에 오게 돌려 놓고(`view.setFrame`) 광장 물건은 줄어들며 땅속으로·경기장 물건은 '뿅', 바닥·하늘은 원으로 잘라 바뀜, 앞에 불꽃 띠·불티. 합친 배경에 물건마다 가운데 자리(`piv`)를 꼭짓점에 넣어 셰이더가 하나씩 움직임(느린 PC도 가벼움). 물결 중 그림자는 `sun.shadow.intensity = 0`(끄고 켜면 재질을 다시 만들어 멈춤).

## 7. 화면 전환 — 광장은 사라지지 않는다 (사용자 확정 11/24)
**원칙**: ① 광장은 절대 사라지지 않고 창만 뜬다 ② 카메라는 끊기지 않는다(지금 광장 카메라에서 출발해 날아감) ③ 경기장에 들어가는 방법은 하나 = **불꽃 고리 물결** ④ 네트워크 0.
- **ⓐ 랭킹·꾸미기·뽑기 창**: `plazaShown()`이면 창 뒤에 광장을 계속 그림. 창이 뜨면 걷기·돌리기 끔, 카메라가 `setFocus`로 0.9초 동안 그 자리로(`WIN_CAM`, 가게 안쪽 좌표라 가게를 옮기면 따라감): 랭킹 = 명예의 전당·트로피가 화면 왼쪽 · 꾸미기 = **내 캐릭터가 카메라 쪽으로 돌아서고** 비스듬히 앞에서(얼굴 고르기는 정면 1.85m), 입어 보는 모습은 광장의 내 캐릭터에 그대로 · 뽑기 탭 = 뽑기방(좁은 골목이라 빵집 앞 남동쪽에서 비스듬히 — 마주 보는 옷장에 안 막히게). 창은 오른쪽에서 쑥(휴대폰은 아래), 닫으면 `closeWindow()`. **배경·탁구대·탁구공을 입어 볼 때만** 그 경기장 랠리(`arenaPreview`, 살짝 어두웠다 밝아짐).
- **ⓐ' 로그인 화면 = 광장**: 광장 남쪽 높은 곳에서 천천히 좌우로(`WIN_CAM.login`), 내 캐릭터 숨김, 채널 안 붙음. 로그인하면 내 등 뒤로 날아 내려감. 응답 기다리는 동안(`curScreen` '')도 광장.
- **ⓑ 경기 시작·끝 물결**: VS 소개 첫 1초 '어둠 속 심장 소리'를 **광장 → 방장 경기장 물결**로 바꿈(전체 10.2초 그대로, `introHooks.waveStart`). 카메라는 광장 자리 → VS 첫 자리로 1초. 물결은 프레임마다 조금씩(최대 0.05초) 진행해 멈칫해도 끝까지 보이고, 늦어도 VS 장면(4.4초)에 끝. 끝나면 거꾸로 물결(`roomHooks.onEnd`). 물결 준비(`prepWave`)는 경기 시작 순간에 한 번(미리 하면 더 나빴음).
- **ⓒ 뽑기**: 1회·10회 → 꾸미기 창이 잠깐 숨고 동전 소리 → **뽑기방 문 앞 노란 작은 뽑기 기계** 손잡이가 드르륵 → 캡슐이 굴러 나옴(10회는 셋) → 카메라가 캡슐로 쏙 → 번쩍 → 탁구공 깨기(`openGacha`). 약 1.8초(`GA`), 서버 요청은 동시에. 코인 모자람·움직임 줄이기·배경 입어 보는 중이면 바로.
- **ⓓ 김제빵 혼자 하기**: 김제빵 탁구대 좌표로 광장 → **내 배경** 물결, 카메라는 `aiWaveCam`이 1.1초 동안 이어 줌. 늦어도 4초 안에 끝.
- 옛 로비 장면(`LOBBY_CAM`·`lobbyDemo`)은 이제 꾸미기에서 배경·탁구대·탁구공을 입어 볼 때만 쓰임.
