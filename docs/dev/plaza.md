# 광장 로비 (기획 확정 11/23, ①~⑤ + 경기장 거품 test)

> 기존 메인 메뉴·방 목록·방 코드 입장을 없애고, **걸어 다니는 3D 광장**을 메인 화면으로 만든다.
> 단계마다 멈추고 사용자가 test에서 확인한다. '사용자 확정'은 바꾸기 전에 사용자에게 확인.

## 0. 기본 전제 (사용자 확정)
- **1대1·2대2 선수의 네트워크·핑에 부담을 주면 안 된다.** 광장이 생겨도 경기 중 선수 PC가 보내고 받는 양은 지금과 같아야 한다.
  - 걷기는 **클릭할 때 한 번만** 보낸다(`{from, to, t}`), 걷는 모습은 각자 PC가 계산해서 그린다. 매 프레임 위치 전송 금지.
  - 광장 채널(`pingpong-plaza`, 테스트 배포 `pingpong-test-plaza`)과 경기 채널(지금의 `pingpong-room-XXXX`)을 나눈다.
  - **경기가 시작되면 선수 PC는 광장 채널에서 빠진다**(걷기·채팅·모집 알림을 하나도 안 받음). 경기가 끝나면 다시 붙는다. 경기 중인 탁구대의 상태(누가 치는지·점수)는 지금처럼 방장 1명이 로비 정보(`announceRoom`, 바뀔 때만)로 올린다 — 지금과 같은 양.
  - 관전은 지금처럼 **듣기만**(관전 ①~⑥ 방식 그대로).
  - 광장에서 진짜 공이 날아다니는 경기는 **가까이 간 탁구대 1대만** 받는다. 먼 탁구대는 점수판만(로비 정보로).
  - 시험: 경기 시작 후 20초 동안 선수가 보낸 메시지 수가 광장 인원 0명·10명일 때 같은지 잰다(관전 때와 같은 방식).

## 1. 광장 모양
- **3인칭 시점(GTA 같은)**, 카메라가 내 캐릭터 뒤에서 따라간다. **마우스로 바닥을 클릭하면 그곳으로 걸어간다.** 걸어갈 곳에 작은 표시.
- 내 캐릭터 = 꾸민 몸 + 탁구채 + 머리 위 칭호·이름(관중석 캐릭터 `crowd.js`와 같은 방식).
- 광장 배경은 **'광장' 하나로 고정**(배경 아이템과 상관없음). 가볍게 만든다(`bakeArena`로 합치기).
- **상점·꾸미기·랭킹은 광장 안의 건물(가게)**로 만든다(사용자 확정). 가까이 가서 누르면 지금 화면이 열린다. **너무 멀면 안 됨**: 처음 서는 곳에서 몇 초 안에 닿는 거리, 다 한눈에 보이게.
- **미션은 지금처럼 화면에 띄운다**(사용자 확정, `ui/missions.js`). 쉬는 시간 보너스 알약도 그대로.
- 없애는 것(사용자 확정): **방 코드 입장, 비공개 방(관전 막음 = 비공개)**, 로비 '지금 열린 방' 목록.

## 2. 탁구대 (사용자 확정)
- 처음 **4대**: 사람 대결용 3대(1대1·2대2 둘 다 가능) + **김제빵 탁구대 1대**.
- **사람 대결용이 모두 차면 1대씩 새로 생긴다.** 빈 탁구대가 2대보다 많아지면 1대가 없어진다(경기 중인 탁구대는 절대 안 없어짐).
- **자리 4칸**: 탁구대 양쪽에 2칸씩. 칸을 클릭하면 걸어가서 선다. 1대1 = 양쪽 1명씩, 2대2 = 4칸 다.
  - **처음 선 사람이 그 탁구대의 방장**(지금 방장 역할: 경기 기준 로직 `match.js`를 돌림). 방장이 나가면 다음으로 먼저 선 사람.
  - 두 사람이 같은 칸을 동시에 누르면 **먼저 누른 사람**이 가진다(모든 PC가 같은 규칙으로 판단: 선 시각 → id 순).
  - 시작: 서 있는 사람이 모두 '준비'를 누르면 시작. 2명(양쪽 1명씩)이면 1대1, 4명이면 2대2.
- **자리 비움**: 탁구대에 서서 1분 동안 아무것도 안 하면 자동으로 내려온다.
- **경기가 끝나면** 선수는 그 탁구대 앞에 그대로 서 있고 '🔁 한 판 더' 버튼이 뜬다.
- **배경 아이템 (사용자 확정 = A + C)**:
  - A: 경기가 시작되면 화면이 바뀌며 **그 탁구대 방장(처음 선 사람)의 배경** 경기장으로 들어간다(지금 경기 화면 그대로). 끝나면 광장으로 돌아온다.
  - C: 광장에서는 탁구대에 **장식만** 그 배경 느낌으로: 바닥 깔개·깃발·표지판(예: '🏖️ 해변 경기장'). 방장이 바뀌면 장식도 바뀐다. 가볍게(배경 9종 각각 깔개 색·작은 소품 1~2개 정도).

## 3. 김제빵 탁구대 (사용자 확정)
- 누가 쓰고 있어도 **누구나 동시에** 할 수 있다(각자 자기 PC에서 혼자 하기 = 지금 `ui/ai.js`, 네트워크 안 씀).
- 다른 사람 눈에는 **김제빵 혼자 서 있고 '🔥 N명 도전 중' 표지판**만 보인다(도전 중인 사람 수는 광장 presence에 '김제빵 도전 중'만 올림).
- 혼자 하기 보상(3번에 1코인 등)은 그대로.

## 4. 3명일 때 김제빵이 한 자리 채우기 (사용자 확정 + 연출 추가)
- 2대2 탁구대에 3명이 있고 '1명 부족' 알림을 보냈는데도 아무도 안 오면 **'🤖 김제빵 불러서 2대2'** 버튼.
- **연출(사용자 요청: 빵 만들다가 뛰어온 느낌)**: 광장의 빵집(또는 광장 가장자리)에서 김제빵이 **뛰어온다** — 요리사 모자·앞치마에 밀가루, 한 손에 바게트(또는 오븐 장갑), 뛸 때 밀가루가 폴폴, 도착하면 헉헉 + 말풍선 '빵 굽다 왔어요!' → 바게트를 옆에 두고 탁구채(프라이팬)로 바꿔 든다. 경기가 끝나면 '앗, 빵 타겠다!' 하고 다시 뛰어간다.
- 김제빵 1명 + 사람 3명의 2대2는 방장 PC가 김제빵을 움직인다(김제빵은 방장 PC의 AI). **전적·랭킹엔 안 넣고 코인은 보통 2대2와 똑같이**(8장).

## 5. 모집 알림·초대 (사용자 확정)
- **'1명 부족' 알림**: 탁구대에 선 사람이 누르면 광장 위쪽에 띠: '🏓 2번 탁구대 2대2, 1명 구해요! [가기]'. [가기]를 누르면 자동으로 그 탁구대 빈칸으로 걸어간다.
  - **같은 탁구대 알림은 15초에 한 번**(보내는 쪽 버튼 잠금 + 받는 쪽도 무시).
  - 경기 중인 선수는 안 받는다(광장 채널에서 빠져 있으니까).
- **콕 집어 초대**: 광장의 다른 사람 캐릭터를 누르면 '초대하기'. 받은 사람은 [수락]/[다음에]. 같은 사람에게 15초에 한 번.

## 6. 정해진 채팅 (사용자 확정)
- 자유 입력 없음. **정해진 문구만** 골라서 머리 위 말풍선(약 3초). **한 사람 2초에 한 번.** 경기 중인 선수 화면엔 안 보임.
- 문구(처음 목록, 사용자가 바꿀 수 있음): 🏓 1대1 한판 하실래요? / 👥 2대2 한판 하실래요? / 🙋 저 낄게요! / ⏳ 잠깐만요! / 👏 잘 치시네요! / 😂 ㅋㅋㅋ / 🔁 한 판 더? / 👋 안녕하세요 / 🙏 다음에 해요 / 🔔 곧 쉬는 시간 끝나요!
- 보내는 건 문구 번호만(`{k:'say', id, c}`), 받는 쪽은 목록에 있는 번호만 보여 준다(`Object.hasOwn`).

## 7. 관전 (사용자 확정)
- 광장을 드나드는 누구나 다른 사람 경기를 볼 수 있다.
- 탁구대 **가까이 가면** 광장에서 그 경기가 실시간으로 보인다(그 탁구대 채널 듣기만, 공·캐릭터를 광장 탁구대 위에 그림). 멀어지면 끊고 점수판만.
- 탁구대 옆에서 '👀 관전'을 누르면 지금의 관전 화면(그 경기장 배경, 관중석·응원·'🙂 내 자리' 시점)으로 들어간다. 대기 중인 탁구대 관전(⑥)도 그대로.
- 탁구대 둘레에 서 있는 사람 = 관중(관중석 채널 track). 관중 16명·캐릭터 12명 제한 그대로.

## 8. 정한 것 (사용자 확정 11/23)
- **휴대폰도 광장에 들어온다**: 탭으로 걷기, 김제빵·관전·채팅만. 사람 대결 자리에는 못 섬(지금처럼 PC만, '🔒 PC에서만').
- **카메라**: 자동으로 내 캐릭터 뒤를 따라옴 + 오른쪽 버튼 끌기로 돌리기 + 휠로 가까이/멀리(휴대폰은 두 손가락).
- **걷기는 클릭(탭)만**, 키보드(WASD) 없음.
- **광장 최대 40명**(41번째부터는 '광장이 꽉 찼어요'). 평소엔 10~20명이라 부담은 같고, 많아질 때를 대비해 멀리 있는 사람은 간단히 그린다(이름표·그림자 생략 등). 경기 중 선수는 광장 채널에서 빠져 있으니 인원과 상관없음.
- **김제빵 낀 2대2**: 전적·랭킹엔 안 넣음, **코인은 보통 2대2와 똑같이**(서버가 계산, 김제빵 낀 판임을 서버가 알 수 있게).

## 9. 만드는 순서 (단계마다 멈추고 사용자 테스트)
① 광장 기본: 광장 장면, 클릭해서 걷기, 3인칭 카메라, 다른 사람 보기(광장 채널), 정해진 채팅, 가게 건물 3개(누르면 지금 상점·꾸미기·랭킹 화면). 미션은 화면에 그대로. 이 단계에서는 옛 로비로 가는 버튼을 임시로 남겨 둔다.
② 탁구대에 서서 경기: 사람 대결용 3대, 자리 4칸, 처음 선 사람 = 방장, 준비 → 지금 경기 화면(방장 배경)으로 → 끝나면 광장으로 + '한 판 더'. 자리 비움. **선수 부담 측정.** 여기서 옛 로비·방 목록·방 코드 입장·비공개 방을 없앤다.
③ 김제빵 탁구대: 동시 도전, '🔥 N명 도전 중' 표지판.
④ 광장에서 관전: 가까이 가면 실시간, '👀 관전' → 관전 화면, 탁구대 둘레 관중.
⑤ 모집 알림(15초)·콕 집어 초대 + 3명일 때 김제빵 부르기(뛰어오는 연출).
⑥ 탁구대 늘어나기/줄어들기 + 탁구대 배경 장식(C).

## 10. 구현 메모 — ① 광장 기본 (11/23, test)
- 파일: `src/arena-plaza.js`(광장 배경·가게 자리 `PLAZA`), `src/plaza.js`(3D: 캐릭터·걷기 `posAt`·`clipWalk`·3인칭 카메라·클릭), `src/ui/plaza.js`(광장 채널·채팅·가게 열기·화면 흐름). `scene.js`의 `world.setPlaza(on)`이 광장을 처음 켤 때 한 번 짓고 `bakeArena`로 합쳐 둔다(그리기 약 55회).
- 광장 = **로비 화면 + `plaza-on`**: 메뉴(왼쪽)·랭킹·꾸미기 아이콘만 숨기고, 내 정보·미션·쉬는 시간 알림·무료 뽑기·업데이트·치는 방법은 그대로 위에 뜬다. `state.js`의 `plazaHome`(true = 광장, false = 옛 로비). `show('lobby')`는 지금 자리(광장/옛 로비)로 간다.
- 가게: 북쪽에 상점(x −5.6, 뽑기 탭)·꾸미기(x 0, 옷장)·랭킹(x 5.6). 처음 서는 곳 (0, 2.5)에서 문까지 8~9m(약 2초). 건물을 누르면 문 앞까지 걸어가서 도착하면 화면이 열린다(이미 문 앞이면 바로). 걷는 길에 건물이 있으면 건물 앞에서 멈춘다.
- 걷기 4m/s. 클릭할 때 `{from, to, t}`(t = 보낸 PC의 Date.now, 받는 쪽은 지금보다 미래면 지금으로). 받는 쪽은 그 길을 따라 그리고, 바뀌면 순간 이동 대신 부드럽게 붙는다(3m 넘게 어긋나면 바로).
- 광장 채널: `net.js` `joinPlaza`(관중석과 같은 presence + broadcast). 명단 정보 = `{id, nick, title, titleX, look, at, mob, w}`, 클릭할 때만 고침(0.25초보다 잦으면 마지막 것만). 꾸미기·칭호가 바뀌면 1초 안에 다시 올림.
- 채널에 붙는 때: 광장 모드에서 로비·꾸미기·랭킹 화면일 때만. 경기·대기실·관전·옛 로비·로그인 화면이면 빠진다.
- 40명: 들어온 시각 → id 순으로 41번째부터 '광장이 꽉 찼어요' → 옛 로비(지금은 옛 로비가 있어서). 먼 사람(16m+)은 이름표 생략, 24m+는 움직이는 옷 효과 멈춤, 그림자는 모두 발밑 동그라미(진짜 그림자 안 씀).
- 채팅: `PHRASES`(번호 1~10) — 보내는 건 `{k:'say', id, c}`, 받는 쪽은 `Object.hasOwn` + 광장 명단에 있는 사람만 + 1.8초 안에 또 오면 무시. 말풍선 3초.
- 카메라: 내 뒤에서 따라감(걸을 때 걷는 쪽으로 천천히 돌아감). 오른쪽 버튼 끌기(휴대폰 한 손가락 끌기)로 돌리면 다음 클릭까지 그대로. 휠·두 손가락으로 3.2~15m. 세로 화면은 화각을 넓혀 가게 3개가 다 보이게. 건물 앞면 뒤로는 카메라가 안 들어감. 클릭: 가게 클릭 상자는 앞면보다 1.2m 앞까지(앞 바닥·간판도 가게로)인데 카메라는 앞면 0.4m까지 오므로, **카메라가 상자 안에 있으면 그 가게는 클릭 판정에서 건너뜀**(안 그러면 어디를 눌러도 그 가게가 눌림).
- 옛 로비 버튼(임시): 광장 왼쪽 위 '🏠 옛 로비로', 옛 로비 왼쪽 아래 '🏞️ 광장으로'. ②에서 없앤다.
- 점검: `npm run check`의 '화면: 광장 (탭 두 개)'.

## 13. 고친 것 — 실제 서버에서 서로 안 보이던 문제 (11/24 사용자 제보)
- 증상: 다른 브라우저로 들어오면 서로 다른 광장에 있는 것 같거나, 한쪽만 상대가 보이고, 탁구대에서 준비해도 상대 화면엔 아무것도 안 뜸. 로컬(탭) 점검에선 안 생기고 진짜 Supabase에서만.
- 원인(실제 서버로 잼): **Supabase는 명단 정보(presence `track`)를 짧은 시간에 여러 번 고치면 그 채널을 끊어 버린다** — 약 12초 안에 6번째 track에서 `CLOSED`(0.3초·1초·2.5초 간격 모두 같음, 12초 간격이면 괜찮음). 광장은 걷기·자리·준비마다 track을 해서 몇 번 걷고 나면 내 광장 채널이 끊겨, 나는 남을 못 보거나 남이 나를 못 봤다.
- 고침:
  - `net.js` `lobbySupabase`: track은 **최소 4초 간격**으로 묶어 마지막 정보만 보냄(`TRACK_MIN`). 서버가 다시 이어 주면 다시 올림. 로비(점수)·관중석(응원 팀)도 같이 안전해짐(점수 표지판이 최대 4초 늦을 수 있음).
  - 광장 명단(presence)에는 이름·칭호·꾸미기·들어온 시각·휴대폰만. **걷기·탁구대 자리·준비·경기 채널 코드·연승은 메시지 `{k:'st', id, w, seat, rdy, code, st, pid}`**(바뀔 때만, 0.25초에 한 번까지). 메시지는 들어오기 전 것을 못 받으니 **새 사람이 명단에 들어오면 모두 내 상태를 한 번 더**(0.3~0.8초 뒤, 묶어서), 그리고 15초마다 한 번 더(놓친 것 맞추기).
- 확인(실제 서버, 시험용 채널 이름으로): 두 사람 서로 보임 → 자리 → 준비 → 경기 시작 4번 연속 성공(고치기 전 4번 중 2번 실패), 0.2초마다 20번 걷기 뒤에도 끊기지 않고 마지막 자리 보임, 경기 끝 → 광장 '한 판 더' → 두 번째 판 시작.

- **김제빵 부르기**: 2대2 탁구대에 사람 3명(한쪽 2·한쪽 1)이고 '구해요'를 보낸(또는 같은 탁구대 사람이 보낸) 뒤 **10초** 동안 아무도 안 오면 **방장**의 자리 판에 '🤖 김제빵 불러서 2대2'(그 전엔 'N초 뒤 부를 수 있어요', 방장이 아니면 '방장이 김제빵을 부를 수 있어요'). 누르면 방장 상태에 `kc: {t, s, at}`(빈칸) → 모든 PC가 그 칸을 김제빵 자리로 본다(같은 칸 다른 사람은 '김제빵이 선 자리예요'). 부른 뒤 4.5초(뛰어오는 시간)가 지나야 김제빵 '준비 완료'.

### 지금 왜 끊겨 보이나 (11/24 스크린샷으로 확인)
- **랭킹·옷장·상점을 열면 광장이 통째로 사라지고 옛 로비 장면이 나온다.** `plazaShown()`이 로비 화면일 때만 true → 다른 화면이면 `main.js`가 옛 로비(배경 아이템 경기장 + 두 캐릭터 랠리 `lobbyDemo` + 흔들리는 `LOBBY_CAM`)를 그린다. 광장의 돌바닥·가게·하늘이 한 프레임 만에 체육관(무대 커튼)으로 바뀜.
- 옷장 카메라(`PV`)도 광장 카메라가 아니라 **옛 로비 카메라에서** 출발하고, 입혀 보는 캐릭터도 광장의 '나'가 아니라 랠리하던 캐릭터.
- **경기 시작**: 모두 준비 → 바로 어두운 경기장(VS 소개 ① 심장 소리 1초)으로 툭 바뀜. 광장에서 내가 서 있던 탁구대·자리와 이어지지 않음. 정작 관전자는 불꽃 고리 물결(16·18장)로 매끄럽게 들어가는데 선수만 끊김.
- 경기가 끝나 광장으로 돌아올 때도 툭 바뀜. 김제빵 혼자 하기도 같음.

### 큰 원칙 (제안)
1. **광장은 절대 사라지지 않는다** — 랭킹·옷장·상점은 '광장 위에 뜨는 창'. 뒤에는 늘 광장(흐리게)과 내 캐릭터가 있다. 옛 로비 장면(`LOBBY_CAM`·`lobbyDemo` 랠리)은 광장 뒤로는 안 씀.
2. **카메라는 끊기지 않는다** — 모든 전환은 '지금 광장 카메라 자리'에서 출발해 날아간다(약 0.6~1초, 부드럽게 감속). 돌아올 때는 거꾸로 내 등 뒤 3인칭으로.
3. **경기장에 들어가는 방법은 하나** — 관전자가 쓰는 **불꽃 고리 물결**(사용자 확정 효과)을 선수·김제빵 혼자 하기에도 똑같이. "이 게임에서는 경기장이 이렇게 열린다"는 하나의 약속.
4. **창 여는 모양도 하나** — 유리 창이 그 건물 쪽에서 쑥 커지며 나오고, 닫으면 그 건물 쪽으로 쏙 들어감. 전환 소리도 하나(가벼운 '슉').
5. 네트워크는 0 — 전환은 모두 각자 PC 안에서만(경기 시작은 지금처럼 'go' 하나를 받은 시각 기준). 느린 PC·휴대폰은 짧게(효과 줄임), 경기 시작은 건너뛰기 그대로.

### 화면별 안
- **옷장(꾸미기)**: 가게 앞에 도착하면 카메라가 내 캐릭터 둘레를 돌아 **앞에서 비춤**(옷장 거울 앞에 선 느낌), 오른쪽에서 유리 창. 입혀 보는 캐릭터 = **광장의 내 캐릭터**(머리 위 이름표만 잠깐 숨김). 얼굴 고르기 때 가까이 가는 것(`PV_FRONT`)도 이 캐릭터 기준. 닫으면 카메라가 등 뒤로 돌아오고 바로 걸을 수 있음.
- **상점·뽑기**: 카메라가 **뽑기 기계 유리 공** 쪽으로 다가가고 상점 창이 뜸. 뽑기를 누르면 **기계 손잡이가 돌고 캡슐(탁구공)이 굴러 나오는 것**에서 지금 뽑기 연출(탁구공 깨기, `gachaShow.js`)로 이어짐 → 끝나면 다시 상점 창. (지금은 뽑기 연출이 아무 데서나 화면을 덮음)
- **랭킹**: 카메라가 **시상대·트로피(명예의 전당)**를 올려다보고 랭킹 창. (나중 안: 1~3위 사람의 꾸민 캐릭터가 시상대에 실제로 서 있기 — 서버 랭킹 함수가 꾸미기 정보를 같이 줘야 해서 SQL이 필요함)
- **1대1·2대2 시작** (VS 소개 = 사용자가 만든 연출이라 길이·순서는 확인 필요):
  - ① 모두 준비 → 카메라가 내 등 뒤에서 위로 빠지며 탁구대 전체가 보이게(0.5초)
  - ② 탁구대 둘레에 불꽃 고리가 번쩍 → **물결이 퍼지며 광장 물건이 쏙, 방장 배경이 뿅**(관전자가 보는 것과 같은 효과, 선수들은 자기 자리에 그대로 서 있음 — 광장 탁구대 좌표 ↔ 경기 좌표 90° 돌림은 거품 코드 그대로)
  - ③ 그 카메라 자리에서 VS 소개의 첫 카메라로 이어짐. 지금의 '어둠 속 심장 소리 1초'를 이 물결로 바꾸면 **전체 길이(10.2초)는 그대로**.
- **경기 끝 → 광장**: 결과 창 뒤 '광장으로'(또는 자동) → 거꾸로 물결(경기장 쏙, 광장 뿅) → 카메라가 내 등 뒤로 내려오며 '🔁 한 판 더'. 관전자는 이미 이렇게 나감(18장).
- **김제빵 혼자 하기**: **내 배경으로 물결이 퍼진다**(사용자 확정) + 카메라도 이어서(광장 카메라 → 경기 카메라).
