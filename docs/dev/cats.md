## 기획 (사용자 확정 11/26)
### 기획 14-0. 원칙 (사용자 확정)
- **한 문장으로 설명되는 것만**: "고양이에게 생선을 주면 하트가 오르고, 하트가 오르면 더 친해지고 옷이 생겨요." 설명이 필요한 규칙은 뺌.
- **보기만 하면 아는 귀여운 행동은 많이**(규칙 없음).
- **혼내지 않기**: 며칠 안 와도 하트는 안 줄어듦. 다시 오면 달려와 비비기('보고 싶었어').
- 고양이·옷은 모두 **보기만 다름**(판정·경기 그대로).

### 기획 14-2. 고양이 6마리 (사용자 확정)
치즈 · 고등어(고등어 무늬) · 삼색이 · 턱시도 · 까망이 · **샴**(크림색 몸 + 얼굴·귀·발·꼬리 끝 진한 갈색 + 파란 눈, 새침·우아).
- **모두 늘 선착장에 있음**, 규칙은 모두 같음. 다른 건 생김새·몸짓뿐(먹보는 먹을 때 춤, 샴은 고개 한 번 돌렸다 먹기 등).
- 이름은 고양이마다 정해진 것(이름 짓기 없음).
- 길고양이 배회는 기포처럼 서버 시각으로 정해서 모두에게 같은 자리. **하트는 사람마다 따로.** ♥3부터 따라오는 고양이는 '내 고양이'로 따로 생김(광장에 같은 종류가 여러 마리일 수 있음). 광장엔 **한 번에 한 마리**만 데리고 다님.
- 그림체 = **B 2등신 인형**(11/26 확정, 아래 상태 참고). 시안 `cats.html`.

### 기획 14-3. 먹이 주기
- 고양이를 누르면 '🐟 주기' 하나 → 가방에서 **지금 시세가 가장 싼 생선**을 자동으로 줌(쌀 땐 고양이 밥, 비쌀 땐 횟집이 저절로 생김).
- **아무 생선이나 똑같이 하트**(좋아하는/싫어하는 생선 없음).
- ~~하루 3마리까지~~ → **1시간에 1마리**(사용자 11/26 — 자주자주 들어오게): 먹고 나면 배 보이고 누워 'zzz', 머리 위에 '다음 밥까지 n분'. 하루 몇 번이든 가능.
- 쓰다듬기(누르기) = 골골송·하트 연출만(하트는 안 오름). **남의 고양이도 쓰다듬기 가능** → 주인에게 '○○님이 치즈를 쓰다듬었어요 💕'.
- 진도 어림: 매일 조금씩 하면 한 마리 단짝까지 약 2~3주(숫자는 만들 때 정함). 하트는 서버가 계산.

### 기획 14-4. 하트 단계 · 행동 · 옷 (사용자 확정)
| 하트 | 행동 | 생기는 옷(그 고양이 것) |
|---|---|---|
| ♡0 | 무관심, 근처 어슬렁 | – |
| ♥1 | 낚시하러 오면 꼬리 세우고 다가옴, 다리에 비비기 | 🔔 방울 목걸이 |
| ♥2 | 낚시 옆에 앉아 리듬에 고개 까딱 · Perfect '냥!' · 놓치면 귀 접힘 · 잡으면 물고기 툭툭 | 🎀 리본·스카프 |
| ♥3 | 어디든 따라옴(광장까지) | 🎩 모자 |
| ♥4 | 로그인하면 선착장 쪽에서 꼬리 세우고 뛰어옴 | 🧥 옷(우비·망토 등) |
| ♥5 | 뛰어와서 안기기 / 머리·어깨 위에 올라가기 | ✨ 그 고양이 전용 세트(예: 치즈 모자, 생선 탈) |
- 옷은 **하트로만** 열림(코인으로 못 삼) → 옷이 곧 '얼마나 친한지' 자랑. 6마리 × 5 = 30벌.
- 언제나: 밤에 졸기, 비 오면 다리 사이로 숨기, 고양이끼리 코 인사.
- 처음 단짝(♥5)이 되면 광장 알림 '🐱 ○○님이 샴과 단짝이 됐어요!'.

### 기획 14-5. 탁구할 때 고양이 (사용자 확정)
| 하트 | 행동 |

## 지금 모습 (1~4단계)
### 설계 원칙 (토큰·코드 아끼기)
- **코드는 `src/games/cats/`에만.** 큰 파일(`ui/plaza.js`·`game.js`)은 '고양이에게 알려 주기' 한두 줄만(`catHooks`) → 새 대화가 큰 파일을 통째로 안 읽음. 광장 연결은 `registerAddon`(`cleanup.md` 12번).
- **모형 하나 + 털 무늬 표**: 그림체 **B 2등신 인형**(큰 머리·작은 동그란 몸·큰 까만 눈 + 반짝이·ω 입·볼터치·콩알 발·테두리 — 세로 동공·수염·긴 몸·가는 다리는 징그러워 보여서 안 씀). `models.js makeCat(id)`, 털 무늬·눈 색·먹는 몸짓 = `COATS` 표. 동작은 뼈대 없이 부품을 돌림: sit · nod · stand · walk · loaf(식빵) · belly(벌러덩 zzz) · tap(앞발 툭툭), `userData.fx` { ear 귀 접힘 · hop · tailUp }. 시안 `cats.html`(`?t=2`).
- **네트워크 메시지를 늘리지 않음**: 배회 자리 = 서버 시각 씨앗 계산(전송 0) · 내 고양이 = 내 상태에 `ct: { c, h, o }`만 바뀔 때 · 탁구할 때 = 경기 시작 때 한 번, 반응은 각 PC가 득점 소식으로 · 쓰다듬기 알림 = 광장 채널로 한 번(10초에 한 번까지).
- **규칙 한 파일** `src/games/cats/rules.js`(three 없음): `CAT_IDS`·`CAT_NAME` · 밥 간격 `FEED_GAP_MS` 1시간 · `PER_HEART` 10(생선 1마리 = 1점, ♥5 = 50점, 하루 4~5번 들르면 약 2주) · `heartOf`·`heartProgress` · `OUTFITS`·`canWear` · 배회 `catAt`·`catPath`·`catGround`. SQL·로컬 가짜 서버·점검이 같이 씀.

### 배회 · 밥 주기 (3a)
- **배회** `catAt(id, ms)`: 쉬는 자리 `CAT_SPOTS`(쉼터 방석·앞 판·팔·계단 아래·계단 위 풀밭·횟집 앞) 사이 길(Floyd 가장 짧은 길), 75초 한 칸(걷기 0.85m/s → 쉼 sit·loaf·stand), 45% 제자리 · 20% 쉼터로. 시각 = `marketNow()`(서버 시각) → 모두 같은 자리. y = 바닥 높이(`heightAt`).
- 화면 `plazaCats.js`: 광장에 6마리(0.75배), 누르기 = `plaza.js addPicker` → 말풍선 `#cat-pop`(이름·하트·막대·'🐟 주기' / '😴 배불러요 · n분 뒤' · '🐱 내 고양이', 15초 또는 14m 멀어지면 닫힘). 멀면 옆까지 걸어가서 줌, 먹는 2.6초 까딱 + 🐟·💗, 배부르면 쉴 때 belly zzz(내 화면만).
- 밥 = 가방에서 **지금 시세가 가장 싼 생선**(`market.js cheapestIn` = 서버 시세순 + id순).
- 서버 `37_cats.sql`: 표 `pingpong_cat(player_id, cat_id, pts, fed_at, outfit)` · `pingpong_cat_list(token)` · `pingpong_cat_feed(token, cat)` → ok | wait | no_fish | bad_cat. `account.js catList·catFeed`(`account.cats`).
