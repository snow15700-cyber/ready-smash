# 한 번에 테스트할 목록 (test 브랜치에 있고, 아직 main에 안 합친 것)

> 사용자 요청(11/24): 단계마다 따로 테스트하지 않고 **나중에 한 번에** 한다. Claude는 test에 올릴 때마다 여기에 추가하고, 사용자가 확인하면 ✓.
> 기준: `git log origin/main..origin/test`. **main에 합친 뒤에는 그 항목을 지운다**(내역은 git 기록에).
> 11/27: 그때까지의 항목은 모두 main에 합쳐져서 비움.

## 준비
- 실행할 SQL이 있으면 `docs/dev/sql-to-run.md` 먼저.
- PC 2대(가능하면 4대) + 휴대폰 1대, 같은 교실 와이파이. test 미리보기 주소.

## 테스트할 것
(없음)
