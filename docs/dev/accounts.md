# 계정·전적·랭킹·코인·부정 방지·업적·미션

> **지금 모습만**(11/27 정리). 서버 SQL `01`~`40` 진짜 Supabase에 모두 실행됨. 새 SQL은 `41_...sql`부터(`sql-to-run.md`).
> 서버 규칙을 바꾸면 로컬 가짜 서버(`src/localServer.js`, 브라우저 localStorage `smash-local-db`)도 같은 규칙으로.

## 1. PIN 계정
- 설계는 기획서 5장. 진짜 정보는 Supabase DB, 브라우저에는 로그인 열쇠(`smash-token`, 30일·쓸 때마다 연장)만. 복구 단어 없음, **손님 모드** 있음(presence `guest: true`).
- `01_accounts.sql`: 표 `pingpong_players`·`pingpong_sessions`(RLS로 잠금), 함수 `pingpong_login`·`signup`·`me`·`change_pin`·`logout`(security definer만 anon에). PIN bcrypt, 토큰 sha256. **5번 틀리면 5분 잠금**.
- 화면 `src/account.js`(서버 함수 부르기 `call`) · `ui/login.js`(로그인 `#login`·PIN 바꾸기 `#pin-change`). 같은 브라우저의 탭은 같은 계정, 로컬 테스트에서 탭마다 다른 계정은 `?acct=2`.

## 2. 전적 · 랭킹
- 1대1·2대2 승패·`best_rally`, 상대 전적 표 `pingpong_h2h`(내 쪽 방향만). **각 PC가 자기 결과만** 냄(아래 4장 규칙으로 확인). 경기 중 나가면 기록 없음.
- **패 수는 화면에 안 보임**(사용자 확정): 내 전적·랭킹은 승수만. 승패가 둘 다 보이는 곳은 1대1 상대 전적뿐(서버엔 패도 저장).
- 혼자 하기 최고 기록: 로그인 = 서버가 인정한 친 횟수(`pingpong_ai_rally`), 손님 = 브라우저 `smash-ai-best`.
- **랭킹** `pingpong_ranking('wins'|'rally')`: 로그인 없이, 닉네임·칭호·숫자만, 상위 50, 같은 기록은 공동 등수. 명예의 전당 창 `ui/rank.js showRank`(승수 · 최장 랠리 · 🐟 월척 탭, 1~3위 메달, 내 줄 강조).

## 3. 코인
- 경기 정산은 **서버가 계산**(보너스 횟수는 0~3으로 자름). 참여·승리·퍼펙트 3연속마다 +1·랠리 10마다 +1(AI 제외)·**3·6·9연승 +15**. 하루 첫 접속 +20(`pingpong_daily`, 한국 날짜).
- 혼자 하기: **3번에 1코인**(26), **하루 250코인까지**(32).
- 낚시 코인은 횟집에서 팔 때(하루 1000까지) — `fishing.md` 7장.
- 화면: 경기 끝 광장 자리 판에 결과·코인 내역, 효과음 `playUI('coin')`.

## 4. 부정 방지 (사용자 확정)
- **브라우저가 보낸 숫자는 믿지 않는다.** 경기 번호 `mid`(방장이 'go'에 실음) → 각 PC가 자기 토큰으로 `pingpong_match_join`(시작 30초 안, 쪽별 정원) → 끝나면 결과 → 업적 → 미션 → 사람 업적 순서(`ui/room.js saveResult`). 상대·팀원은 서버가 입장 기록에서 찾음.
- **가장 최근에 입장한 경기만** 결과를 낼 수 있음(아니면 `stale`). 시작 25초 전엔 거절, 한 번만.
- **로그인한 같은 상대**: 하루 1~5판 보통 코인, 6~10판 참여 +10만, 11판째부터 0(승패·상대 전적은 계속).
- **상대 쪽에 로그인한 사람이 없는 경기**(손님 상대 = 혼자 꾸민 가짜와 구별 불가): 승수·패수·연승·승리 업적 X, 코인은 하루 5판까지.
- **공정한 결과**(32, `pingpong_match_result`): 선수마다 처음 보낸 결과를 고정 → 상대 쪽 누군가 같은 승자를 말하면 정산 / 다르게 말하면 `disputed` = 승패·연승·상대 전적·승리 코인·승리 업적·미션 '이김' 없음(참여·퍼펙트·랠리 코인은 그대로) + '⚠️ 서로 이겼다고 해서…' / 아직이면 `wait`(화면이 1.5초마다 다시, '상대 결과 확인 중…') / 내가 말한 지 20초면 내 말대로. 2대2는 한 명이라도 다르면 그 판 승패 없음.
- 혼자 하기 친 횟수는 **1.2초에 1번**까지만 인정(실제로 그보다 빨리 못 침).
- 옛 함수(`record_match`·`finish_match`·`match_finish` 등)는 anon에서 닫힘(14·33). **13·18·19·24·27을 다시 실행하면 옛 함수가 다시 열리니 33도 다시.**
- **경기 결과 규칙을 또 고칠 때는 32의 `pingpong_match_result`에서 시작**, 정산 함수들(`match_finish`·`ai_rally`·`daily`·`__mission_grant`·`achievements`)은 **세트 보너스가 들어간 24 정의에서 시작**(보너스가 빠지지 않게).
- 운영자용 '서로 이겼다' 조회 쿼리는 `13_match_check.sql` 끝.
- 안 하기로 함(사용자): 계정 두 개로 승수 쌓기 막기, 가입 제한, 퍼펙트·랠리 보너스 횟수 더 줄이기.

## 6. 업적 · 칭호 (사용자 확정)
- 목록은 **기획서 11장** + 낚시 7개. 목록은 두 곳: `src/achievements.js`(`ACHS`)와 SQL insert. 보상 ★20 / ★★50 / ★★★150코인.
- **칭호는 하나만** 달고 꾸미기 '🏅 칭호' 탭에서 바꿈. 이름표 = 두 줄(칭호 알약, 남색 `#3d3b5c`). 놀림형 칭호 OK.
- **숨은 업적 없음**: 이름·조건은 다 보이고 칭호 글자만 깨기 전 '칭호 ???'.
- 서버: 표 `pingpong_ach`·`pingpong_ach_got`, 선수 `title`·`ach_n`(누적 숫자 jsonb). `pingpong_achievements`(목록 + 새로 깬 것) · `pingpong_set_title` · `pingpong_ach_match(token, mode, won, stats)` → 누적은 `pingpong__ach_check`, 지급은 `pingpong__ach_grant` · `pingpong_ach_people`(천적·복수·짝꿍) · 뽑기 횟수 트리거 `pingpong_count_gacha` · 출석 `ach_n.days`·`days_run`.
  - 천적 = 같은 상대에게 5연패 → 칭호 「(상대 닉네임) 공포증」(`titleText(id, x)`, presence `titleX`, 랭킹 `title_x`).
- 화면: `game.js trackAch`(판정·방향·타이밍·스매시·찬스볼·서브·점수 흐름) → `achSummary` → `achMatch`. 알림·칭호 `ui/titles.js`.
