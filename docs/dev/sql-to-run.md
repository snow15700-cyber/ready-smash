# Supabase SQL 실행 목록 (사용자가 SQL Editor에서 직접 실행)

모든 파일은 **여러 번 실행해도 괜찮아요**. 이미 실행한 것을 다시 해도 문제없으니, 헷갈리면 아래 순서대로 전부 실행하면 됩니다.
Supabase → SQL Editor → New query → 파일 내용을 통째로 붙여넣기 → Run.
