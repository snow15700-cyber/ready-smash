# 화면 디자인·대기실 무대

> CLAUDE.md에서 옮겨 온 상세 기록. 작업할 때 필요한 부분만 읽는다. 새로 정해진 것도 여기에 적는다.

## 새 디자인: 탁구 색 + 유리 (2026-11-18 사용자 확정, 로비부터 화면별로)
- 예전 '따뜻한 주황 + 파랑 유지'를 **대신한다**. 시안 2개(탁구 색 / 탁구 색 + 유리) 중 사용자가 **'추천 섞기'(탁구 색 + 유리)**를 골랐다.
- 색(탁구용품에서): 빨강 `--tt-red`(러버) = 가장 중요한 버튼, 파랑 `--tt-blue`(탁구대) = 두 번째 버튼, 흰 반투명 유리 `--glass`·`--glass-line` = 패널, 공 주황 `--tt-ball` = 코인 하나만. 글자는 흰색.
- 글꼴: 화면 글자 = **Pretendard**(npm `pretendard`, `main.js`에서 dynamic-subset CSS를 import → 쓰는 글자 묶음만 받음, `--font-ui`). **로고만 Jua**.
- 아이콘: 이모지 대신 **선 아이콘**(인라인 SVG `.ic`, Lucide 모양). 버튼은 아래 두꺼운 그림자 없이 평평 + 누르면 살짝 작아짐.
- 유리는 뒤가 진해야 예쁨 → 로비에서만 3D 화면 색을 빼고 어둡게(`body:has(#lobby:not(.hidden)) #c` filter) + 남색 덮개(`--night-*`). 흐림이 안 되는 브라우저는 진한 남색 패널(`@supports not`).
- 성능: 유리(흐림)는 **메뉴 화면에만**, 경기 중 HUD에는 안 쓴다. 유리 칩 안의 메뉴(⚙️)는 흐림이 안 먹어서 거의 불투명.
- 성능 지킴이 `glassGuard`(main.js): 로비에서 2초씩 재서 두 번 연달아 40fps 아래면 `html.lite-glass`(흐림 끔, 진한 남색 패널), 브라우저에 `smash-lite-glass` 기억. `?glass=0` 항상 끔 / `?glass=1` 항상 켬.
- 공통 테마 클래스 **`.gx`**(style.css '새 디자인 공통'): 화면 div에 붙이면 글꼴·유리 패널·빨강 큰 버튼·유리 버튼·입력칸이 새 디자인으로. 아이콘은 `src/icons.js`의 `ic(name)`(JS) / index.html에는 같은 SVG를 붙여 둠.
- 진행: ① 로비 ✓ ② 로그인·PIN·코드 입장·대기실·치는 방법·업데이트 창 ✓ (둘 다 작업 브랜치에만, test에는 아직 안 올림 — Vercel 하루 한도 때문에 사용자가 쉬자고 함, 스크린샷으로 확인). 대기실은 밝은 경기장 위라 **어두운 유리**, 팀 색 **A = 빨강 / B = 파랑**(경기 HUD는 ⑤에서 맞춤). ③ 랭킹 ✓(밝은 유리 패널, 탭 = 유리 위 흰 알약, 메달 이모지 → 금·은·동 동그라미 `.mdl`, 내 줄 = 빨간 빛 + 흰 테두리, 내 순위 띠 = 진한 유리 + 공 주황 숫자). ④ 꾸미기 ✓(사용자 확정 '추천' 안: 배치 그대로, **3D는 어둡게·흐리게 안 함**(아이템 진짜 색), 패널·크게 보기 = 어두운 유리, 카드 = 반투명 + 위쪽 은은한 빛 + 등급 띠·테두리 빛(희귀 보라·전설 금), 장착 = 흰 테두리 + 빨간 체크, 뽑기 1회 빨강 / 10회 보라 유지, 지갑 코인 = 주황 동그라미·조각 = 퍼즐 아이콘). ⑤ 경기 화면 ✓(사용자 확정 '추천' 안: 흐림 없이 진한 반투명 `--hud-bg`, 글꼴 = 정보 Pretendard / 가슴 뛰는 순간(내 차례·승리·준비하시고 스매시) Jua. **판정(PERFECT·GOOD·BAD·BLOCK·SMASH·헛스윙)·VS·3·2·1은 '빛 글자'로 바꿈(사용자 확정 11/18, 유리 판·유리 글자 안과 비교해 고름)**: Pretendard, VS·숫자는 가는(300) 큰 흰 글자 + 은은한 빛(블러에서 또렷해지며 나타남), 판정은 굵은(700) 글자 위 흰색 → 아래 등급 색(`--g`: 초록·노랑·주황·파랑·빨강) + 등급 색 빛, 점수판 A 빨강·B 파랑 + 듀스 공 주황, 랠리 카드 평소 남색 → 6회부터 공 주황→빨강→분홍→보라, 알림 = 진한 알약 + 공 주황 점, 승리 띠 빨강·패배 남색, 업적 알림 진한 남색 + 금 테두리, VS 소개 이름 카드 팀 색·아이템 알약 진한 반투명). **다섯 화면 모두 끝 — test에 한 번 올려서 사용자 확인 차례.**
- **경기 전 연출 1단계 (test)** — 사용자 요청(11/18): 시작 버튼 ~ 첫 서브 사이 긴장감. `src/ui/intro.js`의 `INTRO` 시간표(초): 0~1 대기실 그대로 + 어두운 막(`.vi-dim`, 대기실은 `#room.leaving`로 못 누르게) + 심장 소리(`playUI('heart')`) → 1~6 VS 소개 5초(상대 1~2.7 → 우리 2.7~4.4 → VS 4.4~6) → 6~9 3·2·1(`#vi-num`, `playUI('count')`, 심장 0.85초 → 0.5초 간격) → 9~9.6 정적 '준비하시고,'(막이 가장 어두움, 심장 멈춤) → 9.6 '스매시!' + `playUI('smash')` + 관중 함성(`playCrowd('roar', …, clap=false)`, 박수는 빼기로 — 사용자 결정) → 10.2 경기. 구간은 `vs-intro`의 class(`dim`·`p1`·`p2`·`p3`·`cd`·`hush`·`go`).
  - **건너뛰기(사용자 결정, 전에 '건너뛰기 없음'을 바꿈)**: 오른쪽 아래 버튼 + 선수 수만큼 빈 원, 누른 사람 수만큼 초록 불. 선수 **모두**가 누르면 정적(9초)으로 넘어감(끝맺음 1.2초는 보여 줌). 메시지 `{k:'skip', from}`을 모든 PC가 각자 세고(`addSkip`), 다음 프레임에 `t0`를 옮긴다. 버튼은 VS 소개~카운트다운 동안만.
  - **② 이 판에 걸린 것 (test)**: VS(4.4초)부터 카운트다운 끝까지 위쪽 가운데 `#vi-stake` 알약 최대 3개, **내 쪽에서 본 것**(PC마다 다름, `stakes()`): 상대 전적(1v1·둘 다 로그인, 대기실이 불러 둔 `room.h2h`: 0판 '첫 대결!' / 지는 중 '복수전!' / 이기는 중 '우세 지키기' / 같음 '이번 판이 승부처') → 상대(팀) 2연승 이상 '연승 저지 찬스!' → 내 2연승 이상 '이기면 N연승' → 쉬는 시간이면 '코인 +50%'. 이름 카드 아래 2연승 이상이면 '🔥N연승 중'. 다른 선수의 연승은 팀 고를 때 `'st'` 메시지에 실려 옴(`streakOf`, 보여 주기만 — 코인·판정과 무관). 코인 숫자·'연승 보너스 코인' 문구는 넣지 않기로(사용자 결정, 같은 상대 하루 판 수 제한을 브라우저가 몰라서 틀릴 수 있음).

## 광장 메뉴 정리 (11/25 사용자 요청 "버튼 배치가 너무 난잡해", test)
- 광장 위에 뜨던 것 전부 조사: 왼쪽 위 알약 3개(광장 인원·날씨·로컬 테스트), 위 가운데 쉬는 시간 띠·모집 알림·받은 초대, 오른쪽 위 내 정보 칩·전적 3칸·오늘의 미션(따로 떠 있는 4장), 오른쪽 아래 큰 금빛 무료 뽑기 배너 + 업데이트 아이콘(혼자 떨어져 있음), 왼쪽 아래 치는 방법·09시 알약, 가운데 아래 말하기 + 조작 안내 글, 상황별 자리 판·사람 누르기·거품 판·알림(toast)·업적 알림.
- 원칙: **자리마다 하는 일을 하나로** — 왼쪽 위 = 광장 상태(알약 하나에 구분선) · 위 가운데 = 알림(한 줄 알약, 쉬는 시간 → 모집 → 초대 차례로) · 오른쪽 위 = **나(이름·코인·⚙ / 전적 / 미션을 유리 카드 한 장)** · 왼쪽 아래 = 안내(치는 방법 · **업데이트** · 09시, 조용한 작은 알약 — 업데이트를 오른쪽 아래에서 옮김) · 가운데 아래 = 말하기 · 오른쪽 아래 = 무료 뽑기(큰 배너 → 한 줄 카드, 반짝임은 그대로).
- 조작 안내 글은 말하기 위 작은 알약으로, **로비에 올 때마다 10초 보이고 사라짐**(자리에 섰을 때·거품 안·말하기 창이 열리면 안 보임).
- 휴대폰: 위 = [👥 N명] … [내 카드: 이름·코인·⚙ + 미션 머리줄], 알림은 내 카드 아래로, 아래 한 줄 = [❓][📢] [💬 말하기] [🎁 숫자 딱지]. 날씨 알약·09시·안내 글은 숨김. **미션은 정한 적이 없으면 휴대폰에서 접힘**(PC는 펼침, 누르면 기억 — `missions.js folded()`).
- 코드: `style.css` 맨 끝 '광장 메뉴 정리'(모두 `.lobby.plaza-on` 안 — 대기실·경기 화면은 그대로), `#btn-updates`는 `.lb-bottom`으로 옮김(`.lb-help.lb-upd`), `#lb-free`에 `data-left`(휴대폰 딱지).

## (예전) 디자인 손보기 — 주황 + 파랑 시절 기록
- 색감은 따뜻한 주황 + 파랑이었다(위 새 디자인으로 바뀌는 중). 예전 변수 `--orange`, `--blue`, `--paper`, `--cream` …은 아직 안 옮긴 화면이 쓴다.
- 순서: ① 로비 → ② 대기실·코드 입장·로그인 → ③ 랭킹 → ④ 상점·옷장 → ⑤ 경기 중 화면(점수판 등). 단계마다 test에서 사용자 확인.
- **① 로비 (main 배포됨)**: 안 A '게임 타이틀형'. 왼쪽 = 제목 + '혼자 하기'(주황) + '친구랑 하기' 묶음(1 대 1 / 2 대 2 파랑, 코드로 입장). 오른쪽 위 = 내 정보 칩(이름·코인·⚙️ 메뉴에 PIN 바꾸기/로그아웃) + 전적. 오른쪽 아래 = 랭킹·상점·옷장 아이콘. 왼쪽 아래 '❓ 치는 방법' → 창(`#howto`). 좁은 화면(760px 미만·높이 560px 미만)은 세로로 쌓기.
  - 배경: 두 캐릭터가 끝없이 랠리(`src/lobbyDemo.js`, 실제 물리 사용). 카메라 `LOBBY_CAM`(메뉴를 피해 탁구대를 오른쪽으로 `shift`). 앞쪽 캐릭터는 내 장착. 팔 동작은 `game.js`의 `armPose`를 같이 쓴다.
  - 배경 소리(사용자 확정): **로비·꾸미기 화면에서만** 작은 타구음·바운드음(친 캐릭터의 탁구채 소리). 크기는 `main.js`의 `LOBBY_QUIET`(0.4) → `audio.setQuiet`(위치 있는 소리만 작게·부드럽게, 경기 중엔 1). 브라우저 규칙상 첫 클릭·키 입력 뒤부터 들린다(`unlockAudio`).
  - 다른 게임 바로가기(사용자 확정): '❓ 치는 방법' 옆 알약 `#lnk-until09` → `"09시까지 출근하세요" 플레이 ↗`, 새 탭으로 https://until09-5zhx.vercel.app/ . 로비에만, 휴대폰에서도 보임(`.lb-bottom`으로 두 버튼 묶음).
  - 처음 온 사람에게 '치는 방법' 창 자동으로 한 번(사용자 확정): 닫으면 브라우저에 `smash-howto-seen` 저장.
- **② 로그인·PIN·코드 입장·대기실 (main 배포됨)**
  - 로그인·PIN 바꾸기: `.screen.left` — 로비처럼 왼쪽에 제목 + 카드, 오른쪽에 랠리 배경.
  - 코드 입장: 4칸 글자 상자(`#code-boxes`, 투명한 `#join-code` 위에 글자를 그림, `renderCodeBoxes`).
  - 대기실: 위에 '← 방 나가기' + 모드·인원 알약, 점선 '방 코드' 표, A팀 | VS | B팀(좁은 화면은 세로). 선수 줄 = 동그란 얼굴(닉네임 첫 글자) + 닉네임 + 꼬리표(N번·👑 방장·손님·나) + ✓ 준비. 빈자리는 점선.
- **③ 랭킹 (main 배포됨)**: 위 '← 로비로' + 제목, 알약 모양 탭(🏓 승수 / 🔥 최장 랠리). 1~3등 = 시상대(가운데 1등·왼쪽 2등·오른쪽 3등, 금·은·동 받침대, 빈 자리는 '?'), 4등부터 목록(동그란 얼굴, 내 줄 강조 + 자동 스크롤), 맨 아래 검은 '내 순위' 띠(손님은 로그인 안내, 순위 밖이면 안내). `ui/rank.js`의 `showRank`.
- **④ 꾸미기 = 상점+옷장 합침 (main 배포됨)**: 안 A '오른쪽 패널형'(사용자 확정). 패널 = '← 로비로'·제목·지갑, 탭 👕 옷장 / 🎁 뽑기 / 🏅 칭호(`dressTab`). '골라 사기' 탭은 옷장과 겹쳐서 없앰(사용자 확정, 없는 아이템은 옷장의 '크게 보기' 카드에서 산다). 카테고리 칩(아이콘, 아직 없는 건 '곧'), 아이템 카드 4열(아래 등급 색 띠, 없는 것 🔒 흐리게, 가격은 카드에 안 씀). 뽑기 탭 = 캐릭터/경기장 작은 탭, 확률 배지, 전설 보장 막대, 1회(주황)·10회(보라, '10% 이득').
  - 왼쪽 아래 '크게 보기' 카드 `#spot`(`renderSpot`): 고른 아이템(`selId`, 없으면 지금 장착) 큰 그림·등급·이름·상태 + 특수 소리가 있는 것만 '🔊 특별한 소리'(소리 이름은 안 씀, 사용자 확정), 버튼 = 장착하기 / 🪙·🧩 사기(두 번 눌러야) / 🔊 소리 듣기(`playHit`). 옷장에서 가진 것 누르면 바로 장착, 없는 건 입어 보기.
  - 미리보기 카메라 `PV`는 랠리 중인 내 캐릭터 등 뒤(좌우로 움직이면 부드럽게 따라감).

'← 나가기' 알약, 아래 안내 알약, 알림 주황 알약. 경기 끝 = 가운데 큰 결과 띠 `#result`(🏆 승리! 주황 / 😢 아쉬워요 남색, 약 2.7초). `ui/hud.js`의 `hud`.

## 대기실에서 서로의 꾸밈 보기 (①②③ main 배포됨)
- 목적(사용자): 꾸밈이 서로 보여서 '나도 저 아이템 갖고 싶다'는 마음이 들게. 단계: ① 대기실 무대 → ② 클릭하면 연습 스윙 + 탁구채 소리(다른 사람에게도 보임) → ③ 경기 시작 전 VS 소개(지금은 약 10초 연출의 일부, 모두 누르면 건너뛰기).
- 사용자 확정: 대기실에서 옷 갈아입기 없음(입장할 때 차림, presence `look`). 아이템 이름은 보여 주고 **등급은 색·빛으로만**(글자 X). → 11/22 사용자 결정: 정보가 너무 많아 **칭호 + 닉네임만**(아이템·세트 이름 알약 `lookPills`는 없앰, 등급은 발밑 빛 고리로만). 팔이 없어서 탁구채는 멀리 띄우지 말고 **몸 옆에 붙여 들기**.
- ① 배치 = 안 B '자리 위에 서기': 아래 넓은 카드(`#room-card`)에 자리 칸 A1 A2 | VS | B1 B2, 칸 바로 위에 그 선수의 3D 캐릭터(정면). 빈자리는 흐린 실루엣 + '빈자리 · 기다리는 중'. 빈 칸 누르면 그 팀으로, 내 칸 누르면 빠지기. 머리 위 HTML 이름표 `#room-labels`(칭호 + 닉네임만 — 아이템 알약은 11/22에 모두 뺌). 발밑 빛 고리 `setGlow`(카드에 가려 거의 안 보임). 결과·코인·상대 전적은 위 가운데 `.room-news`.
- ② 연습 스윙 (main 배포됨): 대기실 3D 부분을 누른 채 위로 밀면 휘두르기(위로 40px 이상 perfect, 12px 이상 good), 그냥 누르면 툭(block). 경기와 같이 누르기 직전 0.15초 ~ 직후 0.12초 움직임(이벤트 `timeStamp` 기준). 내 소리는 그대로, 남의 소리는 그 캐릭터 쪽에서 작게(위치 소리). 0.45초에 한 번까지. 메시지 `{k:'sw', id, g}`. 팀을 안 골랐으면 안내 토스트. 왼쪽 위 안내 알약 `#room-hint`. `ui/stage.js`의 `SWING`·`practiceSwing`·`holdPose`.
- ③ VS 소개 (main 배포됨 — test에서 위 '경기 전 연출'로 늘어남): 'go'를 받은 순간부터 3초(`INTRO`), 1v1·2v2만(혼자 하기 X). 0~1초 상대 팀 앞에서 카메라가 다가감 → 1~2초 우리 팀 → 2~3초 옆에서 크게(우리 팀 왼쪽) + VS 도장(`playUI('rare')`) + 2.4초 '준비하시고, 스매시!'(`playUI('turn')`). 팀이 소개될 때 각자 한 번 휘두르며 그 탁구채 소리. 이름 카드(칭호 + 닉네임만, 아이템 알약은 11/22에 뺌) 상대 오른쪽·우리 왼쪽 `#vs-intro`. 그동안 HUD 숨김(`body.intro`), 클릭 무시(`game.paused`), `game.update` 대신 `introFrame`. 끝나면 `endIntro`가 경기 모습으로 되돌리고 방장만 `match.start`(참가자는 방장의 serveReady를 받음). 경기가 중간에 취소되면 `stopGame` → `endIntro(false)`.
- 소리 크기 `setQuiet`는 매 프레임 루프에서 정한다(경기·대기실 1, 로비·꾸미기 `LOBBY_QUIET`). 예전에는 이 줄이 'pong' 메시지 처리 안에 잘못 들어가 있어서 로비 배경 소리가 줄지 않았다(고침).

## 첫 로딩 빠르게 (최적화 ⑤, main 배포됨)
