# 화면 디자인 · VS 소개 · 업데이트 내역 · 광장 메뉴

> **지금 모습만**(11/27 정리). 로비·대기실·코드 입장 화면은 광장으로 바뀌며 없어짐(`plaza.md`). 아래는 사용자 확정.
> 새 화면·아이템을 만들 땐 `principles.md`(그림체 하나·어둡게 금지·UI는 그림으로).

## 1. 새 디자인: 탁구 색 + 유리 (11/18 확정, 모든 화면)
- **색(탁구용품에서)**: 빨강 `--tt-red`(러버) = 가장 중요한 버튼 · 파랑 `--tt-blue`(탁구대) = 두 번째 버튼 · 흰 반투명 유리 `--glass`·`--glass-line` = 패널 · 공 주황 `--tt-ball` = 코인 하나만. 글자는 흰색. 팀 색 **A = 빨강 / B = 파랑**.
- **글꼴**: 화면 글자 = **Pretendard**(npm `pretendard`, dynamic-subset — 쓰는 글자 묶음만 받음, `--font-ui`). **로고와 가슴 뛰는 순간(내 차례·승리·준비하시고 스매시)만 Jua**.
- **아이콘**: 이모지 대신 **선 아이콘**(인라인 SVG `.ic`, Lucide 모양, `src/icons.js ic(name)`, index.html에도 같은 SVG). 쉬는 시간 ☕·⏳ → `coffee`·`hourglass`, 미션 아이콘 = `missions.js ico`. **응원 이모지·업데이트 창·3D 그림 글자는 그대로.**
- 버튼은 평평 + 누르면 살짝 작아짐. 공통 테마 클래스 **`.gx`**(style.css '새 디자인 공통').
- **성능**: 유리(흐림)는 메뉴 창에만, 경기 HUD엔 안 씀. 지킴이 `glassGuard`: 2초씩 재서 두 번 연달아 40fps 아래면 `html.lite-glass`(흐림 끔, 진한 남색, `smash-lite-glass` 기억). `?glass=0|1`. 흐림이 안 되는 브라우저는 진한 남색(`@supports not`).
- 화면별: 랭킹 = 밝은 유리 패널, 1~3등 금·은·동 동그라미 `.mdl`, 내 줄 빨간 빛 · 꾸미기 = **3D는 어둡게·흐리게 안 함**(아이템 진짜 색), 카드 반투명 + 등급 띠·테두리 빛(희귀 보라·전설 금), 장착 = 흰 테두리 + 빨간 체크, 뽑기 1회 빨강 / 10회 보라.

## 2. 경기 화면 (`ui/hud.js`)
- 흐림 없이 진한 반투명 `--hud-bg`. 점수판 A 빨강 · B 파랑(바뀐 쪽 숫자 통통 `bump`), 듀스 공 주황 알약. 오른쪽 위 랠리 카드(평소 남색 → 6회부터 공 주황→빨강→분홍→보라, 혼자 하기는 최고·Perfect·코인 알약).
- **판정·VS·3·2·1 = '빛 글자'**: Pretendard, VS·숫자는 가는(300) 큰 흰 글자 + 은은한 빛, 판정(PERFECT·GOOD·BAD·BLOCK·SMASH·헛스윙)은 굵은(700) 흰색 → 아래 등급 색(`--g`) + 빛.
- 알림 = 진한 알약 + 공 주황 점. 경기 끝 = 가운데 큰 결과 띠 `#result`(승리 빨강 / 패배 남색, 약 2.7초). 업적 알림 진한 남색 + 금 테두리. 연결 표시 `#net-pill`(`gameplay.md` 7장).

## 3. VS 소개 = 경기 전 연출 (`ui/intro.js INTRO`, 10.2초)
- 0~1초 **광장 → 방장 경기장 불꽃 물결**(`plaza.md` 7장 ⓑ, 예전 '어둠 속 심장 소리'를 대신) → 1~6초 VS 소개(상대 1~2.7 → 우리 2.7~4.4 → VS 4.4~6, 카메라가 다가감) → 6~9초 3·2·1(`#vi-num`, 심장 0.85 → 0.5초 간격) → 9~9.6 정적 '준비하시고,' → 9.6 '스매시!' + 관중 함성(박수 없음) → 10.2 경기. 구간 class `dim`·`p1`·`p2`·`p3`·`cd`·`hush`·`go`. 1대1·2대2만.
- 이름 카드 = **칭호 + 닉네임만**(아이템·세트 알약은 없앰, 정보가 너무 많아서). 2연승 이상 '🔥N연승 중'.
- **건너뛰기**: 오른쪽 아래 버튼 + 선수 수만큼 빈 원, **모두** 누르면 정적(9초)으로(끝맺음 1.2초는 보여 줌). `{k:'skip', from}`을 각 PC가 셈(`addSkip`).
- **이 판에 걸린 것** `#vi-stake`(VS부터 카운트다운 끝까지, 최대 3개, **내 쪽에서 본 것** `stakes()`): 상대 전적(1대1·둘 다 로그인 — '첫 대결!'·'복수전!'·'우세 지키기'·'이번 판이 승부처') → '연승 저지 찬스!' → '이기면 N연승' → 쉬는 시간이면 '코인 +50%'. **코인 숫자는 안 씀**(같은 상대 하루 판 수 제한을 브라우저가 몰라서).
- 3·2·1 동안 카메라가 첫 서브하는 사람(A팀 1번) 어깨 너머로 가고, 숫자마다 공을 '통'(`serveRoutine`). 관전자가 있으면 '👁 N명이 지켜보는 중', 카운트다운·'스매시!'에 관중석 들썩.
- 탁구채 든 자세는 `ui/stage.js`.

## 4. 광장 메뉴 배치 (11/25 확정 "버튼 배치가 너무 난잡해" → 정리)
- **자리마다 하는 일 하나**: 왼쪽 위 = 광장 상태(알약 하나: 인원·날씨) · 위 가운데 = 알림(한 줄: 쉬는 시간 → 모집 → 초대 차례로) · 오른쪽 위 = **나(이름·코인·⚙ / 전적 / 오늘의 미션을 유리 카드 한 장)** · 왼쪽 아래 = 안내(❓ 치는 방법 · 📢 업데이트 · 09시 — 작은 알약) · 가운데 아래 = 💬 말하기 · 오른쪽 아래 = 🎁 무료 뽑기 한 줄 카드.
- 조작 안내 글은 말하기 위 작은 알약, **광장에 올 때마다 10초 보이고 사라짐**(자리에 섰을 때·거품 안·말하기 창 열림이면 안 보임).
- 휴대폰: 위 = [👥 N명] … [내 카드 + 미션 머리줄], 알림은 내 카드 아래, 아래 한 줄 = [❓][📢] [💬 말하기] [🎁 숫자 딱지]. 날씨·09시·안내 글 숨김. 미션은 정한 적 없으면 휴대폰에서 접힘(`missions.js folded()`).
- ⚙ 내 계정 메뉴: PIN 바꾸기 · 🎵 박자 맞추기(`fishing.md` 4-6) · 로그아웃.
- 코드: `style.css` 맨 끝 '광장 메뉴 정리'(`.lobby.plaza-on` 안).
- 다른 게임 바로가기 `#lnk-until09` → '"09시까지 출근하세요" 플레이 ↗'(https://until09-5zhx.vercel.app/, 새 탭).
- 처음 온 사람에게 '치는 방법' 창 자동으로 한 번(`smash-howto-seen`).

## 5. 업데이트 내역 (`src/updates.js UPDATES`, 맨 위가 최근)
- **test를 main에 합칠 때마다 그날 항목을 추가.** 날짜 = **실제 게임(main)에 들어간 날(한국 시간)**, 날짜 안에서는 유저에게 변화가 큰 순서. 기획만 하고 뺀 것·개발용 변경은 안 적음.
- 큰 것(`big`)은 카드, 나머지는 '자잘한 변경·고침'(`small`, 접힘). **비슷한 건 한 카드로**(예: 꾸미기 머리·얼굴·탁구대·세트를 한 카드로). 코인 규칙은 숫자 없이 뭉뚱그림.
- 새 소식 표시: 📢 아이콘에 빨간 **N**만(자동으로 창 안 띄움), 브라우저 `smash-updates-seen`. 창 `.howto-pop`(`#updates`), 광장 게시판 왼쪽 종이로도 열림.

## 6. 첫 로딩 빠르게
- 첫 화면 약 0.6초(10Mbps·지연 60ms 흉내). 첫 3D는 `renderer.compileAsync`로 셰이더를 준비한 뒤(HTML 먼저 보임).
- Jua는 `media="print" onload` + preconnect(화면 안 막음). three.js 따로 묶음(`manualChunks`), `/assets/*` 1년 보관(`vercel.json`).
- 낚시·고양이 창 등 큰 코드는 누를 때 `import()`.

## 7. 안 하기로 한 것
- 예전 '따뜻한 주황 + 파랑' 디자인 · 로비 메뉴 화면(혼자 하기·1대1·2대2 버튼)·대기실 무대·연습 스윙·코드 입장 상자 → 광장으로 바뀜
- 이름표·VS 소개의 아이템·세트·등급 알약
- 유리 판·유리 글자 판정(빛 글자로 고름)
