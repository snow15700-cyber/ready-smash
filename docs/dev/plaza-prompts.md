# 광장 로비 — 단계별 프롬프트 (복사해서 새 대화에 붙여 넣기)

> 한 단계씩 차례대로 쓴다. 앞 단계를 test에서 확인한 다음에 다음 단계로 넘어간다.

## ① 광장 기본
```
docs/dev/plaza.md를 읽고 '9. 만드는 순서'의 ① 광장 기본을 만들어 줘.
- 광장 장면(배경 아이템과 상관없는 고정 배경, bakeArena로 가볍게), 바닥 클릭으로 걷기, 내 캐릭터 뒤를 따라가는 3인칭 카메라.
- 광장 채널(pingpong-plaza / 테스트 pingpong-test-plaza)로 다른 사람 보기. 걷기는 클릭할 때 {from, to, t} 한 번만 보내고, 걷는 모습은 각자 계산해서 그려.
- 정해진 채팅(plaza.md 6장 문구, 한 사람 2초에 한 번, 머리 위 말풍선).
- 상점·꾸미기·랭킹 가게 건물 3개(처음 서는 곳에서 가깝게). 누르면 지금 화면이 열리게. 미션은 지금처럼 화면에.
- 옛 로비로 가는 버튼은 임시로 남겨 둬.
휴대폰·카메라·최대 인원은 plaza.md 8장대로.
다 되면 npm run check에 광장 점검을 추가해서 돌리고, test에 올린 뒤 테스트 방법을 쉽게 알려 줘.
```

## ② 탁구대에 서서 경기
```
docs/dev/plaza.md의 ② 탁구대에 서서 경기를 만들어 줘(2장 규칙대로).
사람 대결용 탁구대 3대, 자리 4칸, 처음 선 사람 = 방장(방장 배경으로 경기), 준비 → 지금 경기 화면 → 끝나면 광장 + '한 판 더', 자리 비움 1분.
경기가 시작되면 선수 PC는 광장 채널에서 빠지게 하고, 광장 인원 0명·10명일 때 선수가 보낸 메시지 수가 같은지 재서 알려 줘.
옛 로비·방 목록·방 코드 입장·비공개 방은 이 단계에서 없애 줘(점검도 고쳐 줘).
```

## ③ 김제빵 탁구대
```
docs/dev/plaza.md 3장대로 김제빵 탁구대를 만들어 줘. 누구나 동시에 혼자 하기, 다른 사람 눈엔 김제빵 혼자 + '🔥 N명 도전 중' 표지판.
```

## ④ 광장에서 관전
```
docs/dev/plaza.md 7장대로 광장 관전을 만들어 줘. 가까이 간 탁구대 1대만 실시간(듣기만), 먼 탁구대는 점수판만, '👀 관전' → 지금 관전 화면. 선수 부담이 0인지 다시 재 줘.
```

## ⑤ 모집 알림·초대·김제빵 부르기 (11/24 test ✓)
```
docs/dev/plaza.md 4·5장대로 '1명 부족' 알림(같은 탁구대 15초에 한 번), 콕 집어 초대, 3명일 때 김제빵 부르기(빵 굽다 뛰어오는 연출)를 만들어 줘.
김제빵 낀 경기의 전적·코인은 plaza.md 8장대로(전적 없음, 코인은 보통 2대2와 같게).
```

> 11/24: '경기장 거품'(plaza.md 16·18장) test ✓ — 광장이 넓어지고 탁구대 자리가 바뀌었다. ⑥(탁구대 늘어나기)은 원끼리 안 겹치는 정해진 자리 안에서 다시 정한다.

## ⑥ 탁구대 늘어나기 + 배경 장식
```
docs/dev/plaza.md 2장대로 탁구대 늘어나기/줄어들기와 탁구대 배경 장식(깔개·깃발·표지판, 방장 배경)을 만들어 줘. 장식 시안은 스크린샷으로 몇 개 보여 주고 고르게 해 줘.
```
