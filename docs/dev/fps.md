# FPS(1인칭 슈팅) — 기획 초안 (11/28, 아직 확정 아님)

> 이 문서는 **초안**이에요. ❓ 표시는 사용자가 정할 것. 정해지면 '(사용자 확정)'으로 바꿔 적어요.

## 0. 전제 (CLAUDE.md 규칙 그대로)
- **같은 프로젝트 안에** 만든다: 로그인·코인·업적·칭호·꾸미기·광장·서버를 같이 씀.
- 코드는 `src/games/fps/`, 광장 연결은 `registerAddon({ id: 'fps', ... })` 한 번(`cleanup.md` 12번 '새 콘텐츠 붙이는 법').
- 꾸미기(몸·머리·얼굴)는 FPS 캐릭터에도 그대로 보임(보기만 다름, 판정은 똑같이).

## 1. 어떤 슈팅인가 ❓ (가장 먼저 정할 것)
교육 기관의 쉬는 시간 게임이라 **총·피 대신 귀여운 무기**를 추천해요. 탁구 게임과도 어울려요.

| 안 | 내용 | 느낌 |
|---|---|---|
| **A. 탁구공 블래스터 (추천)** | 탁구공을 쏘는 장난감 대포. 맞으면 "펑!" 하고 캐릭터가 잠깐 빙글 돌며 기절 → 몇 초 뒤 출발점에서 다시 | 우리 게임 이름과 딱 맞음, 탁구공 꾸미기(`balls.js`)를 총알 모양으로 재사용 가능 |
| B. 페인트 물총 | 맞으면 몸에 색이 묻고, 바닥을 우리 팀 색으로 칠한 넓이로도 점수 | 밝고 화려함, 칠하기 계산이 조금 더 무거움 |
| C. 눈싸움 | 겨울(운영 1월 말까지)에 맞춰 눈덩이. 포물선으로 날아감 | 계절감, 조준이 쉬움 |

## 2. 광장에 어떻게 들어가나 ❓
- **추천: 광장에 '사격장' 건물(또는 체육관 지하 문) 하나** → 탁구대처럼 앞에 **자리(발판)** 가 있고, 서서 '준비'하면 모인 사람끼리 시작.
- 시작·끝은 지금 탁구처럼 **물결 전환**(`plaza.md` 19장 ⓑ) → 경기장으로, 끝나면 광장으로 돌아옴.
- 다른 사람이 FPS 중이면 광장에서 그 사람 머리 위에 🎯 표시, 전광판에 "사격장 3:2 진행 중".
- 관전: 건물 앞에 **경기장 거품**(18장 방식)을 띄워 걸어 들어가 구경 — 나중 단계.

## 3. 모드 (단계별로 하나씩)
1. **혼자 연습 '표적 맞히기'** — 사격장에서 튀어나오는 표적(김제빵 판때기?)을 60초 동안 맞히기. 서버·네트워크가 거의 필요 없어서 **처음 만들기 좋고**, 조작감을 먼저 다듬을 수 있음. 기록은 랭킹.
2. **팀전 2대2 ~ 4대4** — 3분, 먼저 정해진 점수 또는 시간 끝에 많이 맞힌 팀 승리.
3. (나중) **김제빵 봇** — 사람이 모자랄 때 빈자리를 채움(탁구 김제빵처럼).
4. (나중) 개인전, 깃발 뺏기 등.

## 4. 한 판 흐름 (팀전, 숫자는 시안에서 조정)
- 대기(자리 채우기) → 3초 카운트 → **3분** 경기 → 결과(MVP, 맞힌 수) → 광장으로.
- 체력 없이 **한 방에 기절**(단순하고 공정) ❓ 또는 3방.
- 기절 3초 → 우리 진영에서 다시 출발, 다시 나온 직후 2초 무적.
- 맵: 작은 방 1개(교실·체육관 느낌), 숨을 상자·벽 몇 개. 작을수록 빨리 만나서 쉬는 시간에 맞음.

## 5. 조작
- **PC(주 대상)**: 화면 클릭 → 마우스가 화면에 잠김(Pointer Lock). 마우스 = 보기, WASD = 이동, 클릭 = 쏘기, 스페이스 = 점프, Esc = 잠금 풀기.
- **휴대폰** ❓: FPS는 휴대폰 조작이 어려움. 안: ⓐ 휴대폰은 관전만 ⓑ 왼쪽 손가락 이동 + 오른쪽 끌어서 보기 + 자동 쏘기(가운데 조준점에 적이 오면).
- 마우스 감도 설정은 ⚙️에(기기에 저장, 낚시 박자 보정처럼).

## 6. 네트워크 — 탁구·낚시와 가장 다른 부분 ⚠️
탁구는 2명이 '친 순간'만 주고받지만, FPS는 **여러 명이 계속 움직임**을 주고받아야 해요.
- 위치 보내기: 1초에 **10번** 정도, 받는 쪽은 그 사이를 부드럽게 이어 그림(보간).
- **Supabase 무료 한도 주의**: 8명이 1초에 10번씩 보내면 한 판(3분)에 받는 메시지가 약 10만 개. 무료 요금제 월 메시지 한도(약 200만 개, 확인 필요)를 금방 씀.
  → **추천: 이미 만들어 둔 선수끼리 WebRTC 직접 연결 + 서울 중계(TURN)** 을 써서 움직임은 그 길로, Supabase는 시작·끝·점수만. (대안: 방장 한 명이 모아서 다시 뿌리기)
- 맞았는지 판정: **쏜 사람 화면 기준으로 "맞았다" → 방장이 거리·시간이 말이 되는지 확인 후 인정**. (와이파이가 느려도 내가 맞힌 건 맞힌 것처럼 느껴지게)
- 쏜 공은 느린 탁구공이라 날아가는 모습이 보임 → 순간 판정 총보다 **늦음이 덜 티 남**(A안의 장점).

## 7. 보상·서버
- 코인: 한 판 참가 + 승리 보너스, **하루 한도**(낚시 1000처럼). 서버가 계산(브라우저 숫자 안 믿음).
- 업적: "첫 명중", "한 판 10명중", "연속 3명중" 등 / 칭호 "명사수".
- 랭킹: 표적 맞히기 최고 점수, 팀전 승수.
- SQL은 새 번호 파일(`41_fps.sql` …), `pingpong_` 접두어, 로컬 가짜 서버도 같이.
- (나중) 상점: 블래스터 꾸미기(모양만 다름, 판정 같음).

## 8. 만드는 순서 (단계마다 멈추고 사용자 테스트)
1. **시안 페이지 `fps.html`** — 빈 방에서 1인칭으로 걷기·보기·쏘기·표적 맞히기. 조작감·무기 모양 고르기(스크린샷).
2. **혼자 표적 맞히기** 완성 + 광장 사격장 건물·발판·물결 전환.
3. **2명 대결**(탭 두 개로 시험) — 위치 주고받기·맞히기 판정.
4. **팀전 4~8명** + 결과 화면.
5. 서버(코인·업적·랭킹).
6. 관전 거품·김제빵 봇·휴대폰 조작·꾸미기.

## 9. 사용자에게 물어볼 것 (정리)
1. 무기 테마: A 탁구공 블래스터 / B 페인트 물총 / C 눈싸움 / 다른 것?
2. 광장 입구: 새 '사격장' 건물 / 기존 건물(체육관 등) 안 / 광장 공터에서 바로?

## 10. 사용자 희망 (11/28): 서버 부담 적게 · 타격감 · 간단함
→ 아래는 Claude 제안(아직 확정 아님).

### 10-1. 서버 부담을 줄이는 방향 — "실시간 대전"을 기본으로 하지 않기
| 방식 | 서버 부담 | 내용 |
|---|---|---|
| **① 혼자 사격 (기본)** | 0 (끝날 때 점수 1번 저장) | 표적·김제빵 로봇을 맞히는 1인 모드. 모든 계산은 내 PC에서 |
| **② 오늘의 도전 (추천 경쟁 방식)** | 거의 0 | 모두가 **같은 씨앗(seed)** 으로 같은 표적 순서를 받음(`util.js`의 `seeded`). 따로 하지만 같은 문제라 공정하게 랭킹 경쟁. 쉬는 시간마다 다른 사람이 해도 됨 |
| ③ 유령 대결 (나중) | 작음 | 1등의 기록(언제 어디를 쐈는지)을 저장해 두고, 내 화면에 반투명 '유령'으로 같이 보여 줌 |
| ④ 실시간 2~4명 (나중, 꼭 원하면) | 작음 | 기존 선수끼리 직접 연결 + 서울 중계 사용. Supabase는 시작·끝·점수만 |

- 참고(대략 계산, 확인 필요): 위치 정보는 아주 작아서 ④도 한 판에 몇십 MB 정도. 중계(TURN) 무료 용량에 비하면 작은 편. **진짜 부담은 Supabase 메시지 개수**라서, Supabase로 움직임을 보내지 않는 게 핵심.
- 점수 속임 막기: 서버는 "점수 상한·하루 코인 한도"로 막고, ②는 같은 씨앗이라 비정상적으로 높은 점수를 가려내기 쉬움.

### 10-2. 간단함 — "움직이지 않는 사격장" 추천
- **이동 없음**: 제자리에 서서 마우스로 조준·클릭만(축제 사격장 느낌). WASD·점프 없음 → 설명 필요 없음.
- 같은 이유로 **휴대폰도 그냥 됨**: 누른 곳으로 발사.
- 한 판 **60초**, 규칙은 "맞히면 점수, 빨리·연속으로 맞히면 더 많이".
- 표적 종류 3개 정도: 보통 표적 / 빨리 지나가는 표적(점수 2배) / 김제빵 판(맞히면 감점 — 피해야 함).

### 10-3. 타격감 — 넣을 것 목록
1. **멈칫(히트스톱)**: 맞는 순간 0.05초 정도 화면이 멈칫.
2. **화면 살짝 흔들림** + 블래스터 반동(총이 뒤로 툭).
3. **소리 두 겹**: 쏠 때 "퐁", 맞을 때 "팡!"(Web Audio 합성 `audio.js`), 연속일수록 음이 올라감.
4. **표적이 산산조각** 파티클(`fx.js`) + 점수 숫자가 튀어 오름.
5. **조준점 반응**: 맞으면 조준점에 ✕ 표시가 번쩍.
6. **정중앙 보너스**: 표적 가운데 맞히면 "Perfect!" + 더 큰 소리(낚시 Perfect 연출 재사용).
7. **콤보**: 연속 명중 수가 커지고, 끊기면 "쨍그랑".

### 10-4. 바뀐 만드는 순서(제안)
1. 시안 `fps.html`: 제자리 사격 + 타격감 7가지 → 사용자가 손맛 고르기
2. 60초 혼자 모드 + 광장 사격장 건물·발판
3. 오늘의 도전(같은 씨앗) + 랭킹·코인(서버 SQL 한 번)
4. (나중) 유령 · 실시간 2~4명
