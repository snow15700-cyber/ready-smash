## 1. 한도 정리 (11/28 조사)
| 서비스 | 무료 한도 | FPS에 뜻하는 것 |
|---|---|---|
| Supabase Realtime | 월 메시지 200만 개, **초당 100개** (넘으면 연결 끊김). 방송 1번 = 보낸 사람 1 + 받는 사람 수만큼 셈 | **움직임을 Supabase로 보내면 안 됨.** 8명이 1초에 10번만 보내도 초당 600개 이상 → 바로 끊김 |
| Cloudflare TURN(서울 중계) | 월 1,000GB(SFU와 같이 씀), **Cloudflare에서 나가는 쪽만** 계산 | 작은 숫자만 보내면 거의 안 씀(아래 계산) |

→ **결론: 움직임·총알은 전부 선수끼리 직접 연결(WebRTC, 교실에선 서울 중계)로. Supabase는 방 만들기·연결 인사·시작·결과 저장만.**

## 2. 네트워크 설계 (용량 아끼는 핵심)
- **방장 한 명이 가운데(별 모양)**: 각자는 방장에게만 보내고, 방장이 모아서 한 번에 돌려줌.
  - 모두가 모두에게 보내는 방식보다 꾸러미 수가 훨씬 적음(8명: 56갈래 → 14갈래). 꾸러미마다 붙는 포장(약 60~80바이트)이 실제 내용보다 커서 이게 제일 중요.
  - 방장이 **심판**도 함(맞았는지 최종 인정) → 탁구의 `match.js` 방장 방식과 같음.
- **1초에 15번**, 숫자를 작게 줄여 보냄(위치·방향을 2바이트 정수로). 사람 1명 정보 ≈ 10바이트.
- **'안 와도 되는' 길로**: 위치는 늦게 온 건 버리는 데이터 채널(순서 X, 다시 보내기 X), 맞음·기절·점수는 '꼭 가는' 채널. 지금 `makeP2P`는 꼭 가는 채널 하나라 FPS용 채널을 하나 더 만든다.
- **지금 탁구처럼 Supabase 방송으로 같이 보내지 않기**(탁구는 두 길로 보내고 먼저 온 것을 씀 — FPS에선 이걸 끔).
- 용량 대략 계산(8명, 3분): 방장이 받는 것 7×15×≈75B + 7명이 받는 것 7×15×≈150B ≈ **초당 24KB → 한 판 약 4~5MB**. 하루 50판 ≈ 250MB, 한 달 ≈ 7GB(1,000GB의 1% 미만). Supabase는 한 판에 수십 개.
- 방장이 나가면: 그 판은 끝(간단하게). 결과는 그때까지 점수로. ❓

## 3. 타격감 — 느린 와이파이에서도 "쏜 즉시" 느낌
네트워크가 15번/초라도 손맛이 좋으려면 **내 화면에서는 기다리지 않게** 만든다.
- **내 움직임·내 총은 내 PC에서 바로** 처리(서버 답을 안 기다림).
- **쏜 사람 기준 판정**: 내 화면에서 맞았으면 → 바로 맞음 연출 → 방장에게 "몇 시 몇 분에 누구를 맞힘" 보냄 → 방장은 거리·연사 속도·그 순간 위치가 말이 되는지만 확인하고 인정. (드물게 거절되면 점수만 안 오르고 연출은 그대로)
- 다른 사람은 **0.1초 전 모습을 부드럽게** 이어 그림(뚝뚝 끊기지 않게).
- 즉발 총(맞는 즉시)이 이 방식에 가장 잘 맞음. 날아가는 공은 늦음이 보임.

손맛 연출(내 화면에만, 네트워크 0):
1. 쏠 때 반동(총 툭·화면 살짝 위로) + 총구 번쩍 + "탕/퐁" 소리
2. 맞으면 조준점 ✕ 번쩍 + "틱!" 맞음 소리(따로 들리게 높은 음)
3. 맞은 사람 몸이 움찔·색이 번쩍, 숫자 튀어 오름
4. 쓰러뜨리면 짧은 멈칫(0.05초) + 큰 소리 + 화면 가장자리 번쩍 + "1킬"→"2연속!" 글자
5. 내가 맞으면 맞은 쪽 방향 화면 가장자리 빨강/색 + 둔한 소리
6. 머리 맞히면 소리·✕가 다름(더 쨍함)

## 4. 간단함 — 게임 규칙
- **팀전 4대4까지**(2대2부터 가능), **3분**, 많이 쓰러뜨린 팀 승리. ❓ 인원
- 체력 100, 몸 맞으면 -34(3방), 머리 -100(1방) ❓
- 쓰러지면 3초 뒤 우리 진영에서 다시, 나온 직후 1.5초 무적.
- 무기 **하나만**(고르기 없음), 장전 없음 또는 자동 장전. 아이템·스킬 없음.
- 맵 **하나**, 작게(교실 2~3개 넓이), 상자·벽으로 숨는 곳.
- 조작: 클릭 → 마우스 잠금, WASD 이동, 마우스 보기, 왼클릭 쏘기, 스페이스 점프, Esc 풀기. 감도는 ⚙️(기기에 저장).

## 5. 무기·겉모습 테마 ❓

- A. **탁구공 레이저 블래스터**(즉발, 빛줄기 + 탁구공 색 불꽃) — 추천

- 관전은 나중에(관전자도 방장에게 받으면 용량이 늘어남 → 관전자 수 제한).

## 8. 만드는 순서 (단계마다 멈추고 사용자 테스트)
1. **손맛 시안 `fps.html`** — 혼자 빈 맵에서 걷기·쏘기·허수아비 맞히기(시험용, 실제 게임엔 혼자 모드 없음). 반동·소리·✕ 고르기.
2. **2명 연결**(탭 두 개 → 실제 PC 두 대) — 별 모양 연결·15번/초·쏜 사람 기준 판정. 용량 측정 숫자를 화면에 띄워 확인.
3. **4대4 팀전** + 결과 화면 + 교실 와이파이 시험.
4. 광장 사격장 건물·발판·전환.
5. 서버(코인·업적).
