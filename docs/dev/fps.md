# FPS(1인칭 슈팅) — 기획 (11/28 사용자와 정함, 아직 만들기 전)

> ❓ = 사용자가 정할 것. (사용자 확정) = 정해진 것. 이 문서는 **지금 모습만** 적는다(버린 안은 맨 아래).

## 0. 필요 요소 (사용자 확정 11/28)
1. **멀티플레이만**, 2. **PC만**, 3. **타격감**, 4. **Supabase·Cloudflare 용량 적게**(Cloudflare는 조금 더 써도 됨).
- 같은 프로젝트 안: `src/games/fps/`, 광장에는 `registerAddon({ id: 'fps', ... })`, 로그인·코인·업적·꾸미기 공유.

## 1. 한도 (11/28 조사)
| 서비스 | 무료 한도 | 뜻 |
|---|---|---|
| Supabase Realtime | 월 200만 메시지, **초당 100개**(넘으면 끊김), 방송 1번 = 1 + 받는 사람 수 | 움직임은 절대 Supabase로 안 보냄 |
| Cloudflare TURN(서울 중계) | 월 1,000GB(SFU와 같이), 나가는 쪽만 계산 | 교실은 기기끼리 직접이 막혀서 **모든 선수 소식이 여기를 지남** |

## 2. 네트워크 — '방장 없는 판' (사용자 확정 11/28)
### 2-1. 왜 방장을 없애나
- 같은 교육장이면 모두 와이파이가 비슷 → '연결 좋은 사람 고르기'는 효과가 작음(사용자 지적).
- 방장이 있으면 **방장 한 명이 끊기면 모두의 판이 끝남**(무효). 끊김이 잦은 교육장에서는 이게 제일 큰 약점.
- → **누구 하나가 끊겨도 판이 계속되게**, 모두를 똑같은 자격으로.

### 2-2. 규칙: "내 몸은 내가 책임"
- **내 위치·움직임** → 내가 정해서 모두에게 보냄(1초 30번, 바로 전 2개 겹쳐 실음).
- **내가 쐈을 때 맞았는지** → **쏜 사람이** 자기 화면 기준으로 판단(0.25초 전까지만) → "○○ 머리 맞힘" 소식을 모두에게.
- **내 체력** → **맞은 사람이** 그 소식을 받아 자기 체력을 깎음. 쓰러지면 "××에게 쓰러짐"을 모두에게.
- **점수** → 모두가 같은 "쓰러짐" 소식을 받아서 각자 셈 → 모두 같은 점수판.
- **시간** → 탁구에서 쓰는 시계 맞추기(`room.js`)로 모두 같은 시각에 시작·3분에 끝.
- 거의 동시에 서로 쏘면 **둘 다 쓰러질 수 있음**(맞교환) — 오히려 재미 요소.

### 2-3. 끊겼을 때
- 끊긴 사람: 그 자리에 서 있다가 3초 뒤 반투명(📶). **15초 안에 돌아오면** 점수 그대로 이어서, 넘으면 빠짐. **다른 사람의 판은 그대로 계속.**
- 사람이 **1명만 남으면** 그 판 무효(사용자 확정: 끊겨서 끝난 판 = 무효).
- 돌아온 사람은 남은 사람 아무에게서 지금 점수판을 받음(모두 같은 걸 갖고 있음).

### 2-4. 결과·코인 (속임 막기)
- 끝나면 **모두가 각자 결과를 서버에 보냄** → 서버는 **절반 넘게 같은 결과일 때만** 인정(1대1 '서로 맞아야 승리'를 여럿으로 넓힌 것).
- 조작한 브라우저가 맞아도 체력을 안 깎는 속임은 막기 어려움 → **하루 코인 한도 1000**(사용자 확정 11/28, 일단)으로 피해를 작게.

### 2-5. 용량 계산 (8명, 3분, 1초 30번 + 겹쳐 싣기)
- 모두가 모두에게 보내서 v2(방장)보다 약 3배 → **한 판 약 25MB**, 하루 50판이면 한 달 **약 35GB**(무료 1,000GB의 3~4%). Supabase는 한 판에 수십 개(시작·결과).
- 지금 탁구의 직접 연결(`makeP2P`)이 이미 '여럿이 서로 연결' 구조라 그대로 쓸 수 있음. FPS용 '늦으면 버리는' 길만 하나 더 + Supabase로 같이 보내기는 끔.

## 3. 타격감 (내 화면에만, 용량 0)
- 내 움직임·총은 기다리지 않고 바로. 다른 사람은 0.1~0.2초 전 모습을 부드럽게.
- 반동·총구 번쩍·소리 / 맞히면 조준점 ✕ + "틱!" / 머리는 더 쨍한 소리·다른 ✕ / 쓰러뜨리면 0.05초 멈칫 + "2연속!" / 맞으면 맞은 쪽 화면 가장자리 번쩍 / 화면 구석 📶 초록·노랑·빨강.

## 4. 규칙 (사용자 확정 11/28)
- **개인전**: 최대 8명, 모두가 적. **3분 또는 먼저 15명 쓰러뜨리면** 끝, 1·2·3등. (거의 동시에 15가 되면 시계 시각이 빠른 쪽)
- **팀전**: 1대1 ~ 4대4, 3분, 많이 쓰러뜨린 팀 승리.
- **머리 1방, 몸 2방**(체력 100, 몸 -50, 머리 -100).
- 쓰러지면 3초 뒤 다시, 나온 직후 1.5초 무적. 무기 하나, 맵 하나, 아이템·스킬 없음.
- 조작: 클릭 → 마우스 잠금, WASD·마우스·왼클릭·스페이스, Esc. 감도 ⚙️(기기에 저장). 휴대폰은 "PC에서만".

## 5. 보류 (사용자 11/28)
- 무기·겉모습 테마, 사격장 건물 위치. (추천은 총·피 없는 테마)

## 6. 광장·서버
- 광장 사격장 발판에서 준비 → 시작·끝 물결 전환. 경기 중인 사람 머리 위 🎯.
- 참가·승리 코인 + 하루 한도, 업적. SQL 새 번호 + 로컬 가짜 서버. 결과는 2-4처럼 '절반 넘게 같은 결과'만.

## 7. 만드는 순서 (단계마다 멈추고 사용자 테스트)
1. **손맛 시안 `fps.html`** — 빈 맵에서 걷기·쏘기·허수아비(시험용). 반동·소리·✕ 고르기.
2. **2명 → 4명 연결**(탭 여러 개 → 실제 PC) — 방장 없는 규칙·끊겼다 돌아오기. 화면에 용량·끊김 숫자 띄워 **교육장 와이파이에서 시험**.
3. 개인전·팀전 + 결과 화면.
4. 광장 사격장·전환.
5. 서버(코인·업적·결과 맞추기).

## 8. 전체 테마 (사용자 확정 11/28)
- **그림체: 우리 광장 캐릭터 + 어두운 네온 맵.** 꾸미기(옷·머리·얼굴)가 그대로 보임. 몸에 팀 색 빛 테두리.
- **움직임: 중간** — 빠른 달리기 + 짧은 대시 1개(쿨타임) + 점프대. (속도 숫자는 시안에서 정함)
- **'어둡지만 잘 보이게'** (사용자 확정 11/28 — `principles.md` 2번 '어둡게 만들지 않기'의 FPS 예외): 배경은 어둡게, 바닥·벽 윤곽은 밝은 네온, 캐릭터는 밝게. 빛 번짐 후처리 없이 흉내(교육장 PC).

## 9. 남은 일
- 연결 길 바꿀 후보: **Cloudflare '우체국'(SFU)** — 각자 Cloudflare에만 연결 1개(8명이면 7개 → 1개라 끊김에 강함). 서버 함수 하나 더 필요, 아직 시험 안 함. 2-2 규칙은 그대로라 길만 바꿔 끼움. 7장 2단계 교육장 시험에서 연결이 자주 끊기면 그때.
- 7장 1단계 **손맛 시안 `fps.html`**(새 대화): 어두운 네온 작은 맵 + 우리 캐릭터(허수아비 몇 개, 꾸미기 적용) + 중간 속도 움직임 + 쏘기·타격감 연출. 빛은 가볍게(빛 번짐 후처리 없이 흉내). 스크린샷으로 사용자가 색·연출을 고름.
- 무기 테마·건물 위치는 보류(시안 보면서 같이).


## 안 하기로 한 것
- 혼자 사격·오늘의 도전·제자리 사격·휴대폰 지원(첫 초안) — 사용자: 멀티 전용·PC 전용.
- 방장 한 명이 가운데(연결 좋은 사람 자동 선정) — 같은 교육장은 와이파이가 비슷해 의미 작음, 방장 끊김 = 모두 끝 → '방장 없는 판'으로.
- Cloudflare 서버(Durable Objects)가 방장 — 웹소켓(TCP)이라 끊김 잦은 와이파이에 약함, 무료 하루 요청 10만(하루 40~50판에서 막힘).
- 봇(AI) — 교실에선 봇 움직임도 Cloudflare를 지남. 다시 넣으려면: 결정만 가끔 보내고 걷기는 각자 PC가 똑같이 계산(용량 아주 적음). 봇 보상 '덜 주기', 봇과 혼자 하기 보류였음.
- 그림체 후보 장난감 경기장·스틱맨·낙서, 움직임 느긋·하이퍼(빠를수록 와이파이 늦음이 티 남).
