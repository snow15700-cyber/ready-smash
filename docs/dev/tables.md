## 기획 (2026-11-21 사용자와 정함, 아직 안 만듦)

### 공통 규칙
- **보기만 다름**: 치는 판의 크기·높이·네트 높이 그대로, 판정·물리 그대로. 물건 모양이어도 공이 닿는 면은 평평하게.
- **공 튀는 소리는 안 바꿈**(사용자 확정). 바운드음은 공(`BOUNCE_SKINS`)이 정한다.
- 판 가장자리가 잘 보여야 함(공이 밖으로 나갔는지 알게).
- 공 19종이 모두 잘 보여야 함 → 탁구대마다 공을 올려 사진 점검. 흰 공이 묻히는 흰색·연한 색 판은 피한다.
- 방장 탁구대가 모두에게 보임(경기장 뽑기). 관전 카메라가 옆면을 보므로 옆면·다리도 꾸민다.
- 효과는 공보다 작고 흐리게(배경 규칙과 같음).

### 등급별 차이 (사용자 확정)

### 목록 (사용자 확정 '다 좋다', 전설 5·6은 Claude 제안 — 확인 필요)
- **일반 6**: 클래식 초록 · 검정 · 원목 · 체리 분홍(진하게) · 보라 · 위장 무늬
- **고급 8**
  - 사무실 책상 두 개: 마주 붙인 책상, 가운데 칸막이 = 네트, 모니터·커피잔 / 튈 때 서류 팔랑
  - 택배 상자: 갈색 상자 두 개, 박스테이프 줄 = 네트 / 튈 때 상자가 살짝 움푹
  - 급식판: 스테인리스 식판(칸 자국 얕게), 숟가락·젓가락 = 네트 / 튈 때 반짝
  - 침대: 이불, 베개 줄 = 네트 / 튈 때 이불 폭신 들어감
  - 바둑판: 나무 바둑판, 바둑돌 한 줄 = 네트 / 튈 때 돌이 달각 들썩
  - 시골 평상: 수박 반통 줄 = 네트, 부채·모기향(연기 솔솔)
  - 커다란 식빵 두 장: 치즈 한 장 = 네트 / 튈 때 빵가루 (식빵 탁구채와 세트)
  - 펼친 교과서: 접힌 곳 책갈피 끈 = 네트 / 튈 때 책장 끝 살랑
- **전설 6**
  1. 오락실 게임기: 어두운 픽셀 화면 판 / 튈 때 '+100'·픽셀 불꽃 / 스매시 득점 'K.O.!' / 긴 랠리 'COMBO ×N'
  2. 마법 양탄자: 다리 없이 둥둥, 술 날림 / 튈 때 무늬 반짝 / 스매시 때 물결
  3. 거대 거북이: 등껍질 판, 고개로 공을 따라봄·눈 깜빡 / 스매시 득점 때 목 쏙 → 빼꼼
  4. 초콜릿 생일 케이크: 초 줄 = 네트(불꽃 흔들) / 튈 때 크림 출렁 / 스매시 득점 때 초 '훅' 꺼짐 → 폭죽과 함께 다시 켜짐
  5. (제안) 식빵 고양이: 회색 고등어 무늬 고양이가 식빵 자세로 엎드린 등이 판, 꼬리 = 네트(살랑살랑) / 튈 때 귀 쫑긋·분홍 젤리 발자국 / 스매시 때 꼬리 펑 부풀어 오름 / 득점 때 기지개 + 하트 / 가끔 하품·꾹꾹이
  6. (제안) 솜사탕 구름: 분홍·연보라 솜사탕 구름이 둥둥(흰 공 잘 보이게 흰 구름은 안 씀), 작은 무지개 = 네트 / 튈 때 구름이 폭신 패이고 별가루 / 스매시 때 무지개 반짝 / 득점 때 구름 위로 작은 하트 풍선

## 1단계 시안: 일반 6종 (2026-11-21, test)
- `src/tables.js`: `TABLES`(id·name·grade, 기본 `blue`), `makeTable(id)` → Group(원점 = 바닥 가운데, 판 윗면 = TY). 지금 `scene.js`의 `buildTable`과 같은 모양(판·흰 선·다리 8개·밑판·네트·기둥)에 색만 `LOOK`으로. 원목·위장 무늬는 캔버스 무늬(`woodTex`·`camoTex`, 정해진 난수라 늘 같은 무늬). 검정은 은색 다리(윤기). 무늬는 판 윗면에만, 옆면은 `edge` 색.
- 아직 게임에는 안 씀(`buildTable` 그대로). 게임·상점 연결 때 `buildTable` 대신 `makeTable`을 쓰고 방장 장착으로 바꾸면 된다. 움직이는 탁구대(고급·전설)는 `userData.tick(t, dt)`을 매 프레임 부르게(시안 페이지는 이미 부름).
- 시안 페이지 `tables.html`(`src/tables-page.js`, vite 빌드 입력·`npm run check`에 포함). 공 단추로 공을 바꾸고, 카메라 경기 화면/관전(옆)/위에서, 밝은 곳/어두운 곳, 화면을 끌면 빙 돌아봄. 주소 `?id=wood&ball=orange&cam=side&bg=dark&yaw=0.5`.
- 공 보이기 점검(공 8종 × 탁구대 7종, 밝은 곳·어두운 곳): 모두 보임. 가장 약한 조합은 어두운 곳의 원목 + 주황 공, 체리 분홍 + 핑크 공.
