# 낚시 (기획 확정 11/25)

> 사용자: "광장에 바다가 있으니 거기서 낚시를 하자." 레퍼런스 = 동물의 숲(톡톡 풍덩) + 우리 탁구의 타이밍 링.
> 순서(사용자 확정 11/25): **출석 도장판·승리 세리머니는 잠깐 보류하고 낚시를 먼저**.

## 0. 전제
- 새 광장(`plaza.md` 20장 '경주캠퍼스 느낌')의 바다에서 한다. 광장 바닥은 바다보다 약 12m 높고, 남동쪽 바다 전망대 아래 자갈 해변(z ≈ 48)이 있다.
- 새 광장은 아직 시안(`campus.html`)이다. 그래서 **손맛 시안은 캠퍼스 시안의 바다 위에서 먼저** 만들고, 게임 광장에 넣는 건 광장 옮기기 ⓐ(바닥·본관·바다·산) 다음에 한다.
- 꾸미기처럼 **판정·경기와 상관없는 놀이**다. 경기 중인 선수 PC에 네트워크 부담을 주지 않는다.

## 1. 낚시 자리 (사용자 확정)
- 전망대 옆 계단으로 내려가 해변의 **나무 선착장**에서 한다.
- **정해진 칸 없음**: 선착장 위 어디서든 서서 던질 수 있고, 여러 명이 나란히 서도 된다(겹치면 살짝 비켜 섬).
- 다른 사람에게는 걷기처럼 '던졌다(어디로)'·'잡았다(무엇을)'만 한 번씩 보낸다(광장 채널).
- **휴대폰도 가능**(사용자 확정): 노리는 그림자를 톡 눌러서 던지고, 링 판정은 화면 아무 데나 누르기.

## 2. 한 마리 잡는 흐름 (사용자 확정, 숫자는 시안에서 조정)
1. **그림자 보기**: 물속에 물고기 그림자 2~3개. 크기로 짐작.
2. **던지기**: 마우스를 위로 올리며 클릭(스윙과 같은 동작). ↖ ↑ ↗ = 왼쪽·가운데·오른쪽 그림자.
3. **입질**: 매번 **찌 둘레에 타이밍 링**이 좁혀진다. **진짜만 누르고 가짜는 참는다.**

| 입질 | 찌·소리 | 링 | 정답 |
|---|---|---|---|
| 톡 (가짜) | 살짝 콕, '톡' | 작고 빠름 | **안 누르기** → '✨ Perfect 참기!' |
| 가짜 풍덩 (변칙, 사용자 아이디어) | 쑥 잠겼다가 **바로 다시 튀어 올라옴** | 닫히기 전에 깨짐 | **안 누르기** → '✨ Perfect 참기!' |
| 진짜 풍덩 | 쑥 잠기고 **계속 잠겨 있음**, 묵직한 '풍덩!' + 물보라 | 끝까지 닫힘 | **닫힐 때 클릭** (Perfect / Good / Bad) |

   - 가짜 풍덩과 진짜는 **잠기는 순간까지 똑같다**. 차이는 그다음 약 0.15초(튀어 오르느냐). 급하게 누르는 사람을 거르는 함정.
   - 진짜는 잠긴 뒤 링이 닫힐 때까지 약 0.35초 여유(보고 눌러도 되게).
   - 가짜에 누르거나 진짜를 놓치면(Miss) 물고기가 도망간다.
   - 입질 순서는 물고기마다 다르다(순한 것: 톡 → 진짜 / 까다로운 것: 톡·톡·가짜 풍덩·톡 → 진짜).
   - 진짜 판정: Perfect = 바로 잡음(참기도 다 Perfect면 도감에 ✨ 표시) · Good = 잡음 · Bad = 랠리 한 번 더.
4. **큰 물고기 랠리**(사용자 확정 → 11/25 **5-2장의 짧은 장력 밀당 + 펌핑 링으로 바꿈**): 잡은 뒤 물고기가 물 위로 2~3번 펄쩍 뛴다. 뛸 때마다 링이 뜨고, 맞추면 '탁!'. 한 번 놓치면 줄이 흔들리고, 두 번 놓치면 도망.
5. **잡음**: 들어 올리는 연출 + 말풍선 '○○을(를) 잡았다! 42cm'.

## 5-2. 강화안 반영 (11/25 사용자가 준 설계안 'ASMR 사운드 이원화 및 PC 중심 웹 낚시 게임 손맛 극대화' 검토, 사용자 확정)
> 설계안 요지: 소리 없이도 손맛(의성어·시각 햅틱), 원버튼 홀드 장력 밀당·펌핑, 장비 강화, 3단 가로 UI, 어탁 카드·아쿠아리움·주간 대회·실시간 티커 등.

**넣는 것 (사용자 확정)**
- **파이팅 = 섞기**: 입질 구별(톡·가짜 풍덩·진짜 풍덩, 2장 그대로 — 우리 게임만의 재미)은 그대로. **'큰 물고기 랠리' 대신 짧은 장력 밀당(5~8초)**을 희귀·전설에만: 누르면 감기(장력 ↑·거리 ↓), 떼면 풀기(장력 ↓·물고기가 멀어짐). 장력 100% = 줄 끊김, 거리 끝 = 도망. **펌핑 = 타이밍 링**(낚싯줄 위로 링이 지나갈 때 떼었다 다시 누르기 → 크게 당기고 장력 −30%) — 탁구와 같은 '링' 약속. 일반 물고기는 밀당 없이 빨리(약 12초 그대로).
- **던지기 = 우리 기획 그대로**: 마우스를 위로 휘두르는 탁구 스윙 동작(↖ ↑ ↗ = 왼쪽·가운데·오른쪽 그림자). (설계안의 홀드 힘 게이지는 안 씀)
- **장비 강화 안 넣음**: 낚싯대·릴·미끼 성능 강화 없음. **꾸미기(찌·낚싯대 스킨)만, 보기만 다름** — 꾸미기 규칙 그대로, 월척 랭킹은 실력만.
- **소리 없이도 손맛(시각 햅틱)** — 교실 PC는 소리를 끈 경우가 많아서 꼭:
  - 의성어 글자: '톡', '풍덩!', '드르륵!'(감을 때), '끼이익!'(장력 높을 때 — 커지고 빨개지며 떨림).
  - 입질 직전 찌 둘레 **고대비 파동 링**(화면 가운데를 안 봐도 보이게).
  - 진짜 풍덩 챔질 성공 = **히트스톱 0.06초** + 화면 흔들림, 희귀·전설 걸림 = 집중선 컷인.
  - 장력 단계 색: 0~40% 흰·파랑 줄 / 41~79% 노랑·주황 줄 + 낚싯대 끝 떨림 / 80~99% 빨강 깜빡 줄 + 줄 불꽃 + 화면 가장자리 빨간 맥동 / 100% 하얀 번쩍 + 줄이 끊어져 튕김.
  - 물고기가 좌우로 도망치면 카메라가 그쪽으로 살짝 끌려감(방향 흔들림).
  - 잡는 순간 0.2초 느린 동작(물방울) + 이름·cm가 도장 찍히듯 '쾅'.
- **바다 소리**: 합성음(`audio.js`)으로 잔잔한 파도·릴 드르륵·풍덩·물보라. 녹음 파일은 없음. (설계안의 소리 믹서 UI는 안 만듦 — 지금 소리 설정 그대로)
- **어탁 인증 카드**: 잡은 뒤 '🖼️ 어탁 저장' — 물고기 그림(먹 탁본 느낌)·이름·cm·잡은 시각·날씨·닉네임 도장이 찍힌 그림을 이미지 파일로 저장(브라우저 안에서 그림 → 서버·네트워크 없음).
- **어종별 대물 기네스**: 물고기마다 가장 큰 기록 1명(명예의 전당 도감·랭킹). 서버가 cm를 정하니 그대로 기록(5장 속임수 막기 그대로).

## 7. 손맛 시안 1단계 (`fishing.html`, 11/25 test) — 코드 `src/games/fishing/`
**11/25 사용자 확정**: 카메라 = **어깨 높이(가까이)**, 선착장 = **일자 + 끝이 넓은 모양**(전망대 데크 동쪽 끝 → 꺾인 나무 계단 → 자갈 해변 → 다리 약 14m → 끝 판 11×4.5m), 물고기 3종 = **고등어(일반)·참돔(희귀)·🏓 황금 탁구공 물고기(전설)**, 시안은 **선착장 끝에서 바로 시작**(◀ ▶ / ← → 로 끝 판 위 좌우 자리 옮기기만. 걸어 내려가기는 6장 4단계).

- 파일: `page.js`(흐름·조작·카메라) · `world.js`(선착장·계단·낚싯대(마디 8개 휨)·줄·찌·그림자·물고기 모형·물보라, 물결 높이 `seaHeight` = `campusFx.js` 셰이더와 같은 식) · `hud.js`(링·의성어·게이지·컷인·도장·결과 카드, 2D 캔버스) · `sound.js`(합성음) · `data.js`(물고기·입질 순서·시험 설정 `TUNE`).
- 장면은 캠퍼스 시안(`buildCampus`)을 그대로 불러 쓰고 선착장만 더함. 화면 오른쪽 = 세계 −x(바다 +z를 봄).
- **던지기**: 누른 순간 앞 0.15초 ~ 뒤 0.15초 동안 위로 14px 넘게 올리면 던짐. 옆 이동이 위 이동의 30% 이상이면 ↖/↗. 방향에 가장 가까운 그림자로. 휴대폰은 그림자를 톡(가까운 그림자, 화면 너비 20% 안). 스페이스 = 가운데.
- **입질 시간표**: 링이 나타나고 `lead` 0.55초 뒤 잠김(톡은 0.4초 뒤 '톡'). 진짜는 잠긴 뒤 `win` 0.35초에 링이 닫힘. 가짜 풍덩은 잠긴 뒤 0.15초에 튀어 오르며 링이 깨짐(좁혀지는 빠르기는 진짜와 같음). 판정: 닫힘 ±0.07 Perfect · ±0.15 Good · 잠긴 뒤 그보다 이르면 Bad · 닫힘+0.15 지나면 놓침. 잠기기 전에 누르면 '너무 빨랐어요', 톡·가짜에 누르면 '가짜에 속았어요'. 가짜를 참으면 매번 '✨ Perfect 참기!'.
- 입질 순서(`biteSeq`): 고등어 톡(→톡) → 진짜 / 참돔 톡·가짜·톡 또는 톡·톡·가짜 → 진짜 / 황금 톡·가짜·톡·톡·가짜 → 진짜. 가짜 비율 '적게'·'많이'로 바꿔 봄.
- **Bad = 펄쩍 한 번 더**(2장 'Bad = 랠리 한 번 더'를 이렇게 해석): 물고기가 물 위로 뛰고 꼭대기에서 링이 닫힘(±0.15) → 맞추면 계속, 한 번 놓치면 한 번 더 뜀, 두 번 놓치면 도망.
- **줄다리기**(참돔·황금만, 집중선 컷인 0.9초 뒤 시작): 누르면 장력 → 0.3+당기는 힘×0.85 쪽으로 오르고 거리 줄어듦, 떼면 장력 내려가고 물고기가 멀어짐. 물고기는 돌진(좌우)·쉼을 번갈아. 장력 100% = 끊김, 거리 130% = 도망. **펌핑 링**: 1.3~2초마다 찌 쪽에서 줄을 타고 1초 만에 '펌핑' 표시에 도착 → 도착 ±0.13초에 다시 누르기(떼었다 누르기) = 거리 −20%(황금 −16%, ±0.06이면 ×1.25)·장력 −30%. 헤드리스로 참돔 약 6~8초.
- **소리 없이도 손맛**: '퐁'·'톡'·'풍덩!'·'뽁'·'탁!'·'드르륵!'·'끼이익!'(장력 80%↑, 커지고 빨갛게 떨림)·'쭈욱!'·'촤아악!'·'팅!' 글자, 입질 시작 파동 링, 챔질 히트스톱 0.06초 + 흔들림 + 번쩍, 줄·게이지 색 3단계(흰파랑/노랑주황/빨강 깜빡) + 대 끝 떨림 + 줄 불꽃 + 가장자리 빨간 맥동, 끊기면 하얀 번쩍 + 줄이 튕김, 좌우로 도망치면 카메라가 끌려감, 잡는 순간 0.2초 느린 동작 + 물방울 + 이름·cm 도장 '쾅'.
- ⚙️ 시험 설정: 물고기 고정 · 진짜 여유 0.25/0.35/0.45초 · 가짜 비율 · 장력 빠르기 0.75/1/1.3 · 소리 켬/끔. 주소 `?fish=goldball`. 디버그 `window.__fish.{S, TUNE}`.
- 기록은 이 브라우저(localStorage `fishing-best`·`fishing-count`)에만. 어탁 카드·도감·코인·서버는 다음 단계.
- 탭이 숨겨지면 그리기가 멈춰서 입질도 멈춤(돌아오면 이어서).

### 추가로 정한 것 (11/25 사용자 확정)
- **거리 = 3단계**(가까움·중간·멂): 끄는 속도로 정함. 끄는 동안 3칸 세기 표시가 차오름.
- **기포 = 모든 사람이 같은 곳에 봄**(사용자 아이디어): **3~4분에 1~2곳, 약 40초 유지**. 선착장 끝 판에서 좌우로 걸어 기포와 방향·거리를 맞추는 재미.
  - 네트워크 없이 맞추는 법(안): 기포 시간표를 '시각'으로 정함 — 약 3.5분 칸마다 칸 번호를 씨앗으로 위치·시작 시각을 뽑음(같은 코드 → 모든 PC 같은 결과). 시계는 서버 시각에 맞춘 값을 씀(PC 시계가 틀려도 같게).
  - 서버(5장)도 같은 식으로 기포 시간표를 계산해서, 던질 때 보낸 '선 자리·방향·거리 단계'가 기포 근처인지 직접 판단(브라우저가 '기포 맞췄어요'라고 하는 걸 믿지 않음).
- **찌 확대 창** = 오른쪽 아래 동그란 창, 줄다리기 때는 숨김.
- **박자·패턴**: 고등어 BPM 100·4분음표 4~6개 / 참돔 BPM 115·8분음표 섞어 10개쯤 / 황금 BPM 130·엇박·쉼표 16개쯤. 원은 박자 2개 동안 줄어듦.
- **난이도**: 다 Good이면 잡힘, 2~3번 놓쳐도 만회 가능.

- **콤보 없음**(사용자 확정): 맞출 때마다 Perfect/Good 글자 + 물고기가 끌려오는 모습만.

### 리듬 시안 구현 메모 (11/25 test)
- 파일은 7장과 같음 + `bubbles.js`(기포 시간표 — 11/27 지움, 이제 `rules.js`에서 바로). 7장의 그림자·장력·펌핑·타이밍 링 코드는 지움.
- **던지기**: 누른 채 끌어올림. 최근 0.12초 위로 움직인 거리 ÷ 화면 높이(초당)의 최댓값 ÷ 3 = 세기(0~1) → 0.34 미만 가까이(7.5m) · 0.72 미만 중간(12m) · 그 위 멀리(17m). 방향은 옆 이동이 위 이동의 30% 이상이면 ↖/↗(각도 ±0.36). 25px 미만이면 안 던짐. 준비 중엔 바다 위에 던질 자리 3×3 점, 끄는 동안 세기 3칸 + 그 점이 주황. 스페이스 = 가운데 중간.
- **기포**: `activeBubbles(시각, 'normal'|'often')` — 칸(210초, 시험용 50초)마다 씨앗으로 1~2개, 자리는 끝 판 어딘가에서 (방향 × 거리) 중 하나 ±0.6m, 40초(나타나고 사라질 때 2초 서서히). 떨어진 자리가 1.5m 안이면 '바로 위', 3.5m 안이면 '근처'. 확률(일반·희귀·전설): 보통 72·25·3 / 근처 45·43·12 / 바로 위 25·55·20. 기포 위에 '🫧 N초', 새 기포가 생기면 위쪽 알림.
- **찌**: 긴 막대찌(물 위 약 0.8m, 끝 빛남). **찌 확대 창**: 오른쪽 아래 동그란 창(화면 짧은 변의 30%, 130~220px), 카메라가 찌 자리의 물 높이를 따라 오르내려서 창 안에서는 찌가 제자리 → 떨림·잠김이 또렷. 입질 기다릴 때만.
- **입질**: 톡 = 약한 떨림 1번 + '톡' · 가짜 풍덩 = 약한 떨림 2~3번(0.17초 간격) + '꿈틀꿈틀' · 참으면 '참기 ✨'(작게) · 진짜 = 찌가 완전히 잠김 + 찌 위·확대 창에 '!' + 강한 흔들림 + 휴대폰 진동 220ms. 반응 0.25초 안 Perfect, 0.5초 안 Good, 그 뒤 놓침.
- **리듬**: 기본 원 = 화면 (가운데, 60% 높이). 원은 2박 동안 3.4배 → 1배로 줄어듦. 판정 ±0.06 Perfect · ±0.13 Good · ±0.25 안에서 벗어나면 Miss · 그보다 멀면 무시. '준비'·'시작!' 2박 뒤 첫 노트. 패턴 한 바퀴 뒤 3박 쉬고 다시(잡거나 도망갈 때까지).
  - 거리 게이지 0~100, 60에서 시작: Good −g, Perfect −1.4g, Miss +1.2g (g = 60 ÷ (노트 수 × 0.9)). → **11/26 바뀜: 아래 '손맛 길게' 참고.** 0 = 잡음, 100 = 도망. 고등어는 처음부터 3번 놓치면 도망, 참돔 약 5번.
  - 박자: 릴 '탁'(한 바퀴 첫 박은 세게) + 기본 원·낚싯대 두근. 맞추면 낚싯대 휨·물보라·'드르륵', 놓치면 '스르륵…' + 줄 풀림.
- ⚙️: 물고기 · 기포(기획대로/자주) · 챔질 Perfect 0.2/0.25/0.3초 · 가짜 비율 · 리듬 판정 폭 0.1/0.13/0.17초 · 소리. 주소 `?fish=goldball&bubbles=often`. 디버그 `window.__fish.{S, TUNE, cast(dir, tier)}`.

### 리듬·손맛 더하기 (11/25 사용자 확정 — 시안 test)
- **낚시할 때 캐릭터 반투명**(사용자 요청): 물·찌·리듬 원을 가리지 않게. 안: **내 화면에서만** 내 캐릭터를 약 40% 투명하게(다른 사람 화면에서는 그대로 — 광장에서 누가 낚시하는지 보여야 하니까). 캐릭터의 `setOpacity` 사용.
- **물고기마다 짧은 음악**: 녹음 파일 없이 합성음(드럼·베이스·화음)으로 2~4마디 반복. 템포 = 물고기 BPM(고등어 100 경쾌 · 참돔 115 · 황금 130 신나게). 노트는 음악의 강한 박에 맞춤. 소리를 꺼도 기본 원 두근은 그대로.
- **내가 누르면 멜로디가 됨**(리듬세상 느낌): 맞출 때 나는 소리가 음계라서 패턴을 다 맞추면 한 소절 멜로디가 완성. Perfect = 맑은 화음 · Good = 단음 · 놓치면 그 음이 빠짐(+ 아래 '줄 풀림' 소리).
- **맞출 때마다 확 당기기**: 캐릭터가 낚싯대를 '휙' 들어 올림 · 물고기가 물 위로 살짝 튐 · 화면이 0.05초 살짝 확대됐다 돌아옴 · Perfect는 원이 터지며 불꽃.
- **마지막 큰 노트(피니시)**: 다음 한 번만 맞추면 잡히는 때가 되면, 크고 묵직한 원 하나가 (보통보다 천천히, 3박 동안) 줄어듦 → 맞추면 크게 당겨 물고기가 물 밖으로 튀어 올라 잡힘(지금의 잡기 연출로 이어짐). 놓치면 보통 놓침처럼 멀어지고 리듬 계속.
- **놓치면 줄이 풀리는 느낌**: 릴이 '지이익' 거꾸로 돌고, 줄이 늘어지며 화면이 살짝 기울었다 돌아옴.
- **반복 안 되게**(사용자 요청 11/25: "길게 할 테니 반복되는 걸 지양, 어떻게든 변화를"): `src/games/fishing/rhythm.js`
  - 박자 패턴: 등급별 마디 조각(고등어 4분음표·쉼 6가지 / 참돔 8분음표 섞인 7가지 / 황금 엇박 7가지)을 그때그때 이어 붙임. 같은 조각 연속 금지, 4마디(구절)마다 새로 뽑음. 희귀·전설은 구절 끝 마디가 가끔 '숨 돌리기'(한 박만).
  - 음악: 한 마리마다 조(G·A·B♭·C·D 중) · 화음 진행(5가지) · 드럼 모양(3가지) · 빠르기(±4 BPM)를 새로 뽑음. 구절마다 드럼 모양이 바뀌고 구절 끝 박에 스네어 필인. 전설은 3번째 구절부터 한 음 올림(전조) + 반짝이 분산화음.
  - 멜로디: 맞춘 노트 = 그 박 화음의 음 중 하나로 한두 칸씩 오르내림 → 매번 다른 멜로디.
- 구현 메모: 리듬 시간은 진짜 시계(`performance.now`)로 잼(음악과 안 어긋나게, 누른 순간 정확히). 음악은 0.25초 앞까지 박마다 미리 걸어 둠. 첫 노트 전 1마디는 음악만('준비'·'시작!'). 탭이 숨겨지면 리듬 시계를 밀어서 멈춘 것처럼.
  - 마지막 큰 노트: 남은 거리 − (화면에 떠 있는 노트 수 × g) ≤ g일 때 다음 노트가 큰 노트(3박, 금색 굵은 원, '마지막!'), 그동안 다른 노트는 안 나옴. 맞추면 '영차—!!' + 화음 + 히트스톱 → 잡기. 일반 노트로는 거리가 1 아래로 안 내려감(꼭 큰 노트로 끝남).
  - 맞춤: 낚싯대 '휙'(위로 튕김) · 릴 빨리 감김 · 물고기 0.4초 튀어 오름 · 화면 순간 확대(시야각 −2.5%) · Perfect는 원 둘레 불꽃. 놓침: '지이익…' · 릴 거꾸로 · 줄 늘어짐 · 화면 3.5% 기울기.
  - 반투명: 준비 중엔 그대로, 던진 뒤부터 결과까지 40%. 낚싯대는 그대로(또렷하게).
- 안 넣기로 한 것(이번엔): 물고기 따라 하기(예고 신호) · 입질도 박자에 맞추기 · 잘할수록 화면이 달아오름.

- **희귀 이상이면 '마지막!'을 맞추는 순간 "끝인 줄 알았는데!"**(사용자 확정: 이 연출): 줄이 '지이이익' 확 풀리고 화면 흔들림 + 컷인 "❗ 무겁다! / 아직 안 끝났어!" → 거리 게이지가 0에서 **50**으로 밀려남(처음 60보다 덜 가혹하게) → 희귀 리듬(BPM 115, 8분음표)·**다른 조**의 새 음악. 전설이면 희귀 단계 끝에서 한 번 더 "‼ 엄청 무겁다!! / 보통 놈이 아니야…" → 전설 리듬(BPM 130, 엇박·반짝이).

- **잡을 때 공개**: 물 밖으로 튀어 오르는 순간 컷인 '✨ 희귀! / 참돔' · '🌟 전설! 🌟 / 황금 탁구공 물고기'. 그전까지 거리 게이지의 물고기는 '❓', 맞출 때 튀는 물고기는 **검은 그림자**(단계마다 커짐).
- **높은 단계에서 놓치면 그냥 놓침**(사용자 확정) + 희귀·전설 단계에서 도망가면 '…방금 그건 전설급이었다' 아쉬움 한 줄(사용자 확정). 일반 단계에서 도망가거나 챔질을 놓치면 등급은 안 알려 줌.

## 11. 크기 '최대 없음 + 긴 꼬리' + 큰 놈 연출 (11/25 사용자 확정, test · **`29_fish_size.sql` 실행 필요**)
> **11/26: 13장으로 바뀜** — 아래 식은 이제 cm가 아니라 '크기 점수 s'(배율 × 50). 실제 cm = 물고기 보통 크기 × s ÷ 50. 등급·연출·랭킹은 s로.
> 사용자: "최대를 없애고 꼬리를 길게. 낚았을 때 크기도 드라마틱하게 달라지게. 진짜 큰 걸 낚았다는 걸 알 수 있게."
- 이유: 100cm 상한이면 한 주 600마리일 때 1~10등이 모두 98~100cm(0.1cm 싸움).
- 식(`rules.js` `cmOf(u)` = SQL `pingpong__fish_cm(u)`, 난수 하나): 85cm까지 예전과 같음(20 + 80·u^1.6) → 85cm 위는 파레토 꼬리 85 + 22.5·((1−q)^(−1/3.48) − 1). 안전 상한 999cm. 종류·등급 상관없이 같음(예전 결정 그대로).
- 확률: 20~30cm 27.3% · 30~40 14.8% · 40~50 12.1% · 50~60 10.7% · 60~70 9.7% · 70~80 9.0% · 80~88 8.6% · 88~100 5.8% · 100~110 1.2% · 110~120 0.4% · 120~150 0.4% · 150~200 0.09% · 200~300 0.02%. 중간값 46cm, 평균 51cm.
  - 88cm↑ 약 1/13 · 100cm↑ 1/49 · 110cm↑ 1/111 · 150cm↑ 1/930 · 200cm↑ 1/4,500 · 300cm↑ 1/30,000.
  - 한 주 600마리면 1등 약 150cm, 10등 약 103cm / 3,000마리면 1등 약 200cm.
- 크기 등급(`SIZE_TIERS`): 🏆 **월척** 88cm↑ · 🐋 **대물** 110cm↑ · 👑 **괴물** 150cm↑. 업적 「월척 사냥꾼」은 88cm 그대로.
- 연출(`page.js` `startLand`·`tickLand`): 모형 크기 = `modelScale(cm)`(20cm 0.55배 → 88cm 1.6 → 150cm 2.5 → 300cm 4.75, 최대 5). 등급별로 느린 동작 0.2→0.3→0.45→0.7초, 물보라 30→40→60→90, 흔들림·진동, 들어 올리는 데 1.0→1.1→1.4→1.9초, 끝 1.9→2.1→2.7→3.6초. 대물·괴물은 도장 뒤 컷인 '🐋 대물!!' / '👑 괴물!!!' + 번쩍(글자는 아래쪽). 큰 놈은 카메라가 조금 물러나고 위를 봄, 들고 있어도 퍼덕. 도장은 크기 등급만큼 커지고 아이콘이 붙음(화면 60% 높이 — 물고기를 안 가리게). 줄다리기 중 튀는 검은 그림자도 크기에 맞춰 큼.
- 결과 카드·도감에 크기 등급 아이콘. ⚙️ '크기 (시험)'(로그인 안 했을 때): 랜덤 · 40 · 🏆95 · 🐋125 · 👑180 · 👑300.
- SQL `29_fish_size.sql`: `pingpong__fish_cm` + `pingpong_fish_cast`(28과 같고 크기 한 줄만). 자동 점검이 406개 u로 서버 식 == 화면 식 비교.
