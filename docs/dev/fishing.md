## 4. 한 마리 잡는 흐름
### 4-1. 꾹 눌러 던지기 (사용자 확정 11/27)
- 화면 아무 곳(또는 스페이스)을 **누르는 순간 비트 시작**(첫 박 = 누른 순간). **오래 누를수록 멀리**: 세기 `power` 0~1 = 누른 박 수 ÷ `TUNE.chargeBeats`(**4박**) → **6~18m**, 끝에 닿으면 '최대!'. 아주 짧게 누르면 6m.
- **방향 = 누른 채 좌우로 밀기** → 부채꼴 ±40°(`aim` −1~1). 스페이스로 모을 땐 ←→. 모으는 동안은 안 걸어감.
- 화면: 끝까지 닿는 부채꼴 = 옅은 흰 면 + 가는 테두리 · 지금 세기 = 빛나는 흰 호(물결 안 따라 평평) · 떨어질 자리까지 흐려지는 흰 선 + '○m'. **기 모으기**: 누를수록 최대 약 8% 확대 + 가장자리부터 붉어짐 + 박마다 두근 + 한 음씩 오르는 소리. 떼면 '휙'.
- 코드 `session.js press · chargeNow · moveDrag · release · cancel`. 서버는 '선 자리·aim·power'만 받아 직접 계산.
- **찌 떨어질 자리** `rules.js landingPoint`: 판 위에 떨어지면 던진 방향 그대로 판 끝 + 0.6m까지 넘어감. 던지는 방향은 늘 남쪽. 서는 곳 `STANDS` 3개(앞 판 · 양 팔), `clampStand`.

### 4-3. 입질 · 챔질
- 던진 뒤에도 **같은 곡이 끊기지 않음**(일반 BPM 100, 기다리는 동안은 드럼·베이스만 가볍게). **입질은 박 위에서**(`onBeat`).
- 톡 = 약한 떨림 1번 · 꿈틀(가짜) = 약한 떨림 2~3번(반 박 간격) · **진짜 = 찌가 완전히 잠김 + '!' + 강한 흔들림 + 휴대폰 진동**. 가짜에 누르면 실패. 입질 순서는 등급과 상관없이 고름(순서로 못 알아채게).
- 챔질: '!' 뒤 **0.3초 안 Perfect · 0.5초 안 Good**, 그 뒤 놓침. 시간은 진짜 시계로 잼.
- 찌 = 긴 막대찌(끝 빛남) + 오른쪽 아래 **동그란 찌 확대 창**(물 높이를 따라가서 찌가 제자리, 입질 기다릴 때만).
- 탭이 숨겨지면 박자·입질·기 모으기 시계를 모두 밀어 멈춘 것처럼(`resumeAfter`).

### 4-4. 줄다리기 = 리듬게임 (사용자 확정)
- 낚아채면 **같은 박자를 이어받아** 노트 시작(첫 노트 = 2~4박 뒤 짝수 박, '준비'·'시작!'). 노트 = 화면 가운데(60% 높이) 고정된 기본 원에, **2박 동안 3.4배 → 1배로 줄어드는 원**이 닿을 때 누르기(탁구 링과 같은 약속).
- 판정 ±0.06 Perfect · ±0.13 Good · ±0.25 안에서 벗어나면 Miss(그보다 멀면 무시). Good·Miss 밑에 '◀ 조금/너무 빨라요' · '늦어요 ▶'.
- **거리 게이지** 0~100, 60에서 시작. 맞추면 −g(**Perfect도 Good과 같은 −g** — 빨리 안 끝남, 대신 연출이 크고 **품질 별(7장)로 값이 오름** · 'Perfect ×3'부터 금색), 놓치면 멀어짐. 0 = 잡음, 100 = 도망.
- **길이는 시간으로**(사용자 확정): 단계마다 일반 **6초** · 희귀 **7.8초** · 전설 **7.8초**(`data.js secs`) 동안의 노트 수 N → g = 시작 거리 ÷ (N + 1). 놓쳐도 되는 정도 `missOut` 일반 3 · 희귀 7 · 전설 10. 다 Good이면 잡힘.
- **마지막 큰 노트**: 다음 한 번이면 잡힐 때 3박짜리 금색 굵은 원 '마지막!' → 맞추면 '영차—!!' → 잡기. 일반 노트로는 끝나지 않음.
- **등급 숨기기**(사용자 아이디어·확정): 누구나 일반 리듬으로 시작. 희귀 이상이면 '마지막!'을 맞추는 순간 줄이 '지이이익' 풀리며 "❗ 무겁다! / 아직 안 끝났어!" → 게이지 50 → 희귀 리듬. 전설은 한 번 더 "‼ 엄청 무겁다!!". 새 단계는 음악을 **먼저 들려주고**(희귀 4박 · 전설 8박) 노트 시작. 노트 색 = 단계 색(일반 주황 · 희귀 파랑 · 전설 금색). 그전까지 물고기는 '❓'·검은 그림자.
  - 높은 단계에서 놓치면 그냥 놓침 + '…방금 그건 전설급이었다'. 일반 단계에서 놓치면 등급 안 알려 줌.
- **박자 패턴** `rhythm.js BARS`: 일반 BPM 100 4분음표 · 희귀 115 8분음표 섞음 · 전설 130. 반 박이 가장 잘게, **반박 노트는 항상 바로 앞 정박에 붙음**(쿵-딱). 마디 조각을 그때그때 이어 붙이고 같은 조각 연속 금지, 4마디마다 새로.
- **음악·멜로디**(녹음 없이 합성음): 한 마리마다 조·화음 진행·드럼 모양·빠르기(±4)를 새로 뽑음, 전설은 3번째 구절부터 전조 + 반짝이. **맞춘 노트 = 멜로디 한 음**(Perfect 화음 · Good 단음 · 놓치면 빠짐).
- **반응**: 누르는 순간 기본 원이 '꾹' + 번쩍(판정과 상관없이), 노트 없으면 작은 '톡'. 맞추면 낚싯대 '휙'·릴 감김·물고기 살짝 튐·화면 순간 확대·Perfect 불꽃. 놓치면 '지이익…'·릴 거꾸로·줄 늘어짐·화면 기울기.
- **카메라**: 박마다 살짝 다가갔다 돌아옴(약 1.2%, 마디 첫 박 1.6배) · 희귀 단계 확대 4.5% + 3° 기울기 · 전설 9% + 반대 6°. ⚙️ '카메라 연출'(`TUNE.cam`).
- **잘할수록 달아오름**(사용자 확정, 콤보 숫자는 안 보임): 열기 점수 Good +1 · Perfect +1.5(최대 16) → 3·7·12점에 1·2·3겹, 놓치면 한 겹 아래로. 음악 겹(하이햇·박수 → 굵은 베이스 → 반짝이) + 색(주황 → 분홍 → 금색: 기본 원 둘레 빛·화면 가장자리). 노트 색은 그대로. `TUNE.heat·heatC`, `?heat=0` 끔.
- **주변이 박자를 탐**(내 화면에서만, 던질 때부터): 찌 둘레 물결 고리·반짝임 · 선착장 등·등대·횟집 빛 번쩍, 배 '통', 간판 들썩 · 내 캐릭터 무릎 까딱 · ♥2 고양이 까딱. 박자 정보 `beat.js BEAT`, 연출 `beatFx.js`. `?beat=0` 끔.
- 잡동사니는 일반 리듬을 짧게(약 3초).

## 6. 크기 (사용자 확정 11/26)
- 서버가 '크기 점수' s(20~999, 보통 50)를 뽑음: 85까지 20 + 80·u^1.6, 그 위는 긴 꼬리(파레토) — **최대 없음**. 중간값 약 46.
- **실제 cm = round(s × 보통 크기 ÷ 50, 1)**. 보통 크기(`rules.js SPECIES` = SQL `base_cm`): 고등어 30 · 전갱이 25 · 볼락 20 · 노래미 30 · 가자미 30 · 오징어 30 · 복어 25 · 참돔 50 · 감성돔 40 · 우럭 40 · 방어 70 · 문어 60 · 라테 망둥어 15 · 달빛 갈치 90 · 빗방울 숭어 50 · 황금 40 · 용왕 150.
- 크기 등급은 s로: 🏆 **월척** 88↑(약 1/13) · 🐋 **대물** 110↑(1/111) · 👑 **괴물** 150↑(1/930). 고등어도 '괴물 고등어'가 될 수 있음.
- **행운 주사위**(서버가 여러 번 뽑아 큰 것, 화면에 안 보임): 처음 10마리 3번 · 오늘 첫 3마리 2번 · 그 밖 1번 + **바다 술렁임**(이번 주 1등 기록 뒤 하루마다 +1, 최대 +4, 깨지면 0, 이번 주 기록에만). 크기는 운, 실력은 놓치느냐에만.
- **월척 랭킹 = 길이(cm) 순서**, 이번 주(한국 월요일 0시부터) + 역대, 사람마다 가장 큰 한 마리 50명. 어종별 기록(도감 👑) 1명.
