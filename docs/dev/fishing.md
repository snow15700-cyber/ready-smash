# 낚시 (기획 확정 11/25 — 아직 만들지 않음)

> 사용자: "광장에 바다가 있으니 거기서 낚시를 하자." 레퍼런스 = 동물의 숲(톡톡 풍덩) + 우리 탁구의 타이밍 링.
> 순서(사용자 확정 11/25): **출석 도장판·승리 세리머니는 잠깐 보류하고 낚시를 먼저**.

## 0. 전제
- 새 광장(`plaza.md` 20장 '경주캠퍼스 느낌')의 바다에서 한다. 광장 바닥은 바다보다 약 12m 높고, 남동쪽 바다 전망대 아래 자갈 해변(z ≈ 48)이 있다.
- 새 광장은 아직 시안(`campus.html`)이다. 그래서 **손맛 시안은 캠퍼스 시안의 바다 위에서 먼저** 만들고, 게임 광장에 넣는 건 광장 옮기기 ⓐ(바닥·본관·바다·산) 다음에 한다.
- 꾸미기처럼 **판정·경기와 상관없는 놀이**다. 경기 중인 선수 PC에 네트워크 부담을 주지 않는다.

## 1. 낚시 자리 (사용자 확정)
- 전망대 옆 계단으로 내려가 해변의 **나무 선착장**에서 한다.
- **정해진 칸 없음**: 선착장 위 어디서든 서서 던질 수 있고, 여러 명이 나란히 서도 된다(겹치면 살짝 비켜 섬).
- 다른 사람에게는 걷기처럼 '던졌다(어디로)'·'잡았다(무엇을)'만 한 번씩 보낸다(광장 채널).
- **휴대폰도 가능**(사용자 확정): 노리는 그림자를 톡 눌러서 던지고, 링 판정은 화면 아무 데나 누르기.

## 2. 한 마리 잡는 흐름 (사용자 확정, 숫자는 시안에서 조정)
1. **그림자 보기**: 물속에 물고기 그림자 2~3개. 크기로 짐작.
2. **던지기**: 마우스를 위로 올리며 클릭(스윙과 같은 동작). ↖ ↑ ↗ = 왼쪽·가운데·오른쪽 그림자.
3. **입질**: 매번 **찌 둘레에 타이밍 링**이 좁혀진다. **진짜만 누르고 가짜는 참는다.**

| 입질 | 찌·소리 | 링 | 정답 |
|---|---|---|---|
| 톡 (가짜) | 살짝 콕, '톡' | 작고 빠름 | **안 누르기** → '✨ Perfect 참기!' |
| 가짜 풍덩 (변칙, 사용자 아이디어) | 쑥 잠겼다가 **바로 다시 튀어 올라옴** | 닫히기 전에 깨짐 | **안 누르기** → '✨ Perfect 참기!' |
| 진짜 풍덩 | 쑥 잠기고 **계속 잠겨 있음**, 묵직한 '풍덩!' + 물보라 | 끝까지 닫힘 | **닫힐 때 클릭** (Perfect / Good / Bad) |

   - 가짜 풍덩과 진짜는 **잠기는 순간까지 똑같다**. 차이는 그다음 약 0.15초(튀어 오르느냐). 급하게 누르는 사람을 거르는 함정.
   - 진짜는 잠긴 뒤 링이 닫힐 때까지 약 0.35초 여유(보고 눌러도 되게).
   - 가짜에 누르거나 진짜를 놓치면(Miss) 물고기가 도망간다.
   - 입질 순서는 물고기마다 다르다(순한 것: 톡 → 진짜 / 까다로운 것: 톡·톡·가짜 풍덩·톡 → 진짜).
   - 진짜 판정: Perfect = 바로 잡음(참기도 다 Perfect면 도감에 ✨ 표시) · Good = 잡음 · Bad = 랠리 한 번 더.
4. **큰 물고기 랠리**(사용자 확정): 잡은 뒤 물고기가 물 위로 2~3번 펄쩍 뛴다. 뛸 때마다 링이 뜨고, 맞추면 '탁!'. 한 번 놓치면 줄이 흔들리고, 두 번 놓치면 도망.
5. **잡음**: 들어 올리는 연출 + 말풍선 '○○을(를) 잡았다! 42cm'.

## 3. 잡히는 것 (사용자 확정: 다 넣기)
- **동해 물고기 15종쯤**(일반·희귀·전설): 고등어·전갱이·볼락·우럭·노래미·가자미·복어·오징어·문어·감성돔·참돔·방어 등. 전설 1~2종(예: 🏓 황금 탁구공 물고기).
- **조건 물고기**: ☕ 쉬는 시간에만(`src/breaks.js`) · 🌙 밤에만(광장 시간) · 🌧️ 비 올 때만(광장 날씨 = 대구 실제 날씨).
- **잡동사니 여러 개**(사용자 확정 11/25: 전설 아이템 부품·조립 방식은 **버림** — 어지러움): 나뭇가지·빈 캔·장화·페트병·해초·조개껍데기·낡은 탁구공·부러진 탁구채·김제빵의 바게트 등. **도감 칸 + 업적용**(코인 0).

## 4. 보상 (사용자 확정: 도감·칭호 중심)
- **도감**: 명예의 전당 안 '🐟 도감' 탭. 잡은 종·가장 큰 크기·✨ 표시. 못 잡은 건 그림자 모양만. 물고기·잡동사니 따로.
- **코인**(사용자 확정 11/25):

| 잡은 것 | 걸리는 시간(어림) | 코인 |
|---|---|---|
| 일반 물고기 | 약 12초 | **+4** |
| 희귀 물고기 (랠리 2번) | 약 18초 | **+6** |
| 전설 물고기 (랠리 3번) | 약 20초 | **+10** |
| 잡동사니 | 약 12초 | 0 |
| 놓침 | – | 0 |

  - 새 종을 **처음** 잡으면 보너스: 일반 +5 / 희귀 +15 / 전설 +50.
  - ☕ 쉬는 시간 +50%(혼자 하기처럼).
  - 어림: 잘하면 분당 약 15~20코인. 혼자 하기(분당 약 8)·1대1(분당 약 11)보다 많다 — 사용자에게 알림(11/25). 시안·테스트 뒤 다시 볼 수 있음.
- **업적·칭호(안)**: 도감 10종 「초보 낚시꾼」 · 물고기 모두 「경주 강태공」 · 잡동사니 모두 「바다 청소부」 · 참기 Perfect 10연속 「손맛의 달인」 · 바게트 낚기 「김제빵의 원수」.
- **랭킹**: 명예의 전당 '이번 주 월척'(가장 큰 물고기).
- **광장 알림**: 희귀·전설을 잡으면 모두에게 '🎣 ○○님이 참돔(62cm)을 낚았어요!'.

## 5. 서버·속임수 막기
- 어떤 것이 걸릴지·몇 cm인지는 **서버가 정한다**(던질 때 서버가 뽑음). 브라우저는 잡았다/놓쳤다와 판정만 알린다.
- 던지기부터 잡기까지 **물고기별 최소 시간**, 혼자 하기(`pingpong_ai_rally`)처럼 **지난 기록 이후 시간으로 분당 상한**(코인 표에 맞춰 약 20~25)을 넘으면 자른다.
- SQL `28_fishing.sql`(번호는 만들 때 다시 확인), `pingpong_` 접두어, RLS + security definer. 로컬 가짜 서버(`account.js`)도 같은 규칙.

## 6. 만드는 순서 (단계마다 멈추고 사용자 테스트)
1. **손맛 시안 `fishing.html`**: 캠퍼스 시안 바다 + 선착장, 던지기·톡·가짜 풍덩·진짜 풍덩·랠리, 물고기 3종(서버 없음). 링 크기·판정 시간·가짜 비율을 직접 해 보고 정함.
